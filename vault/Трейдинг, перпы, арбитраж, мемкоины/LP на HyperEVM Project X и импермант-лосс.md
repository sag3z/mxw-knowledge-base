# LP на HyperEVM/Project X и импермант-лосс

Кратко: В чате разобрали два параллельных сюжета вокруг HyperEVM. Первый — конкурс с лидербордом по P&L на перп-DEX: вход от 700 $ на балансе, потолок депозита 1100 $, положительный P&L от +1 $ начинается только с 70 места [[crypto-c0049]]. Второй — концентрированная ликвидность в пуле HYPE/USDC V3 на Project X (prjx.com): nrcair заявляет 400–500% APR в узком диапазоне с автоматическим ребалансом, Timur по своему расчёту получил около 200% [[crypto-c0049]]. Ключевой риск — импермант-лосс: при уходе цены ниже диапазона позиция превращается в покупку HYPE по центру диапазона, и вся надежда на то, что комиссии перекроют убыток [[crypto-c0051]]. Хедж шортом на Hyperliquid участники признали нереализуемым по скорости [[crypto-c0051]].

## Конкурс с лидербордом: условия и схемы

Места считаются по P&L, точные метрики конкурса Max Wayld не уточнял. Для регистрации нужно минимум 700 $ на балансе; положительный P&L хотя бы в +1 $ есть только начиная с 70 места [[crypto-c0049]]. Позже он же обнаружил лимит депозита до 1100 $ и отметил, что «с этим схемка потяжелее будет» [[crypto-c0049]].

Схема мультиаккаунта от Max: загнать три аккаунта, на одном открыть лонг, на двух других — разные шорты, чтобы не палиться [[crypto-c0049]].

Реферальная часть (по словам nrcair): если твой реферал попадёт в топ-20 по итоговому лидерборду, ты получаешь 500 $ [[crypto-c0049]]. Там же упоминается недельный пул 50 HYPE [[crypto-c0049]].

## Механика LP на Project X (HYPE/USDC V3)

Интерфейс на скрине Timur: пул HYPE/USDC V3, fee tier 0.05%, ликвидность около $14,190 (значение в скрине обрезано), текущая цена 65.3 USDC за HYPE, выбранный диапазон 64.9874–65.6405 USDC за HYPE, расчётная доходность 393.58% APR при изменении цены в пределах −0.48% / +0.52% [[crypto-c0049]]. То есть диапазон шириной примерно в 1% вокруг цены — это и есть источник «четырёхсот процентов» в интерфейсе.

По словам nrcair, 400–500% APR достижимы в узком диапазоне, но только с ребалансом софтом [[crypto-c0049]]. Timur по своему расчёту получил около 200% при заявленных 400–500% [[crypto-c0049]].

Отдельно про выбор ноги: nrcair сначала делал бота под «USDC only», потом увидел, что на HYPE-пуле тики большие, и переделал под вторую маленькую ногу — иначе ждать входа цены в диапазон слишком долго [[crypto-c0050]]. На пулах с мелким тиком, по его словам, можно вставать чистым USDC [[crypto-c0050]].

## Импермант-лосс

Прямое предупреждение nrcair в ответ на скрин с 393% APR: «не забывай про импермант лост» [[crypto-c0049]]. Механика описана им же: если цена уйдёт ниже диапазона, считается, что ты купил HYPE по средней цене своего диапазона, то есть по его центру [[crypto-c0051]]. Вся конструкция держится на «надежде, что хайп будет стабильным и комса перекроет потери с лоста» [[crypto-c0051]] — это ставка на боковик, а не безрисковая доходность.

## Почему шорт-хедж на Hyperliquid не спасает

Идея Timur: при падении HYPE параллельно открывать шорт на HYPE на том же Hyperliquid, чтобы захеджировать постепенное погружение вниз по цене. Его же вывод: «нереально по-моему по скорости» [[crypto-c0051]]. По словам nrcair, заработок на 1%-спреде мал [[crypto-c0051]] — то есть покрывать издержки/просадку такой хедж не окупает.

Иллюстрация риска шортового хеджа — пересланный Max Wayld ролик от «$100k на крипте» (23.10.2026) про токен IRYS [[life-c0718]]. По сюжету ролика: «Арти» шортил IRYS по 0.066, доливал маржу на 10x, пересидел рост в 1000% и вышел в профит; «Дима» тоже шортил IRYS и был ликвидирован на $234 000, а хедж-нога на Gate принесла ему $300 — автор ролика называет это «NDA-арбитражем» [[life-c0718]]. На экране фигурируют плашки «−234 000$» и «+300$» и красный баннер «ЛИКВИДАЦИЯ» на графике $IRYS / USDT [[life-c0718]]. Сёма отреагировал шуткой [[life-c0718]]. Кейс не про Project X, но показывает масштаб расхождения между основным шортом и «хеджем» на другой площадке.

## Промпт на LP-бота (от nrcair)

nrcair выложил готовое ТЗ для ИИ-кодера: локальный софт под Mac для автоматического управления LP-позицией в пуле HYPE/USDC V3 на Project X (prjx.com), сеть HyperEVM [[crypto-c0049]]. Параметры в промпте: fee tier 0.3% — при том, что на скрине пула выше фигурирует 0.05%; позиция всегда одна, несколько активных одновременно запрещены [[crypto-c0049]].

Структура проекта: `.env`, `package.json`, `src/index.js`, `README.md`, кликабельный запускатель `.command` для Mac; запуск одним кликом, без меню «1/2/3» — один запуск = автопилот [[crypto-c0049]].

Логика позиции:
- Бот сам проверяет кошелёк и находит активные NFT-позиции в нужном пуле через Position Manager; `POSITION_NFT_ID` не обязателен и не вводится руками [[crypto-c0049]].
- Если активных позиций больше одной — бот не открывает новую молча, а показывает статус и ждёт, пока лишние закроют [[crypto-c0049]].
- Если позиции нет — создаёт первую сам, после mint запоминает/обнаруживает новый tokenId [[crypto-c0049]].
- Вход делается той монетой (USDC или WHYPE/HYPE), которой в кошельке больше по USD-стоимости; позиция почти односторонняя, вторая монета добавляется только как минимально необходимая «пыль» [[crypto-c0049]].
- Никакой логики «свапни 5%»: свапается ровно столько второй монеты, сколько нужно для mint; сначала проверка, хватает ли её на кошельке, если не хватает — добор недостающего с небольшим запасом; при провале mint из-за нехватки — ещё один маленький добор и повтор [[crypto-c0049]].
- На кошельке всегда остаётся запас нативного HYPE на газ, значение задаётся в `.env` [[crypto-c0049]].

Геометрия диапазона:
- Ширина по умолчанию 5%, параметр `RANGE_BPS=500` [[crypto-c0049]].
- Диапазон должен касаться актуального тика, а не стоять далеко; для USDC-позиции цена у края диапазона и позиция почти односторонняя USDC, для HYPE — зеркально [[crypto-c0049]].
- Обязательный учёт `tickSpacing` пула; диапазон в 50% при заданных 5% создавать нельзя [[crypto-c0049]].
- В лог явно выводятся: current tick, tick spacing, lower tick, upper tick, lower price, upper price, выбранная сторона, ожидаемые amount0/amount1 [[crypto-c0049]].

Ребаланс:
- Переставлять позицию каждую минуту из-за выхода из диапазона запрещено; после создания позиция может быть вне диапазона — это нормально [[crypto-c0049]].
- Перестановка только при уходе цены дальше буфера от края: `REBALANCE_TICK_BUFFER=1` в `.env`. Если цена у края или в пределах буфера — ничего не делать [[crypto-c0049]].
- При выходе за буфер: закрыть текущую позицию → забрать токены на кошелёк → заново проверить, какой монеты больше → при необходимости добрать «пыль» → открыть новую позицию по актуальной цене и тем же правилам диапазона [[crypto-c0049]].
- Опрос состояния — раз в `POLL_INTERVAL_SECONDS` из `.env` [[crypto-c0049]].

## Выводы и правила

- 400–500% APR из интерфейса Project X — это оценка для узкого диапазона (~1% на скрине) и не равна реализованной доходности: независимый расчёт Timur дал ~200% [[crypto-c0049]].
- Узкий диапазон = односторонняя ставка. При падении HYPE ниже диапазона позиция становится покупкой по центру диапазона (импермант-лосс), и вся доходность зависит от того, перекроют ли комиссии эту просадку [[crypto-c0051]].
- Шорт на Hyperliquid как хедж нерабочий по скорости исполнения [[crypto-c0051]]; заработок на 1%-спреде, по словам nrcair, мал [[crypto-c0051]]. Кейс IRYS показывает, чем заканчивается шорт с доливкой маржи и «хедж-ногой» на другой бирже: −234 000 $ против +300 $ по сюжету ролика [[life-c0718]].
- Для LP-стратегии nrcair собирает вторую ногу не из любви к HYPE, а из-за крупного тика на HYPE-пуле: чистый USDC имеет смысл только на пулах с мелким тиком [[crypto-c0050]].
- В конкурсе с лидербордом считать нужно не абсолютный P&L, а место: положительный результат начинается только с 70-й строчки, а депозит ограничен 1100 $ при входе от 700 $ [[crypto-c0049]].
- При автоматизации — один пул = одна позиция, ребаланс только по тиковому буферу (`REBALANCE_TICK_BUFFER`), ширина диапазона в базисных пунктах (`RANGE_BPS=500`), обязательное логирование тиков и резерв нативного HYPE на газ [[crypto-c0049]].
