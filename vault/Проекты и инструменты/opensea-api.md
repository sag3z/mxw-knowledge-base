# OpenSea API

**Что это:** API маркетплейса OpenSea, который комьюнити использует для проверки вайтлистов (WL) и получения данных коллекций; доступ выдаётся по ключу разработчика с кредитным лимитом.

## Что говорили в чате

- Предупреждение от TheRikka: при проверке WL OpenSea API возвращает все кошельки, привязанные к основному, как whitelisted. Если минтить по расписанию, основной кошелёк пройдёт, а привязанные упадут (без потери средств). [[nft-c0239]]
- FroZi для сайта-агрегатора Stonkhuman (подключаешь кошелёк — видишь все коллекции, где есть WL) запросил ключ OpenSea API как разработчик и, по его словам, ограничен кредитами. [[nft-c0253]]
- Max: данные коллекции можно получить через endpoint `api.opensea.io/api/v2/collections/<contract>` — подставить ID коллекции. [[nft-c0360-03]]
- Max: в софте для минта (кейс Never Fucking Trade) в readme инструкция — загрузить кошельки, выбрать кошелёк под дисперс, вставить ссылку на OS, контракт вытянется сам; проверка WL делается отдельно через OpenSea API, когда у коллекции появится страница. [[nft-c0360-04]]

## Итог

OpenSea API — рабочий и активно используемый инструмент в чате: через него проверяют WL и тянут данные коллекций (софты Max, агрегатор Stonkhuman от FroZi). Главный риск — ложноположительный результат проверки WL для привязанных кошельков, которые при минте упадут; также доступ ограничен кредитами по ключу разработчика.
