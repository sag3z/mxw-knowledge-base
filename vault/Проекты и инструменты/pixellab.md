# PixelLab (pixellab.ai)

**Что это:** ИИ-инструмент для генерации пиксельных персонажей и анимации спрайтов; поддерживает подключение через API.

## Что говорили в чате

- 2026-09-18: Max советует pixellab.ai для пиксельных персонажей и анимаций — лучше всего для персонажей до 128x128; по его словам, Astra и Fable анимации персонажей не делают [[ai-c0288]]
- 2026-09-18: По словам Max, анимации через pixellab получаются качественнее, чем у связки Codex + Aseprite, где заметны плывущие текстуры и края, выдающие ИИ-происхождение картинок [[ai-c0289]]
- 2026-09-18: Покадровая диффузия PixelLab давала мерцание деталей (волосы, вязка), поэтому Max перешёл на видеомодель animate-pixelminimax (MiniMax H3), которая двигает исходный спрайт и подтягивает цвета к первому кадру (drift_threshold=0); PixelLab при этом подключён через API, чтобы не делать всё вручную [[ai-c0290]]
- 2026-09-18: Рабочий пайплайн для анимаций — Fable или Astra плюс pixellab: анимации выглядят почти идеально, но для художников часть кадров заметно расходится; гайд по такому пайплайну, по словам Max, стоит публиковать только в приватке, иначе «засрут за ИИ» [[ai-c0291]]

## Итог

По словам Max — рабочий инструмент для пиксель-арта и анимации спрайтов (лучшие результаты на персонажах до 128x128) с API-доступом. Риски: мерцание деталей при покадровой диффузии и расхождение отдельных кадров, заметное для художников. Статус: активно используется в рабочем пайплайне сообщества в связке с Fable/Astra и MiniMax H3.
