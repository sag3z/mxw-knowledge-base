# Задача: дизайн — основа (иконки, токены, поля, кнопки)

Работай в `app/web/` (`index.html`, `style.css`, `js/*.js`). Сначала прочитай `tasks/DESIGN.md` — правила обязательны. Не читай `.llm_env`/`.openrouter_key`, не читай `tasks/*.log`, НЕ открывай PNG инструментом Read (сессия падает). LLM не нужен. Сервер/бэкенд не трогай.

Пользователь выбрал направление «тёмный, но доведённый»: оставить текущую тёмную тему и палитру DESIGN.md, но убрать дешёвый вид. Ревьюер посмотрел скриншоты, проблемы ниже.

## 1. Иконки: эмодзи → SVG
Сейчас в боковой панели и кнопках — цветные эмодзи Windows (💬 🗺 📅 👥 📈 📚 ✏ 🙈 👁 🔍 ⚙ 💬 и т.п.), выглядят разнобойно.
- Создай `js/icons.js`: `export function icon(name, size = 18)` → строка inline-SVG в стиле Lucide (stroke `currentColor`, stroke-width 1.75, `fill="none"`, viewBox 0 0 24 24, round caps/joins). Пути нарисуй сам (без CDN и без скачивания пакетов), минимум: `chat` (message-circle), `map` (map), `calendar`, `users`, `trending` (chart-line), `book` (book-open), `plus`, `pencil-square` (новый чат), `eye`, `eye-off`, `search`, `x`, `menu`, `chevron-down`, `chevron-left`, `arrow-up`, `arrow-left`, `more` (три точки), `settings`, `sliders`, `external`, `check`, `alert` (треугольник), `copy`, `trash`, `list` (оглавление).
- Замени ВСЕ эмодзи-иконки интерфейса (боковая панель, кнопка «Новый чат», «Скрыть/Показать ники», «Уточнить», плитки быстрых ссылок на главной чата, поиск в статьях/людях/активностях, кнопки drawer ←/⋯/✕, «Спросить ИИ про эту статью», настройки) на `icon(...)`. Эмодзи в данных (тексты сообщений, ⚠ в статьях, ⭐ «ценное») не трогать. Иконка в меню — цвет вторичного текста, у активного пункта — основной текст.
- Аватары-инициалы в «Людях» оставить.

## 2. Акцент спокойнее
- Кнопка «Новый чат»: вместо розовой обводки — нейтральная (поверхность `#1e222b`, без рамки или рамка `#272b35`, иконка pencil-square + текст), hover — чуть светлее. Акцент `#e5397b` остаётся только для: основной кнопки действия (отправить в чате, активный сегмент переключателя), фокуса, активного пункта меню — тонкая полоска 3px слева или фон `rgba(229,57,123,.12)` с текстом основного цвета (не розовый фон целиком).
- Переключатели-сегменты (карта «По темам/По веткам», «Главное/Без флуда/Всё», «Всё время/3 месяца/Месяц»): единый компонент `.seg` — контейнер с фоном поверхности и рамкой, активный сегмент — приподнятая поверхность `#2a2f3a` + основной текст (не ярко-розовый блок). Один стиль во всех разделах.

## 3. Поля ввода, селекты, чипы — единый вид
- Общий класс поля `.field` (высота 40px, радиус 10px, фон `#171a21`, рамка `#272b35`, фокус — рамка акцента + `box-shadow: 0 0 0 3px rgba(229,57,123,.15)`), с иконкой поиска слева внутри (абсолютное позиционирование, padding-left 38px) и кнопкой очистки ✕ справа внутри поля (видна только когда есть текст).
- **Баг**: в разделе «Статьи» лупа съехала под поле, а ✕ — на отдельную строку. Исправь, применив `.field`. Проверь то же в «Людях» и «Активностях».
- В «Активностях» системные `<select>` («все типы», «все сети») — заменить на стилизованные: либо `appearance:none` + своя стрелка chevron-down в том же стиле `.field` той же высоты 40px, либо кнопка-дропдаун. Ряд фильтров — одна линия одинаковой высоты.
- Чипы категорий: одинаковая высота 28px, точка цвета 8px, hover — приподнятая поверхность, выбранный — рамка акцента.

## 4. Полировка
- Типографика по DESIGN.md (заголовок раздела 22px/600 с letter-spacing -0.01em, пояснение 14px вторичным, max-width 720px).
- Скроллбары тёмные тонкие (`scrollbar-color: #2a2f3a transparent; scrollbar-width: thin;` + webkit-вариант).
- Hover/transition 120ms для карточек, пунктов меню, кнопок. `:focus-visible` — видимое кольцо.
- Внизу боковой панели — «Скрыть ники» как обычный пункт меню с иконкой eye-off/eye.
