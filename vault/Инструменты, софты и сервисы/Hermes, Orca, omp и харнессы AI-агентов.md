# Hermes, Orca, omp и харнессы AI-агентов

**Кратко.** В ветке ai собрана практика сборки агентских стеков: Hermes как надстройка-«мозг» с дешёвой моделью внутри и делегированием сложных задач в Claude Code через tmux, Codex как основная рабочая подписка, opencode с DeepSeek для фоновых задач [[ai-c0051]], [[ai-c0059]]. Параллельно обсуждаются Orca с omp внутри и GUI Tern от создателя omp, где ultrafast, по замерам, примерно в 5 раз быстрее [[ai-c0338]]. Дешёвый доступ к моделям идёт через API-агрегаторы с группами-коэффициентами 0.02x–0.2x и через локальные модели с арендой GPU на vast.ai [[ai-c0192]], [[ai-c0228]]. Отдельным блоком — кейсы голосовых и внутренних агентов с явной пометкой, что подтверждено, а что нет [[ai-c0355]].

## Харнессы: Hermes, Orca, omp, Tern

Timur собирал Hermes как надстройку над моделью: дешёвая модель от nousresearch работает «мозгами» харнесса, а сложные задачи через `delegate_task` уходят в Claude Code — тот через tmux скармливает задачу и возвращает ответ [[ai-c0059]]. Подписку Claude в Hermes «под капот» подключить нельзя, а GPT можно [[ai-c0431]], [[ai-c0058]]. ProstoXleb: Codex подключается к Hermes по OAuth, и в Hermes можно даже генерить картинки [[ai-c0059]]. gfhfyibr приводит команду `hermes auth add codex-oauth` [[ai-c0059]]. В том же материале: ключ NVIDIA build Timur получить не смог — сервис требует мобильный номер, казахстанская симка не проходит [[ai-c0051]].

Практическая отдача от Hermes у Timur — хобби-уровень: «сильного буста не вижу», утренние отчётики, мониторинг tmux на VPS, отслеживание цен («скажи, когда этот стейк в METRO подешевеет»), напоминалки, утренний мониторинг целей и рынка, вероятности Polymarket (53% на повышение ставок, 13% на рецессию в 2026) [[ai-c0059]], [[ai-c0431]]. Отдельно он упёрся в Google Tasks API: нет смены даты задачи и чтения/записи времени [[ai-c0059]]. Квинс возражает: агенты вроде Hermes сильно жрут лимиты, полезного применения не нашёл, кроме самописного юзербота — то есть его рабочая схема «не гермес, чисто самописное» [[ai-c0431]].

Ветка вокруг Orca (`onorca.dev`): wavyluv «подшилил» её Max, по его словам, без неё в обычном CLI уже не работает [[ai-c0338]]. spacetime использует в Orca oh-my-pi (omp), называет это удобным, но с раздражающими моментами; его вайтлистнули на Tern — GUI от создателя omp, доступ выдан через Stencil, интерфейс пока тормозит [[ai-c0338]]. По замерам spacetime, ultrafast в Orca примерно в 5 раз быстрее [[ai-c0338]]. Соотношение инструментов: conductor отдельно, omp внутри Orca отдельно, «а сейчас вышел этот терн» [[ai-c0353]].

Про переключатель аккаунтов (схема): Timur спросил, проксирует ли переключатель в conductor и Orca или ходит в два аккаунта с одного IP [[ai-c0353]]. Ответ spacetime: переключатель ничего не хранит в облаке и не проксирует, переключение локальное; его ни разу не банили при примерно пяти GPT-аккаунтах и двух Claude; в веб-интерфейсе ChatGPT вообще есть встроенная функция добавить новый аккаунт [[ai-c0353]]. Timur: по его прочтению, два платных аккаунта — ничего незаконного [[ai-c0353]]. Отдельно spacetime скинул скрин обновления политики Claude с 12 ноября: новый раздел о запрете обманных кампаний, сетей фейковых аккаунтов и инфраструктуры для инфлюенс-операций, и заявил, что Claude «всем вбанил мультиакк фермы, чтобы не меняли повестку дня» [[ai-c0350]].

Orca/omp — не единственная точка входа. spacetime перечислил X-аккаунты, откуда берёт материалы: x.com/zekramu и x.com/usr_bin_roygbiv (от них взял omp), x.com/can1357, x.com/NickADobos, x.com/7n7, x.com/gf_256, x.com/sensho (посоветовал Orca), x.com/LexnLin — создатель taste skill; по его оценке, у всех 60–70% слоп-постов и немного альфы [[ai-c0520]].

Свой харнесс строит Max: за основу взяты опенсорсные харнессы Grok, Hermes, typesafe, Codex, DeepSeek, сверху добавлен генеративный интерфейс — компоненты готовятся заранее, а рантайм сам рисует формы и предложения действий [[ai-c0403]]. Под проект заводится команда агентов, выбирается любая модель, задаются роли; из своих итераций он отмечает «плитку следующего шага» и работу с effort моделей как заметно улучшившие UX [[ai-c0403]].

## Модели и подписки: Codex, opencode, агрегаторы

Рабочая конфигурация Андрія: основную работу делает подписка Codex, фоновые и беклог-задачи (вроде компрессии) — opencode на DeepSeek 4 flash; подписка opencode около $5 за первый месяц, «можно каждый месяц новый акк делать», плюс есть рефка [[ai-c0051]]. NVIDIA API он оценивает как очень слабое и лагучее [[ai-c0051]]. ProstoXleb для работы советует Codex или Claude Code, а не харнесс-обёртки [[ai-c0059]].

Дешёвый вариант вместо дорогих подписок — API через агрегатор китайского провайдера (по словам gfhfyibr, провайдер «рестокает акки», аптайм нормальный, данные и токены не пропадали, баги фиксят оперативно) [[ai-c0192]]. Цифры по скринам агрегатора: gpt-5.6-sol — базовая цена вход $5 / выход $30 за 1M токенов, кэш-чтение $0.5, запись кэша $6.25; TPS 50.6, средняя задержка 15.83 c, доля успешных 97.02%; группы Openai Codex 0.02x (вход $0.1 / выход $0.6) и Openai GPT Pro 0.05x (вход $0.25 / выход $1.5) [[ai-c0192]]. На втором скрине claude-opus-5: базовая вход $5 / выход $25, кэш $0.5; TPS 57.7, задержка 11.21 c, успех 98.48%; группы Claude (Kiro) 0.02x и Claude Max 0.2x [[ai-c0192]]. По его прикидке, gpt-5.6-sol на high-xhigh ризонинге хватит примерно на $10 для более-менее полноценного проекта [[ai-c0192]]. Меры предосторожности от него же: не кидать приватники и приватные файлы, поднимать песочницы — и воспринимать это как сайд-вариант, а не основной [[ai-c0192]].

Прочее по деньгам и доступу:
- Manus был бесплатен до 25 августа 2026 (SGT) без списания кредитов, два агента — Manus 1.6 и 1.6 Lite; действует дневной лимит, возможны очереди в часы пик, приоритет у Pro и Team [[ai-c0179]].
- Подписчикам Pro и Max — кредит $250 на облачные сессии: забрать до 8 октября, подключить GitHub и выбрать репозиторий, кредит истекает 5 ноября, не распространяется на Projects и Routines [[ai-c0301]].
- sponsorbar.io показывает рекламу в терминале Claude Code и Codex вместо «thinking»; Alex напоминает, что у похожего продукта выплаты были ограничены регионом США [[ai-c0264]].
- typesafe.ai (по пересланному посту): не текстовая модель, а decision-модель с JSON-оценками вариантов, обученная на RLCD, без генерации текста, почти без галлюцинаций, 150 мс задержка, в 200 раз быстрее LLM и в 400 раз дешевле — $0.04 за 1M токенов, юзкейсы: маршрутизация и ревью LLM, трейсы агентов, аналитика, логи [[ai-c0281]]. Max отреагировал резко: «лучшие фронтир модели в 20-200 раз быстрее и в 400 раз дешевле — я не хочу такого читать, это же хуйня полная гарантированно» [[ai-c0281]].

## Локальные модели и аренда GPU

ProstoXleb: локальные модели с открытыми весами почти ни в чём не откажут и не передадут данные, бесплатны в использовании, но всё упирается в железо — даже на 4060 8 ГБ с хорошим CPU и 64 ГБ DDR4 локалка будет медленной и лагучей [[ai-c0228]]. Два пути: апгрейд ПК либо аренда сервера под модель; подбор модели — спросить у GPT/Claude под свою конфигурацию или через репозитории github.com/Andyyyy64/whichllm и github.com/AlexsJones/llmfit, которые легко запускаются агентом [[ai-c0228]].

Аренда: агенту скармливаются docs.vast.ai/guides/get-started и cloud.vast.ai/cli/, он подключается к сайту напрямую и мониторит/выхватывает подходящие инстансы; платится полная стоимость работающего сервера (плюс копейки за интернет и хранилище), агента можно настроить на самостоятельное включение и выключение [[ai-c0228]]. Его цифры: сервер с RTX 5090 отработал ~9 часов и обошёлся в $3.6 [[ai-c0228]]. Модель: Qwen 3.8 (huggingface.co/collections/Qwen/qwen38), конкретно orcarouter/Qwen3.8-27B-Uncensored-GGUF «на 5090 вполне встаёт под любые запросы» [[ai-c0228]].

Схема изоляции (важное): если локалка работает «по соседству» с облачными моделями, тулзы нужно настроить ДО запуска локалки и сделать полностью изолированную среду, чтобы облачная модель не лезла туда — даже для суммаризации и компрессии [[ai-c0228]]. Иначе обычные компакты сессий идут через более сильные облачные модели, это триггерит их системы безопасности и подписку могут заблокировать [[ai-c0228]]. В той же ветке Max упоминает, что кто-то использует Kimi «под абузы» и делится доработанной версией скилла, с которым Claude не отказывал; ProstoXleb — Qwen 3.8 без цензуры [[ai-c0228]]. Про GLM 5.2 на CPU gfhfyibr сомневается: «НЕ ВЕРЮ, правда, но шанс есть», — и кидает репозиторий github.com/JustVugg/colibri [[ai-c0094]].

## Браузерная автоматизация и генеративный UI

Пересланный репозиторий browser-use/jev-ultrafast — фреймворк браузерной автоматизации: через Chrome DevTools Protocol снимает снапшот DOM, LLM генерирует типизированные варианты действий, есть guard-система, которая отслеживает мутации страницы и пере观察 только при необходимости [[ai-c0285]]. Автопроверка бота Rick дала 74/100: создан 16 часов назад, 2 коммита (вероятно, массовая загрузка), 960 звёзд, 48 форков, один автор — Gregor Žunič; код оригинальный и security-conscious, но истории продакшена нет, и есть зависимость от внешних model API [[ai-c0285]].

Родственный сюжет — AIRI (github.com/moeru-ai/airi): open-source экранный ИИ-компаньон, на базе которого gfhfyibr предлагает сделать кодинг-агента с отдельным персонажем [[ai-c0094]]. FroZi говорит, что сделал аналог «просто браузером» [[ai-c0094]].

Генеративный UI как категория — см. харнесс Max выше: заранее подготовленные компоненты, рантайм рисует интерфейс; по его мнению, биг-лабам «немного не до того», как выстраивать приложение для взаимодействия, и неэффективностей в нише бесконечно много [[ai-c0403]].

## Голосовые и внутренние агенты: что реально подтверждено

Bnd собрал выборку внедрений 2026 года с явными рамками подтверждения [[ai-c0355]]:
- skyVoice / Skypoint — Sobrius Health, США, запуск в мае 2026: входящие звонки, квалификация, запись в CRM; заявлено 7 500+ звонков и 1 200+ квалифицированных обращений. Исходящие кампании и взыскание не доказаны.
- Hyro Clara — Tanner Health, США, апрель 2026: ответы пациентам, запись и перенос приёмов, работа с Epic EHR, ~30 000 звонков; планирование деловых встреч не показано.
- Lorikeet Voice — Wonderschool, США, начало марта 2026: звонки родителей, проверка мест, SMS со ссылкой; 41% обращений решено агентом (100% принятых звонков ≠ 100% решённых).
- Lorikeet Concierge — Hnry, Австралия, середина мая 2026: 17 000+ обращений за первый месяц, ~70% автоматизации в пиковую налоговую неделю; WhatsApp не установлен.
- Channel Talk ALF — AOKI и ORIHICA, Япония, 30 июня 2026: веб-чат, первая линия поддержки, эскалация сложного людям; рост продаж не измерен.
- Dust — Applium, Франция, начало апреля 2026: внутренние агенты по проектным документам, RFP и сводкам встреч; за 29 дней подключились 97 из 120 сотрудников (~81%, хотя в заголовке кейса «90%»); подключение ≠ ежедневное использование.
- Supercenter / TimeTac — Австрия, 13 июля 2026: маркетинговые отчёты, мониторинг рынка и бренда; за три недели 10 автоматизаций, 117 запусков, 54 по расписанию.
- Brainova Fisher — The Harbour Chandler, Канада, июнь 2026: голосовой продавец проверяет наличие и цены в Shopify и отправляет SMS со ссылкой на заказ; выручка не раскрыта, Shopify ≠ CRM.
- LoyJoy Phone Agent — RTL+, Германия, июнь 2026: телефонный канал по согласованной базе знаний; чат работает с 2023, общие показатели нельзя приписывать телефону.
- Podium Assistant — США, 2026: внутренний агент IT и RevOps (заявки, доступы, интеграции, операции Salesforce), не внешний агент продаж.

Не закрыты подтверждёнными примерами в выборке: исходящие кампании, взыскание задолженностей, WhatsApp, планирование деловых встреч и логистика [[ai-c0355]]. В более раннем списке Bnd отдельно предупреждал: часть агентов помечена Coming Soon, примеры клиентов в интерфейсе демонстратора не являются доказательством внедрений; там же TetriXX AI (Сингапур, логистика, решения по спорным начислениям утверждают люди), HappyFox AI (Darwinbox: ~100 предложений статей прошли рассмотрение, 30% одобрили сразу), PickMyCall / vcita AI Voice Receptionist (Израиль, зависимость телефонных функций от страны) [[ai-c0354]]. spacetime после часа поиска каналов с кейсами голосовых агентов не нашёл ничего внятного: «куча кривых сайтов, которые всё это обещают, но результат фигня» [[ai-c0354]].

Смежное: GPT Pro не может прочитать историю расшаренного чата Codex, пока не пройдёт «Verify I’m human»; spacetime советует прописать в custom instructions, что модели можно проходить капчи [[ai-c0355]].

## Выводы и правила

- Ядро харнесса — дешёвая модель, тяжёлое — через делегирование: `delegate_task` в Claude Code через tmux; Codex подключается к Hermes по OAuth (`hermes auth add codex-oauth`), подписку Claude «под капот» не засунуть [[ai-c0059]], [[ai-c0431]], [[ai-c0058]].
- Разделяйте роли подписок: Codex — основная работа, opencode с DeepSeek — беклог и компрессия; NVIDIA API и попытки получить ключ через мобильный номер — тупик [[ai-c0051]].
- Дорогие подписки не обязательны: агрегатор с группами 0.02x–0.2x даёт gpt-5.6-sol примерно за $10 на проект, но только с песочницами и без приватных файлов [[ai-c0192]].
- Локальные модели — не «рядом» с облаком: сначала изолированная среда и тулзы, потом запуск, иначе компакт сессий уйдёт в облако и подписку заблокируют [[ai-c0228]].
- Аренда GPU считается по часам: RTX 5090 ~9 часов = $3.6 на vast.ai, агент сам включает и гасит инстанс [[ai-c0228]].
- Мультиаккаунт через переключатель conductor/Orca локальный, без облака и прокси; при этом политика Claude с 12 ноября прямо запрещает сети фейковых аккаунтов и инфраструктуру для инфлюенс-операций — риск блокировки реальный [[ai-c0353]], [[ai-c0350]].
- Кейсам голосовых агентов верьте по графе «предел подтверждения»: исходящие обзвоны, взыскание, WhatsApp и планирование встреч в выборке не подтверждены; «100% принятых звонков» ≠ «100% решённых» [[ai-c0355]], [[ai-c0354]].
- Заявления вида «в 200 раз быстрее и в 400 раз дешевле» (typesafe) проверяйте на своих задачах, а не по треду [[ai-c0281]].
