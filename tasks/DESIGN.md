# Дизайн-гайд MXW (обязателен для задач 019–023)

Пользователь: участник крипто-комьюнити, не разработчик. Сайт должен быть понятен с первого взгляда: никаких внутренних кодов, id и англоязычного жаргона в интерфейсе.

## Структура
Образец всего сайта — **веб-интерфейс Claude (claude.ai) в браузере**: спокойный, много воздуха, главное — чат.
- **Левая боковая панель** (260px, как в claude.ai; сворачивается кнопкой ☰ в узкую полосу 56px, на ширине < 900px — выезжает поверх): сверху «MXW · база знаний»; кнопка «✏ Новый чат» (акцентная обводка); пункты разделов: 💬 Чат · 🗺 Карта · 📅 Активности · 👥 Люди · 📈 Темы · 📚 Статьи; ниже заголовок «Недавние» и список прошлых чатов (по первому вопросу, обрезка в 1 строку, hover — фон; меню ⋯ «Удалить»); внизу панели: «🙈 Скрыть ники» (стример-мод, текст меняется на «👁 Показать ники») и мелко «срез чата: <дата последнего сообщения>».
- Отдельной верхней шапки нет (как в claude.ai): заголовок текущего раздела — вверху основной области.
- **Основная область** — текущий раздел. Роутинг через hash: `#/chat`, `#/map`, `#/events`, `#/people`, `#/topics`, `#/articles`; открытый разговор/статья — параметр `?conv=…` / `?article=…`, чтобы ссылка открывала то же состояние. Кнопка «назад» браузера работает.
- **Правая выезжающая панель** (drawer, 640px, на узких экранах — на всю ширину) — разговор или карточка человека поверх раздела (как панель артефакта в claude.ai); закрытие ✕ / Esc / клик мимо. Панель не перекрывает левую боковую панель.

## Обновление 2026-11-21 (редизайн)
- Иконки — только линейные SVG из `js/icons.js` (`icon(name, size)`, в статической разметке `<span data-ic="name">`), никаких эмодзи в интерфейсе. Пустые состояния — `.e-ic` с иконкой.
- Акцент `#e5397b` — точечно: кружок «Новый чат», кнопка отправки, фокус, активный пункт оглавления. Активный сегмент `.seg` и пункт меню — нейтральный приподнятый фон, не розовый.
- Поле поиска — `.field` (иконка `.f-ic` слева, кнопка `.f-x` справа внутри рамки). `<select>` — свой chevron, высота 40px.
- Статья — отдельная страница `#/articles?article=…` (колонка 720px, оглавление справа, ссылки на разговоры — надстрочные номера `sup.srcs .src`, внизу «Источники»). Разговор поверх статьи — drawer, `?article=` сохраняется в адресе.
- Разговор: заголовок + чипы-мета, карточки «Кратко»/«Схема», ссылки `(#10635)` → `.mref`, сообщения с аватаром `avHtml()` (учитывает стример-мод), подряд идущие сообщения автора в 5 мин — `.cont`.
- Телефон (< 900px): верхняя панель `#mtop` (меню, название раздела, новый чат), меню выезжает слева, ленты чипов прокручиваются горизонтально, нет горизонтального скролла страницы.

## Тексты и подписи
- Разговор везде показывается не по id, а **заголовком**: первое предложение выжимки (до ~90 символов, обрезать по слову, «…»), под ним мелко: дата · ветка · категория (точка цвета категории + название) · «N сообщений». Id (`nft-c0083-01`) — только в «⋯ подробнее» для копирования.
- Оценки разметки: `keep` → «⭐ ценное», `partial` — без метки. Мусорные разговоры (drop) в интерфейсе не показываются вообще.
- Типы схем по-русски: multiaccount «Мультиаккаунты», antisybil «Антисибил», farms «Фермы», accounts «Аккаунты», bots_soft «Боты и софт», kyc_verification «KYC», proxy_antidetect «Прокси и антидетект», bans_risks «Баны и риски».
- Ветки — человеческими названиями из `topics.title`, не slug/short.
- Теги (`#abstract`) — не показывать сырыми списками; максимум 3 чипа без «#».
- Даты: «14 авг 2026», время «22:53»; относительные «вчера» не нужны.

## Стример-мод
Одна функция псевдонима (FNV-1a → «Участник XXX»), применяется ко всем местам вывода автора, во всех разделах, в т.ч. в чате (на сервере `anon:true`). Тексты сообщений/выжимок не меняются.

## Код
- Фронтенд — не один огромный файл: `app/web/index.html`, `app/web/style.css`, `app/web/js/*.js` (ES-модули: `api.js` — единственное место, где фронт получает данные; `ui.js` — общие компоненты: карточка разговора, drawer, чипы, псевдонимы, форматирование дат; по модулю на раздел). Библиотеки (d3, force-graph, marked) — локально в `app/web/lib/` (скачать один раз), без CDN.
- `api.js` имеет два режима: **сервер** (fetch к `/api/...`) и **автономный** (данные из `window.MXW_DATA`, чат/эмбеддинги — напрямую к API из настроек пользователя). Режим определяется наличием `window.MXW_DATA`. Разделы не знают, в каком режиме работают. Это нужно, чтобы архив для создателя собирался из этих же файлов (задача 023).
- Старый `app/index.html` не удалять до задачи 023 — сервер отдаёт новый фронт на `/`, старый — на `/old`.
- Проверка каждой задачи: `node --check` для всех js; скриншоты headless Edge (1440×900) нужных экранов в `data/ui_<раздел>.png` — НЕ открывать PNG инструментом Read (сессия падает); вместо этого `--dump-dom` и поиск ошибок в консоли (`--enable-logging=stderr --v=0`, искать `Uncaught`/`Error`).
