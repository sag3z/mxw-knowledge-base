# Задача: запустить и довести factcheck.py v2 на пилоте из 10 статей

Не читай `.llm_env`/`.openrouter_key`, не читай `tasks/*.log`, НЕ открывай PNG. Статьи в `vault/` не менять. Меняй только `factcheck.py` (и вспомогательные скрипты в `tasks/`).

Контекст: `factcheck.py` проверяет верность статей базы (`vault/`) исходным сообщениям (`data/kb.sqlite`). Версия 2 уже написана по `tasks/018_factcheck_v2.md` (прочитай его — там требования: поиск настоящего источника при неверной ссылке → вердикт `wrong_citation`; полные расшифровки до 4000 символов; судья `qwen3.8-max`, второе мнение `glm-5.3`; пачки по 25 утверждений; общий семафор на 3 параллельных запроса), но ни разу не была прогнана до конца — провайдер обрывал сессии. Результаты v1 лежат в `backup/factcheck_v1/*.json` (для сравнения), текущие `data/factcheck/*.json` — частично v1, частично битые.

## Сделать
1. Прочитай `factcheck.py`, убедись, что требования 018 реализованы; допиши недостающее. Быстрая проверка на одной маленькой статье: `python factcheck.py "<путь к самой короткой статье пилота>" --force`.
2. Устойчивость к провайдеру: любая ошибка LLM-вызова (таймаут, 429/5xx, обрыв, пустой ответ, невалидный JSON после ремонта) — повтор с паузой (до 4 раз), затем раздел помечается `error` и проверка идёт дальше (не падать всей статьёй). Каждая статья сохраняется сразу по готовности (resume работает).
3. Полный прогон пилота: `python factcheck.py --pilot --force` — запускай **отвязанно** (например `Start-Process -WindowStyle Hidden python -ArgumentList 'factcheck.py','--pilot','--force' -RedirectStandardOutput data/factcheck_run.log -RedirectStandardError data/factcheck_err.log` из папки проекта), потому что прогон может идти дольше твоей сессии. Следи раз в 2 минуты до 45 минут; если не закончился — опиши в отчёте прогресс (сколько json готово, среднее время на статью по логу).
4. По готовым статьям — `data/factcheck/report.md` и в отчёте сессии таблица: статья | утверждений | supported % | partial | unsupported | contradicted | wrong_citation | disputed | время | вызовов; сравнение с v1 по общим статьям; 6 показательных находок (утверждение, вердикт, цитата из источника, для wrong_citation — правильный источник).
