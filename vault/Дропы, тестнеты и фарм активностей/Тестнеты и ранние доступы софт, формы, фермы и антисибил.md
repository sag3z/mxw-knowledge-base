# Тестнеты и ранние доступы: софт, формы, фермы и антисибил

Кратко: с 23 июля по 27 октября 2026 в чате прошла серия тестнетов и вейтлистов — Sekai, Fairground (Forte), Skew, The Pit, Trysoar, Checkpoint, Axis Robotics/BitRobot. Основной поставщик автоматизации — sprintray: Python + Playwright софт под Sekai, бот под Fairground, авторег под WL по почтам и «Soft Hub» с обновлением 1.5.5 и улучшенным антисибил-бэкендом. FroZi зашёл в Axis Robotics через инвайт, выполнял задания BitRobot и позже показал дроп AXIS (~$961–1876 на кошельке). Отдельным блоком — схемы мультиаккаунтов: облачные телефоны Geelark под Base App с PayMaster, «-PnL» аккаунты MEXC и минты NFT через Binance Agentic Wallet.

## Sekai: софт на Python + Playwright

sprintray спросил, кто крутит тестнеты Sekai или Fairground, и сразу выложил свой софт под Sekai — репозиторий `github.com/spr1ntray/sekai_testnet`, проект в X: `x.com/sekai_fi` [[crypto-c0146]].

Инструкция запуска из его сообщения: `python -m venv .venv` → `source .venv/bin/activate` → `pip install -r requirements.txt` → `playwright install chromium` → `python main.py`. По его словам, крутит софт почти с первого дня тестнета и ни один аккаунт не «отлетел»; количество аккаунтов не указано [[crypto-c0146]].

## Fairground (закрытый тестнет Forte)

sprintray: закрытый тестнет от Forte (`x.com/ForteProtocol`) — Fairground (`fairground.fi`), туда можно податься в WL. Механика: набиваешь объёмы — получаешь XP. Для тех, у кого есть доступ, выложен бот автоматизации активности: `github.com/spr1ntray/fairground-testnet-bot` [[crypto-c0153]].

Оценки проекта разошлись. sprintray сам называет его «сомнительным»: один пивот из GameFi, тогда собрали почти $1B и «нихуя толком не сделали», но команда большая — по его пониманию, от 100 до 300 человек, есть опыт билдинга; вывод — можно зайти и крутить поинты бесплатно, терять нечего [[crypto-c0153]]. FroZi скептичен: по нему проект переобувался трижды (игровая платформа, ИИ, перпы), при этом собран ~$1B; тестнет пофармить бесплатно можно, но ему нужно во что-то верить, чтобы крутить поинты [[crypto-c0153]]. То есть sprintray говорит об одном пивоте, FroZi — о трёх.

## Axis Robotics и BitRobot: задания, статусы, дроп

25 июля FroZi кинул инвайт в хаб Axis Robotics (`hub.axisrobotics.ai`) — «замутит себе бейджи», по его словам, анонс инвестиций ожидался в понедельник–среду [[crypto-c0151]].

26 июля — практика по заданиям BitRobot внутри платформы Axis Robotics: интерфейс «BitRobot Tasks | 322 tasks | Dual Reward». Задания — телеуправление роботом-манипулятором, Mobile Bimanual: «Pick up the Ginger / Garlic / Asparagus», «Put the Ginger / Garlic / Sardine on the Plate». Сложность ★–★★, время 5 min, у заданий виден прогресс: 485/1200, 495/1200, 630/1200, 663/1200, 581/1200 [[life-c0240]].

Организационные детали от FroZi: «нам в ХАБ», в хабе код не нужен, нужна роль в Discord (для «партнёрской зоны» код не требуется) [[life-c0240]]. В History задания висят со статусом Pending и пустым TX HASH (примеры: «Put the Tape behind the Plate», «Put the Carrot on the Plate»); его трактовка — они на апруве, клеймить можно будет после апрува [[life-c0240]]. По его же словам, участники уже выполнили около 10к заданий, и он думал, «как бы клодом автоматизировать эту руку» [[life-c0240]].

21 октября — результат. FroZi: попал в сейл через второй аккаунт; на кошельке $961.09, из них AXIS 2 949.8213 по $0.3189 (−0.74%), «и еще столько же должно прийти» [[crypto-c0347]]. «Вот вся сумма. Но это без сейла» — на втором скрине $1 876.39, AXIS 5 449.8213 по $0.3432 (+6.84%); с сейла ещё +$100, из них 50% в локе. Друг за неделю забрал $100 [[crypto-c0347]]. Max был скептичен насчёт отработки заданий ради дропа — в ветке это отмечено как спор [[crypto-c0347]].

## Мультиаккаунты: «-PnL» на MEXC и подтверждение WL

12 августа Kam Kamich спросил про суть схемы с «-PnL» аккаунтами на MEXC. Ответ Max Wayld: акки откручивают разную «хуйню», вокруг куча краймов; минусовые старые прогретые аккаунты не банятся сразу, с них можно вывести, а дефолтные улетают. Сам он таких софтов не видел и не крутил — «суть там такая» [[life-c0339]]. huraveq добавил: многим дают нулевую комиссию, типы откручивают объёмы, но в последнее время много негатива — «мекс таки начал ебать» (то есть банить) [[life-c0339]].

Там же по вейтлистам: для подтверждения 100k токенов нужен снэпшот и внесение кошельков в вайтлист, потом минт через сайт проекта (С.Rollins) [[life-c0339]]. Альтернатива от void: если не под флип — зайти на DexScreener и купить через Uniswap [[life-c0339]]. Bnd пожаловался, что на многие сервисы отдаёт 404 (скрин стандартной страницы ошибки), и попросил добавить Kimi в тезисы по ИИ-сервисам — «амеры выёбываются, я стал юзать кими и это неплохо» [[life-c0339]].

## Base App: облачные телефоны + PayMaster (по пересланному посту)

Bnd переслал (Hermes Ledger, 12.08.2026 18:39) гайд по дешёвому накруту пользователей в приложку на Base App — схема помечена автором как high-risk, без гарантий [[ai-c0178]].

Механика по тексту поста:
- В приложение подключается PayMaster (настройка через ИИ), выбираются типы транзакций, которые делает полностью бесплатными — газ на каждый кошелёк в Base депать не нужно. Оплата с карты: у автора около $2 каждые 2–3 недели; первые 2–3 недели можно гонять бесплатно [[ai-c0178]].
- Покупается подписка + минуты Geelark: минимальный стек 30 профилей и 2000 минут — около $30 [[ai-c0178]].
- На каждом устройстве регистрируются аккаунты Base App и обязательно ставится basename — без него бесплатные транзы не пройдут даже с PayMaster [[ai-c0178]].
- Оптимум — 2–3 кошелька на устройство (basename забирается везде), итого с 30 облачных телефонов 60–90 кошельков, «для топа уже достаточно». Сам Base App допускает до 10 кошельков на устройство — «если вы хай риск, то делайте ради бога» [[ai-c0178]].
- Тайминги: топ Base обновляется в 23:00 каждую среду, снэпшот — в 00:00 каждую субботу [[ai-c0178]].
- Обстановка: большой дамп по юзерам у всех, сокращение аппок — около 5к активных, больше половины сами себе крутят. Проверять аппку по физам и транзам советуют на Dune; статистика на Base.dev «работает очень криво и виснет» [[ai-c0178]].
- Скрин лидерборда «Popular Apps»: Clash of Coins 2,657 WTUs, PlanetIX 1,902, Aerodrome 666, Rips 482, Based GM 293, Dustswap 283, Base Runner 250, 2048 on Base 247; у автора Sea Battle (`seabattle.top`) на 24-м месте [[ai-c0178]]. В посте также есть промик на ProxyWing — код не переносим.

## Binance Agentic Wallet: минты NFT по $10–20 (по пересланному посту)

Kapitoshich переслал пост из канала «Секретный» (27.10.2026 19:45) — «новый движ для лоубанков»: создать Agentic Wallet от Binance, пополнить на пару баксов газа, минтить NFT и продавать по $10–20 [[crypto-c0361]].

Кейсы за неделю по тексту поста: `ptah.trade/mint` — NFT по $15, давало минтить 4 штуки; можно было продать, а можно скупить до 10 NFT и превратить их в Loom, добывающие токен PTAH. `nonceprotocol.xyz/mint` — минт х2, флор $10 [[crypto-c0361]].

Инструкция из поста: открыть Binance → вкладка Wallet на главной → баннер с Agent Id (если нет: над балансом My wallet → Add wallet → Create agentic wallet) → ввести тег агента → включить Developer Mode в настройках → открыть LLM с поддержкой MCP (Hermes/Grok/Codex и др.) и скормить команду `npx skills add binance/binance-skills-hub --skill binance-agentic-wallet` → после установки попросить агента залогиниться и перейти по выданной ссылке с телефона для линковки [[crypto-c0361]].

Список актуальных минт-страниц из поста (штук 5 автор отсеял как уже заминченные): `blackhole-nft.pages.dev`, `seed.mchain.art` (можно минтить и с обычного кошелька), `agentbnbai.com/#mint`, `otv-nft.surge.sh/#collection`, `pixel-shiba-club.pages.dev`, `behandbots.surge.sh/#home`, `build-100.com/lab/`, `cf36074bcaad480b.flypod.page/`, `snack.is-a.si/`, `noirbrokers.netlify.app/` [[crypto-c0361]]. Оговорки автора: риски дрейна не анализировал — «твиттера почти везде помойные», вайбкоженные лендинги; но кошелёк советует создать даже без фарма этих «копеек», так как могут появиться пирамидки, игры и протоколы. Отдельно: при наличии фермы Binance (например с альфы) и эмуляторов — «вообще фри кэш» [[crypto-c0361]].

## Выводы и правила

- Тестнет-софт от sprintray публикуется открыто в GitHub: Sekai (`sekai_testnet`), Fairground (`fairground-testnet-bot`), авторег The Pit (`the_pit_wl`). Запуск стандартный: venv → requirements → `playwright install chromium` → `python main.py` [[crypto-c0146]] [[crypto-c0153]] [[crypto-c0150]].
- Централизованный апдейтер — его Soft Hub: чтобы получить патчи (в т.ч. под Trysoar), достаточно ввести ник `spr1ntray` в радар; актуальная версия на 11.08 — 1.5.5 с улучшенным антисибил-бэкендом [[crypto-c0206]] [[crypto-c0205]].
- Для доступа к тестнетам сначала закрывается вейтлист: Fairground — WL по заявке, Skew — форма раннего доступа с последующей подвязкой кошелька по коду из письма, The Pit и Trysoar — WL по почтам [[crypto-c0153]] [[crypto-c0148]] [[crypto-c0205]] [[crypto-c0150]] [[crypto-c0206]].
- Checkpoint на старте — ручная активность: софта под OTC-обмен оффчейн-поинтов до TGE не было [[crypto-c0157]].
- В Axis Robotics вход через хаб и роль в Discord, код партнёрки не нужен; задания BitRobot висят в Pending без TX hash и, по предположению FroZi, клеймятся после апрува — ожидание дропа стоит закладывать [[life-c0240]].
- По Axis Robotics ориентир по выхлопу: ~$100 за неделю у знакомого FroZi, дроп без сейла около $100, с сейла ещё +$100 при локе 50%; при этом часть чата (Max) считает отработку заданий нецелесообразной [[crypto-c0347]].
- Схема Base App требует basename на каждом кошельке — без него бесплатные транзы через PayMaster не работают; масштаб — 2–3 кошелька на облачный профиль, лимит платформы до 10 [[ai-c0178]].
- Схема «-PnL» на MEXC: работают только старые прогретые минусовые аккаунты, дефолтные банятся; сам источник этих софтов в чате не подтвердил и не крутил их [[life-c0339]].
- Agentic Wallet от Binance — отдельный низкопороговый канал: газ на пару долларов, продажа минтов по $10–20, но с явным риском дрейна и без аудита лендингов [[crypto-c0361]].
