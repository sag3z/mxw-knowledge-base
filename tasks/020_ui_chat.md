# Задача: единый чат с ИИ — главная страница (поиск + чат + база знаний в одном)

Сначала прочитай `tasks/DESIGN.md`. Каркас `app/web/` сделан в задаче 019 — продолжай в нём (`js/chat.js` + правки `api.js`, `ui.js`, `style.css`, `app/server.py`). Не читай `.llm_env`/`.openrouter_key`, не читай `tasks/*.log`, НЕ открывай PNG.

Сейчас отдельно существуют: поиск (`/api/search` — гибрид смысл+слова, фильтры, сниппеты), чат (`POST /api/chat` — SSE: meta → delta → done, переформулировка, pin, anon, повторы при 429), статьи (`/api/articles`). Пользователь хочет **одно** окно: спрашиваешь как угодно → ИИ ищет по смыслу в разговорах и статьях и отвечает.

## Образец — чат Claude в браузере (claude.ai)
Чат должен выглядеть и вестись как обычный веб-чат с Claude:
- колонка переписки по центру, макс. ширина 760px; сообщение пользователя — в мягком пузыре (приподнятая поверхность, скругление 16px), выровнено вправо, ширина по содержимому до 85%; ответ ИИ — **без пузыря**, обычный текст на фоне страницы, слева, с маленькой иконкой-аватаром «MXW» перед первым абзацем; хорошая типографика markdown (заголовки, списки, жирный, код, таблицы, отступы между абзацами);
- поле ввода внизу — большой закруглённый контейнер (скругление 20px, поверхность, граница, тень), внутри многострочное поле и справа круглая кнопка отправки ↑ (неактивна при пустом поле; во время ответа превращается в ■ «остановить»); под контейнером мелко серым: «ИИ отвечает по материалам чата MXW и может ошибаться — проверяй источники»;
- в пустом чате — приветствие по центру крупно («Что найти в чате MXW?») и поле ввода под ним по центру (как стартовый экран claude.ai), примеры-чипы под полем;
- источники — **компактно, как цитаты/поиск в Claude**: над ответом свёрнутая строка «🔎 Нашлось в базе: 6 источников ▸» (по клику раскрывается список); в тексте — маленькие номер-чипы `[1]`, при наведении на чип — всплывающая карточка источника (заголовок, дата, ветка, сниппет), клик — drawer;
- список чатов — в левой боковой панели («Недавние»), как в claude.ai; «✏ Новый чат» там же;
- появление ответа — потоком, с мягким курсором в конце, автопрокрутка вниз (если пользователь не прокрутил вверх).
Ниже описанное — функциональные требования; где они расходятся с видом claude.ai по оформлению — выбирай вид claude.ai.

## Экран `#/chat`
- **Пустое состояние**: по центру крупное поле «Спроси что угодно о чате MXW…» (автовысота, Enter — отправить, Shift+Enter — перенос), под ним 6 примеров-вопросов чипами (например: «Что сейчас можно заминтить на Robinhood Chain?», «Как не словить бан Claude из РФ?», «Какие антидетекты советовали для мультиаккаунтов?», «Что было с клеймом Ethereal?», «Кто разбирается в минт-ботах?», «Какие проекты оказались скамом?»), ниже три ссылки-карточки: «📅 Что активно сейчас», «👥 Кто в чём разбирается», «📚 Все статьи».
- **Диалог**: лента — вопрос пользователя справа (пузырь), ответ слева на всю ширину колонки (макс. 760px, по центру). Поле ввода прилипает к низу.
- Для каждого ответа:
  1. Сразу (до ответа модели, ~1–3 с) — блок «Нашлось в базе»: 4–6 карточек источников горизонтально (прокрутка) или сеткой: тип (💬 разговор / 📄 статья), заголовок (для разговора — первое предложение выжимки), дата/ветка, 1 строка сниппета с подсветкой. Клик → drawer. «Показать все (N)» раскрывает полный список с фильтрами (период, ветка, категория, «только схемы») — это и есть бывший поиск.
  2. Ответ модели — потоком, markdown; ссылки на источники в тексте — **сноски-номера** `[1]`, `[2]` (маленькие кликабельные чипы), соответствующие карточкам источников (нумерация по порядку первого упоминания; карточки упомянутых источников получают тот же номер). Ссылки `[[…]]` из модели, которых нет в источниках, — убрать.
  3. Под ответом: «👍/👎» не нужны; кнопки «Скопировать», «Повторить».
  4. Пока модель думает — статус «Ищу в базе…» → «Пишу ответ…», при повторах — «Провайдер занят, повторяю (n/5)…».
- **История**: список прошлых чатов — в левой боковой панели в блоке «Недавние» (см. DESIGN.md), хранение в `localStorage` (до 30), удаление через ⋯.
- **Контекст**: если пришли с `?pin=<разговор или статья>` — плашка над полем «Вопрос про: <заголовок> ✕», запрос уходит с `pin`.
- **Уточнения**: маленькая кнопка «⚙ Уточнить» у поля — период (всё / 7 / 30 / 90 дней), ветка, «только схемы»; выбранные — чипами над полем.
- Стример-мод: `anon:true` в запросе; в карточках источников — псевдонимы.

## Сервер
- `POST /api/chat`: в событии `meta` отдавай источники уже в формате для карточек: `{n, kind:"conv"|"article", id|path, title, date, branch, category, snippet}` — `title` для разговора = первое предложение summary (≤90 симв, по слову), для статьи — название. Нумерацию `n` присвоить по рангу; в материале модели использовать `[n]` вместо `[[id]]` и попросить модель ссылаться только `[n]` (поменяй CHAT_SYS соответственно) — фронту так проще и текст чище.
- **Люди в ответах**: если вопрос про людей («кто…», «кого спросить», «кто разбирается», «к кому») или просто всегда — добавь в материал блок «Эксперты по найденным темам»: по категориям/типам схем найденных разговоров — топ-3 из `expert_topics` (kind category/scheme) с профилем из `experts.profile` и числом ключевых сообщений; при anon — псевдонимы. Модель может ответить «по этой теме чаще всего по делу писали: …».
- `GET /api/search` оставить (для «Показать все»), добавить в результаты поле `title` так же.
- Если LLM недоступен — источники всё равно показываются, вместо ответа: «ИИ сейчас недоступен — вот что нашлось в базе».
