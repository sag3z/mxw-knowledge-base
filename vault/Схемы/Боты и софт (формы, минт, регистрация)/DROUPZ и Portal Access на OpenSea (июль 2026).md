## Софт: Chrome-расширение для трекинга минтов OpenSea

5 августа wdnad переслал пост из канала «M - Drops | Аирдропы тебя ждут» (03.08.2026 00:44) о бесплатном расширении для Chrome [[nft-c0227]].

Суть: у OpenSea есть страница активности в реальном времени (продажи, минты в разных сетях) — быстро прокручивающийся поток, вручную отслеживать минтящиеся сейчас коллекции неудобно; расширение фильтрует этот поток и отсекает мусор [[nft-c0227]].

Заявленный кейс автора: минт стоил 0,0001 ETH ($0,19), «x62» — это 0,0062 ETH ($11,75); заголовок «изи x62» автор прямо называет пародией на кричащие каналы [[nft-c0227]]. По его словам, на кошелёк можно было взять максимум 10 штук, но он взял одну и «это не точно» [[nft-c0227]].

Установка (по пересланному посту) [[nft-c0227]]:

1. На GitHub нажать зелёную кнопку «Code» → «Download ZIP», распаковать архив;
2. Открыть `chrome://extensions/`, справа вверху включить режим разработчика;
3. Слева вверху «Загрузить распакованное расширение» → выбрать папку с распакованными файлами;
4. Расширение включится само и появится в списке;
5. Открыть `https://opensea.io/activity?activityTypes=mint&markets=opensea` и выставить фильтры.

Рекомендованные фильтры: «window 60 min», «min mints 1» и галочка «has any offer» — отслеживание всех минтов на OpenSea с показом только коллекций, где есть офферы, что «сразу отсечёт 90% мусорных коллекций» [[nft-c0227]]. Способ проверки безопасности: скопировать код, вставить в любую ИИ, спросить, работает ли он и нет ли вредоносного кода [[nft-c0227]]. Детали — в описании на GitHub [[nft-c0227]].

Реакция чата: Max Wayld и wdnad отнеслись к таким инструментам как к недолговечным (по выжимке обсуждения) [[nft-c0227]]. Max отдельно: Twitter забит подборками коллекций, у которых по 3–30 подписчиков — «даже не могут потратить 30 рублей на накрутку, а уже делают коллекцию» [[nft-c0227]]. FroZi сказал, что спарсил Twitter и ищет API, wdnad посоветовал взять готовую заготовку [[nft-c0227]]. Для проверки участники называли Moni — чекер через бота [[nft-c0227]].

## Выводы и правила

- Условия минта DROUPZ фиксированы и проверяемы: 27 июля, OpenSea, 4 269 штук, 0,0015 ETH, максимум 2 на кошелёк — считать расход как 0,003 ETH на кошелёк плюс газ [[nft-c0166]].
- Право на Portal Access определяется наличием в кошельке NFT из 23 выбранных коллекций или участием в коллаб-кампаниях — список коллекций надо получить до минта, из отдельного поста проекта [[nft-c0166]].
- Форма WL без даты и с суплаем «3333» — красный флаг: её абузят, ориентироваться на неё как на гарантию доступа нельзя [[nft-c0166]].
- Для трекинга минтов: фильтры «window 60 min» + «min mints 1» + «has any offer» режут основную массу мусора [[nft-c0227]].
- Расширение ставится в режиме разработчика из ZIP; перед установкой прогонять код через ИИ на вредоносные вставки — рекомендация самого автора [[nft-c0227]].
- Иксы на таких минтах считать в ETH, а не в процентах: 0,0001 → 0,0062 ETH это $0,19 → $11,75, а не «x62 в деньгах» [[nft-c0227]].
- События по контрактам (пример MonkeyHood: `upgradesPaused` True → False) ждать подтверждающим сигналом об обновлении контракта, а не реагировать на первый алерт [[nft-c0227]].
