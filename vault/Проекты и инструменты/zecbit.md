# ZecBit

**Что это:** Проект/платформа в экосистеме Zcash (домены zecbit.io и zecbit.net): фриминт NFT-коллекции через форму заявок, позже — мост для заводки ZEC (zecbit.net/bridge) и размещение других коллекций (Cyphersquad).

## Что говорили в чате

- 2026-09-01: Max Wayld обсуждал zecbit.io — по его словам, код сгенерировал Claude и прошёл 5+ аудитов; сам кошельком не заходил, собирался тестировать только при получении WL. Отметил форму на фриминт и 51 смену никнейма; по его мнению, проект хочет не выдать WL и понадеяться на паблик. Bnd отметил 700к просмотров поста о проекте; glimjke — что NFT проекта на аватарке, по слухам, даёт гарант FCFS. [[nft-c0377]]
- 2026-09-01: Фриминт на 3333 supply намечен на 3 сентября; у ZecBit нет дедупликации заявок — ledger нельзя удалять, таймаут нельзя переотправлять, статус pending — их очередь модерации. Для формы написан бот (один POST на заявку: адрес, X-хендл, цитата, ответ). [[soft-c0009]]
- 2026-09-02: Софт ZecBit генерирует хендлы; в него загружают только свои прокси и адреса кошельков, без приватников. [[life-c0475]]

## Итог

Zcash-проект с фриминтом (3 сентября 2026, 3333 supply), который WL фактически не выдал, рассчитывая на паблик. По пересказанному в чате разбору, при покупке нет подтверждения владения NFT, средства уходят в тестовую сеть, а стандарт токена отсутствует в мейннете — признаки высокого риска скама. Позже домен использовался как мост и площадка для новых коллекций; участники взаимодействовали с ним с осторожностью.
