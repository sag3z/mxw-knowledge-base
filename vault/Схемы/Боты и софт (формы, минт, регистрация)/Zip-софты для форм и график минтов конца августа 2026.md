# Zip-софты для абуза форм и график минтов конца августа 2026

Кратко
28 августа 2026 года в ветке nft обсуждали zip-софты для абуза форм: по словам С.Rollins, коллекции на Base, Arbitrum, Ink и Hyperliquid росли именно потому, что таких zip-файлов на рынке не было [[nft-c0360-02]]. Max Wayld заявил, что делает и выкладывает такие софты пачками — «сегодня ещё штук 10 zip файлов заебашу», с розыгрышем в канале [[nft-c0360-02]]. Он же выдал расписание минтов на 28.08: GTD на Cashmere через ~30 минут, Sherwood через 2.5 часа, FroZi (never-fucking-trade) через 4 часа [[nft-c0360-02]]. Параллельно обсуждали условия вайтлистов (Kredoos, формы, регистрация пустых аккаунтов), проверку WL через OpenSea API и DDoS сайта проекта перед минтом [[nft-c0360-04]].

## Почему росли сети: дефицит zip-софтов

С.Rollins (переслано им же, 28.08.2026 12:44) сформулировал причину роста коллекций: «На бейзе, на арб, на инк, на хайпере — везде росли, потому что как раз вот таких zip файлов не было» [[nft-c0360-02]]. То есть всплеск активности в этих сетях участник объясняет не качеством проектов, а отсутствием готового инструмента для массового абуза форм — как только софт появляется, картина меняется [[nft-c0360-02]].

## Производство софтов: темпы и раздача

- Max Wayld (12:45): «Я сегодня ещё штук 10 zip файлов заебашу» — то есть несколько zip-софтов в день [[nft-c0360-02]].
- По схеме разговора, часть этих софтов он собирается разыграть в канале [[nft-c0360-02]].
- Позже в тот же день (17:47): «Софт щас доделываю» — речь о софте под формы Kredoos [[nft-c0360-04]].
- Требования к пользователю минимальные: по словам Max, нужны только прокси и кошельки, всё остальное софт делает автоматически [[nft-c0360-02]].

## Механика zip-софта для форм

Инструкция, которую Max прописывает в readme (17:02):

1. Загрузить кошельки в софт — либо дать ИИ-агенту сделать это самому [[nft-c0360-04]].
2. Выбрать кошелёк, с которого будет идти дисперс (раздача средств на остальные) [[nft-c0360-04]].
3. Вставить ссылку на страницу коллекции OpenSea — контракт софт вытащит сам [[nft-c0360-04]].

Проверка вайтлиста делается отдельно: по API OpenSea, когда у коллекции появится страница на OS. На профильный софт для этого Max дал ссылку в чате — https://t.me/c/3957383989/35323/35339 [[nft-c0360-04]].

Про прокси: по словам Max, на каждый аккаунт — один прокси, а при ретраях прокси берутся из общего пула [[nft-c0360-04]].

## Как выдавали вайтлисты: формы и «пустые аккаунты»

По словам Max, вайтлист на одну из коллекций выдавали по форме и регистрации на платформе проекта, а GTD — по форме и регистрации пустого аккаунта с ником на их платформе [[nft-c0360-02]].

Kredoos: сразу после открытия (17:47) Max написал, что «пиздят, что вайтлисты только первым 477» в форме — информация подана как слух, ссылки проекта: https://kredoos.com/game и https://x.com/kredoosdotcom [[nft-c0360-04]]. Он же подтвердил, что доделывает софт под эти формы [[nft-c0360-04]].

Отдельно Max упомянул, что FroZi предлагал принимать кошельки для раздачи вайтлистов [[nft-c0360-04]].
