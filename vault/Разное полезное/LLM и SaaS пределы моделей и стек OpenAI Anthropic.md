# LLM и SaaS: пределы моделей и стек OpenAI/Anthropic

## Кратко
Пересланное в чат эссе фиксирует простую мысль: современные модели («Астра», Sol 6.1, Opus 5.5, Fable) ваншотят почти всё, что им дают, но человек быстро нащупывает задачи, которые в одном контексте не решаются, а новые модели выходят быстрее, чем заканчиваются такие задачи [[ai-c0376]]. Второй материал — утечка/сборка стека OpenAI и Anthropic по кейсам вендоров, вакансиям и trust-центрам: у обеих лабораторий внутри обычный энтерпрайз (Salesforce, Workday, NetSuite/Oracle Fusion, Stripe, Zip) [[ai-c0468]]. Главный вывод автора разбора для SaaS: быть системой учёта, брать на себя юридическую ответственность, давать нормальный API и MCP и уходить от оплаты за места к оплате за результат [[ai-c0468]]. Отдельно в ветке — практика по мультиаккаунтам ChatGPT/Claude: работает, но «на свой страх и риск» [[ai-c0376]].

## Пределы одного промпта: замкнутый круг запроса
Max переслал эссе (автор — Msvcp60dll, 16.10.2026 14:20:55) с лестницей деградации ожиданий [[ai-c0376]]:
- сначала модели «ваншотят» задачи;
- потом находятся задачи, которые «рендерятся» за 3 запроса;
- потом — задачи на 1–2 дня «нормальной мозгоебли»;
- сейчас есть несколько задач, которые не решаются вообще — не про «тайны мироздания», а про набор «злоебучих параметров», которые текущим моделям вместе в одном контексте не даются [[ai-c0376]].

Из этого — прогноз: пока такие задачи удаётся нащупывать, новые модели будут выходить раз в две недели [[ai-c0376]].

Ключевой тезис эссе (пересказ рассуждения «кента из долины» с YouTube): человек технически не заметит момента, когда LLM станет во всём умнее, потому что LLM сама ничего не делает и выдаёт только то, что у неё попросили, а запрос ограничен способностями человека. Разомкнуть круг может только «раздача моделям самосознания», чтобы они сами запрашивали инференс под собственные нужды; до этого человек получает лишь то, что и сам был бы способен сделать, но быстрее [[ai-c0376]].

## Почему не «завайбкодили» своё: пять затыков
По мнению автора разбора (переслано Max) [[ai-c0468]]:
1. **Это системы учёта.** Зарплата, налоги, выручка — ошибка стоит дороже любой лицензии; аудитор хочет видеть Workday и NetSuite, а не «наш агент посчитал».
2. **Compliance вшит в продукт.** Payroll в десятках стран, SOC 2, налоговые правила — годы и юристы, а не код.
3. **Сетевой эффект.** Slack, Stripe, Salesforce ценны тем, что к ним уже подключено всё остальное.
4. **Фокус.** Инженер в лабе — самый дорогой ресурс на рынке, тратить его на свою CRM «ну такое».
5. **Данные.** Годы истории, миграция страшнее подписки.

## Где ИИ уже заменяет «слой над процессом»
Заменяется не учёт, а надстройка: координация интервью, заметки с собеседований, первая линия поддержки, ресёрч лидов, документация. Стоящие там продукты — Fin, BrightHire, Clay, Mintlify — «уже новое поколение — ИИ-агенты внутри SaaS» [[ai-c0468]].

## Правила защиты для SaaS
Сформулированы автором разбора [[ai-c0468]]:
- **Быть системой учёта, а не интерфейсом.** Кто хранит «истину» (деньги, люди, контракты) — живёт; кто красиво показывает чужие данные — на очереди.
- **Брать на себя ответственность:** сертификаты, гарантии, юридические риски. «ИИ код напишет, а подпись под аудитом не поставит».
- **Нормальный API и MCP.** Агенты будут работать через вас; удобный для агента инструмент не выкинут, им будут пользоваться чаще.
- **Уходить от оплаты за места к оплате за результат.** Людей-пользователей станет меньше, и seat-модель умрёт вместе с ними.
- **Встраивать ИИ самим**, как Intercom с Fin, иначе кто-то сделает это поверх вашего API и заберёт клиента. Жизнеспособность при этом держится на уникальных данных (например, от тысяч клиентов).

## Выводы и правила
1. Модель не вытянет задачу, которую человек не смог поставить: ограничение — не бенчмарк, а формулировка запроса [[ai-c0376]].
2. Если нашли задачу, не решаемую в одном контексте, — это не приговор, а индикатор, что следующее поколение моделей ещё будет иметь смысл [[ai-c0376]].
3. В стеке OpenAI/Anthropic нет «ИИ-замены» учёта: CRM, HR, финансы, закупки и платежи — сторонние системы [[ai-c0468]].
4. Строить защиту вокруг хранения истины (деньги, люди, контракты), а не вокруг интерфейса [[ai-c0468]].
5. Давать API + MCP и делать инструмент удобным для агента — агентный трафик придёт через вас [[ai-c0468]].
6. Менять биллинг с seat на результат [[ai-c0468]].
7. Мультиаккаунты в ChatGPT/Claude — рабочий, но рискованный обход: без прокси у знакомого работает, но возврата денег при блокировке нет; условия — стабильный IP и без «кучи стран» [[ai-c0376]].
