# Игры, SMM-накрутка и витрины прибыльных сделок

Кратко
В ветке life за 26–27 октября 2026 переслали две новости от ваншота: альфа-клиент Steam для PS5 (только на прошивке 13.60) и переписанный на Rust Minecraft с отдельным лаунчером Horizon [[life-c0737]] [[life-c0744]]. В nft-ветке 12 ноября обсудили низкий онлайн FeedFire и кинули чекер Unvault по адресу unvault.com/bugz [[nft-c0762]] [[nft-c0763]]. 13 ноября glimjke показал скрин SMM-панели из видео Харчевникова (50 000 единиц за 8 132 ₽), а Сёма связал такие накрутки с играми вроде FEED FIRE, которые, по его словам, делают около $500 в день на пассах [[life-c0847]]. Отдельно в shitki разобрали Telegram-канал RUSHER с карточками «прибыльных сделок» по мем-токенам как социальное доказательство для захода в бота [[shitki-c0051]].

## Steam на PS5 (пересланная новость, 26.10.2026)

- Клиент Steam вышел на PlayStation 5: запуск игр с ПК-аккаунта прямо на приставке. Работает **только на прошитых PS5** — на любой с прошивкой **13.60** [[life-c0737]].
- Клиент качается с GitHub, есть также версия для macOS; обе поддерживают режим Big Picture. Поддерживаются и клавиатура с мышью, и геймпад [[life-c0737]].
- Проект в альфе, но его активно допиливают и добавляют поддержку новых игр [[life-c0737]].
- На скриншоте из пересланного поста — сетка библиотеки: 557 игр всего, 26 установлено, 2 в избранном, оранжевой рамкой выделена Hades II со статусом «Not installed»; в списке PONY ISLAND, CASTLE CRASHERS, THE TALOS PRINCIPLE, LUMINES REMASTERED, CYBERPUNK, WILD HEARTS, STRAY, BALL x PIT (508 MB), FINAL FANTASY VII REBIRTH, SATISFACTORY и др. [[life-c0737]]
- Формулировка «сумасшествие» и тезис «прошитых приставок всё больше» — из пересланного поста ваншота, не проверка [[life-c0737]]

## Minecraft, переписанный на Rust (пересланная новость, 27.10.2026)

- По пересланному посту ваншота, Minecraft полностью переписали на языке Rust. У версии **свой лаунчер Minecraft Horizon**, который «качается так же просто, как TLauncher»: обновления приходят автоматически, моды публикуются на сайте проекта [[life-c0744]].
- Аргумент авторов: глобальные моды (в пример приводят «атомные бомбы») лагали и плохо работали из-за особенностей Java; на Rust работают лучше, а на ванильном Майне «почти нереально» сделать то, что возможно на Rust [[life-c0744]].
- Сравнение «Rust новее и легче Java, которая уже не вывозит моддинг» — оценочное утверждение из пересланного поста [[life-c0744]].
- Мод из видео лежит на GitHub, клиент скачивается по ссылкам из поста; в приложенном ролике — кинематографичный ядерный взрыв в Minecraft (кольцо с молниями, луч, грибовидное облако, кратер с лавой), без речи и интерфейсов [[life-c0744]].

## FeedFire и Unvault (nft, 12.11.2026)

- glimjke про FeedFire: «вообще очень крутая, но по поводу онлайна, мне кажется это из за того что кроме рыбалки там нет особо активности которой можно заниматься долгое время» — то есть претензия к удержанию, а не к качеству [[nft-c0762]].
- Kapitoshich скинул чекер Unvault: `https://www.unvault.com/bugz` [[nft-c0763]].
- По выжимке ветки, участники отмечают, что проект Unvault идёт месяцами [[nft-c0763]].

## SMM-панель и накрутка (life, 13.11.2026)

glimjke показал кадр из YouTube-ролика Харчевникова «Как накрученные каналы зарабатывают по 30млн ₽?» (1,5 млн подписчиков, 822 тыс. просмотров, 2 недели назад, 16 тыс. лайков / 309 дизлайков) с интерфейсом сервиса накрутки [[life-c0847]]:

- **Заказ**: количество **50 000** (мин. 100, макс. 3 000 000), цена **8 132 ₽**, кнопка «Создать заказ», старт **0–6 часов**, интервальная подача выключена, поле промокода [[life-c0847]].
- **ID услуги 2993**, индикатор «Скорость — Быстро», избранное выключено; часть названий и статистики замазана [[life-c0847]].
- **Меню панели**: Новый заказ / Мои заказы / Массовый заказ / Бонус 3% / Профиль / API / Поддержка; сверху баланс 0 ₽, «Пополнить», скидка 0% [[life-c0847]].
- Реакция в чате: «ахахахха твибуст» — то есть панель опознали как сервис накрутки [[life-c0847]].
- Сёма: «Как накрученные игры по типу feed fire зарабатывают по 500$ в день на пассах» — **по словам Сёмы**, цифра ничем не подтверждена в чате; связка «накрученные каналы → накрученные игровые проекты → доход с пассов» здесь только заявлена [[life-c0847]].

## Витрина «прибыльных сделок» RUSHCULT (shitki, 29.10.2026)

- В чат скинули скрин Telegram-канала **RUSHER** (3 050 подписчиков, закреп #2, «WHO'S RUSHER?») с карточками сделок по мем-токенам под одним ником **ruslan001** [[shitki-c0051]]:
  - $PEPETEEN: +255%, start 0.50 SOL → end 1.78 SOL, time 21m 19s [[shitki-c0051]]
  - $TROLLCRAFT: +121%, 0.61 SOL → 1.34 SOL, 10m 00s [[shitki-c0051]]
  - $SWORDBULL +142%, $NIGHTERGUY +51%, $WIF +62% [[shitki-c0051]]
- Подпись в канале: «Ребята из сообщества продолжают „фарм" фермеров 😄👨‍🌾», кнопки вступления ведут в бота **@RUSHCULT_bot** и сам канал — карточки работают как социальное доказательство для набора подписчиков [[shitki-c0051]].
- tylist про канал: «если кто то знает админа этого говна - дайте знать пж❤️» — то есть в чате восприняли это как скам-рекламу [[shitki-c0051]].
- По выжимке ветки, Max отметил, что такое постится в больших публичных чатах [[shitki-c0051]].

## Выводы и правила

- Steam-клиент для PS5 — только для прошитых приставок (13.60), альфа с GitHub; macOS-версия есть, Big Picture и геймпад поддерживаются [[life-c0737]].
- Minecraft на Rust — ставить только через официальный лаунчер Horizon и сайт проекта; моды — с GitHub-ссылки из поста, а не из сторонних сборок [[life-c0744]].
- Заявленный прайс накрутки для калибровки: 50 000 единиц ≈ 8 132 ₽ на конкретной панели (ID услуги 2993), старт 0–6 ч, API и бонус 3% [[life-c0847]].
- Тезис «накрученные игры делают $500/день на пассах» — слова одного участника чата, не цифра из отчётности; для базы помечать как непроверенное [[life-c0847]].
- Карточки сделок в каналах типа RUSHER (один ник ruslan001 на все «успехи», ссылка на бота) — типовой шаблон соцдоказательства, а не подтверждение результата [[shitki-c0051]].
- По играм смотреть на удержание, а не на хайп: у FeedFire претензия ровно в том, что кроме рыбалки нет долгих активностей [[nft-c0762]]; чекер Unvault — unvault.com/bugz [[nft-c0763]].
