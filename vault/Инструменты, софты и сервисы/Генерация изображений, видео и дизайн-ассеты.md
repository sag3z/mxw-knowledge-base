# Генерация изображений, видео и дизайн-ассеты: Higgsfield, Nano Banana, Pixellab, ComfyUI и запуск AI-продуктов

Кратко: в чате собрали рабочий набор для визуала — промо Higgsfield с 21 моделью безлимитом на сутки, Nano Banana для картинок, Pixellab для пиксель-анимаций и Tripo3D для 3D, fal.ai как дешёвый API-провайдер с промокодом на кредиты. Параллельно — список дизайн-референсов от Max, библиотека анимаций Originkit и скилл FroZi для canvas-анимаций. Отдельным блоком — 62 площадки для продвижения B2B AI SaaS и GitHub-репозитории SEO-скиллов. Ниже — механика каждого сервиса, ограничения и противоречия между участниками.

## Higgsfield: безлимит на 21 модель за $0 (и автопродление)

Сёма переслал корейский промо-пост: при новой регистрации в Higgsfield даётся 24 часа безлимита на 21 модель — Nano Banana, Kling 3.0, Seedance 2.0 и другие — по тарифу «$0 за пробный день». Механика по шагам из поста и скрина-инфографики: зарегистрироваться → зайти на страницу тарифов → найти продукт «TRY ALL TOP MODELS UNLIMITED FOR $0» → нажать «Get FREE trial for $0» [[ai-c0128]].

Список моделей в аккаунте (скрин, период Jul 21 – Jul 23, 2026, статус Active): Nano Banana Pro, Nano Banana 2, Nano Banana, GPT Image 2, GPT Image, Seedream 5.0 Pro, Seedream 5.0 Lite, Seedream 4.5, Higgsfield Soul 2.0, FLUX.2 Pro, Kling O1 Image, Kling v3.0, Kling 3.0 Motion Control, Seedance 2.0 Draft test, Seedance 2.0 Mini, Gemini Omni Flash, Wan 2.7, Text to Speech V2, Mileio Text to Audio, ImworX Text to Speech, Seed Audio 1.0 [[ai-c0128]].

Главный подвох: по окончании суток тариф автоматически продлевается в Higgsfield Plus monthly — на скрине ₩99 970 в месяц с 23.07.2026 (переключатель KRW/USD, курс 1 USD = 1 540,3645 KRW). Отменять автопродление надо сразу после подписки: Manage Account → Subscription → отмена. Досрочная отмена не срезает сам безлимит — 24 часа остаются [[ai-c0128]].

Расхождения по условиям: Сёма настаивает, что «была кнопка безлимитный день за 0$», FroZi видит акцию «за 40 баксов 7 дней безлимита» [[ai-c0129]]. По опыту Сёмы, видеогенерация в сервисе слабая — «я даже кино не смог сделать нормальное», а вот Nano Banana для фоток «вроде топ» [[ai-c0129]].

## Изображения и видео: degenai, Grok, ComfyUI на арендованном GPU

На degenai.art генерация на «GPT 2 в 2K» у Max падала с ошибкой «Generation failed. Please try again later» и кнопкой Retry; FroZi привёл текст ошибки целиком: «The input or output was flagged as sensitive. Please try again with different inputs» [[ai-c0168]]. Причина, по его словам, — ограничения OpenAI на интеллектуальную собственность. Обходная схема: генерировать концепцию на GPT, а переводить в нужный стиль (покемоны, Гарри Поттер, Губка Боб) через Nano Banana [[ai-c0168]].

Grok, по жалобе Руслана, выдаёт однотипные картинки (маяк, рынок, осенние листья), а видео по референсу не получается. Bnd: для картинок лучше Nano Banana, а результат зависит от промпта — референсы брать через Pinterest [[ai-c0521]]. gfhfyibr предложил другой путь: арендовать GPU (например 5090 на Vast), этого достаточно для инференса, а сверху подключить агента/обвязку, который подберёт ComfyUI-сборку и сервер по цене [[ai-c0521]].

Отдельно про детект: Timur обнаружил, что его видео определяется как ИИ по метке SynthID — первый кадр для дублей он генерировал через ChatGPT [[ai-c0399]].

## Пиксель-арт, 3D, озвучка и монтаж

Max: для пиксельных персонажей и анимаций — pixellab.ai, для полноценных 3D-моделей — tripo3d.ai. Astra анимации персонажей не делает, Fable тем более. Для идеальных анимаций в Pixellab персонажа лучше брать максимум 128x128. На Tripo можно делать модельки до 20 млн полигонов, в том числе под 3D-печать [[ai-c0288]].

Сравнение с Aseprite + Codex по видео: видны плывущие текстуры и края, понятно, что картинка сделана ИИ, причём это ещё и самая лёгкая idle-позиция. Через Pixellab, по словам Max, такого не видно — «анимации ебанутые получаются» [[ai-c0289]].

Timur добавил свой набор: fish audio — для озвучки; sosana.art — дешёвая генерация изображений, gpt-image-2.5 примерно $0,0145 за генерацию; hyperframes + Claude Code — для монтажа и векторной графики в видео [[ai-c0288]].

FroZi обновил собственный скилл для Claude: агент теперь сам ищет картинки и вставляет их в hand-drawn canvas-анимацию. Репозиторий: github.com/alesha-pro/tools/tree/main/skills/hand-drawn-canvas-animation [[ai-c0292]].

## fal.ai: API-кредиты, промокод и минимальный депозит

Пересланный пост (от densharik): на fal.ai можно получить «самые настоящие 100$ на апи нейронок». Промокод найден в другом чате — «chroma-fal», активируется через Add credits → Redeem code в биллинге (fal.ai/dashboard/usage-billing/credits). На скрине: план Pay as you go, баланс $116,25, расход за месяц $2,50 ($0,12 в день). Оговорка автора: если сервисом раньше не пользовались, без баланса может не работать — надо что-то закинуть [[ai-c0395]].

ImmuneFOMO описывает fal.ai как замену runpod с минимальным депозитом $10 [[ai-c0398]]. В HN-треде обсуждали OpenAI Dots — агентов, утилизирующих простаивающие мощности; по словам spacetime, Dots на Plus и в Европе пока недоступен. Комментарий ImmuneFOMO: «прикольная мысль про то что это хуйня удобная для утилизации простоев» [[ai-c0398]].

## Выводы и правила

- Higgsfield: подписался на $0-триал — сразу отмени автопродление в Manage Account → Subscription; 24 часа безлимита при этом сохраняются, иначе спишется Plus monthly (₩99 970/мес по курсу на 23.07.2026) [[ai-c0128]]. Условия у участников разошлись ($0/сутки против $40/7 дней) — проверяй, что показывает твоя страница тарифов [[ai-c0129]].
- Видео в Higgsfield — слабое место по опыту Сёмы; картинки через Nano Banana — сильное [[ai-c0129]].
- Упёрся в «sensitive input» на GPT-моделях — генерируй концепт там, а стиль (покемоны, Гарри Поттер, Губка Боб) переноси через Nano Banana [[ai-c0168]].
- Пиксель-анимации: Pixellab, спрайт не больше 128x128; 3D — Tripo3D (до 20 млн полигонов); озвучка — fish audio; дешёвые картинки — sosana.art (~$0,0145 за gpt-image-2.5); монтаж — hyperframes + Claude Code [[ai-c0288]].
- Aseprite + Codex дают плывущие текстуры и края даже на idle; для чистых анимаций — Pixellab [[ai-c0289]].
- fal.ai: сначала Redeem code (промокод «chroma-fal») в биллинге, минимальный депозит $10, без баланса сервис может не работать [[ai-c0395]] [[ai-c0398]].
- Нет GPU — арендуй 5090 на Vast и подключи агента, который подберёт ComfyUI-сборку и сервер по цене [[ai-c0521]].
- Старт AI-SaaS без бюджета: прогнать продукт по 62 площадкам (лаунчи → AI- и SaaS-каталоги → Product Hunt/HN/Reddit → Habr/vc.ru/dev.to) и подключить SEO-скиллы из GitHub; на контент-площадках ставить canonical на свой сайт [[ai-c0407]].
