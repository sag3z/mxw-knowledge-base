# Дашборд MXW, реферальная монетизация и внешние программы

**Кратко**

Сайт-дашборд MXW держится на 400 проектах и 400 инструментах со ссылками, а зарабатывает, по словам Макса (Max Wayld 福), только на рефералках — порядка пары тысяч долларов в месяц, платных продуктов на сайте нет [[life-c0376]]. Официальный аккаунт Base в X ответил на претензию «почему только билдеры», что скоро будет creator program; участники чата ждут аналога кампании на платформе dub и сомневаются в размере выплат [[crypto-c0209]]. По итогам разговора с командой Unvault FroZi сообщил, что проекту дадут API для трекинга eligible-кошельков «как в OpenSea», и попросил чат скинуть ботов-трекеров для своего Discord [[nft-c0444]]. В Telegram-боте MXWMainBot есть личная реф-ссылка и счётчик приглашённых — на скрине FroZi 71 реферал [[life-c0287]].

## Дашборд MXW: масштаб и монетизация

- На сайте «под 400 проектов и 400 тулзов», все — со ссылками [[life-c0376]].
- Рефки стоят «далеко не везде», но их «прям немало» [[life-c0376]].
- Платной инфраструктуры нет: доход идёт «только рефералки, там же нет платной хуйни ни одной» [[life-c0376]].
- Текущая оценка дохода — «в районе паре тысяч баксов в месяц» [[life-c0376]].
- Позиция Макса: сайт изначально делался не под монетизацию, но «на таком дешборде будет очевидно очень тупо не использовать рефки» [[life-c0376]].

Вопрос о монетизации задал Bnd, отдельно отметив ценность схемы «100500 созданных сайтов на вайбкоде, которые дают траффик» [[life-c0376]].

## Base creator program

12 августа 2026 в ветке crypto переслали скрин твит-цепочки: юзер OnChain Memer спрашивает у официального аккаунта Base, «Why only builder why not the community?», на что Base отвечает «we have a creator program coming soon» (118 лайков, 25 репостов на момент скрина) — по пересланному скрину [[crypto-c0209]].

Реакция чата:
- mirnow предполагает, что у Base будет «своя кампания для создателей контента, чист прикл», и ждёт аналога кампании на платформе dub — «как с поликом» (Polygon), но непонятно, за какие действия будут платить [[crypto-c0209]].
- Max Wayld 福 скептичен: «С 5$ выплатами?» [[crypto-c0209]].
- mirnow допускает, что «что-то придумают интересное» [[crypto-c0209]].

Итог обсуждения: параметры программы (размер выплат, перечень действий) на момент разговора неизвестны [[crypto-c0209]].

## Unvault: API для трекинга eligible

По словам FroZi (после разговора с командой Unvault, 11 сентября 2026):
- Unvault назвали MXW «ахуенная дапка» [[nft-c0444]].
- Обещают дать API, чтобы «мы как в опенси могли трекать где элигбл» — по аналогии с OpenSea [[nft-c0444]].
- По выжимке обсуждения: возможен совместный пост, но пока без официального партнёрства [[nft-c0444]].

Параллельно FroZi запросил у чата «ботов которые трекают» кошельки и алерты — с целью поднять такие трекеры в собственном Discord, включая трекер кошелька крипто-царя [[nft-c0444]]. Конкретных названий ботов в материале нет — запрос остался открытым [[nft-c0444]].

## Реферальная механика в MXWMainBot

- В боте есть меню с личной пригласительной ссылкой и счётчиком рефералов: у FroZi на скрине 17407 — «Приглашено: 71» [[life-c0287]].
- Ссылка имеет формат `https://t.me/MXWMainBot?start=ref_…` с персональным ID (код не приводим) [[life-c0287]].
- FroZi попросил Макса сделать ссылку моноширинной (скрин 17406), чтобы её можно было копировать тапом [[life-c0287]].

## Выводы и правила

- Монетизация дашборда MXW — только реферальные ссылки, без платных функций; ориентир дохода — около $2 тыс./мес. при 400 проектах и 400 инструментах [[life-c0376]].
- Рефки вставляются не везде, а только там, где они есть у проекта; приоритет — покрытие новых проектов и тулзов [[life-c0376]].
- Base creator program — пока только анонс в X; не планировать под неё бюджет или выплаты до публикации условий (выплаты, список действий) [[crypto-c0209]].
- Интеграция с Unvault: ждать API для проверки eligible и вернуться к вопросу совместного поста; официального партнёрства на 11.09.2026 нет [[nft-c0444]].
- Для Discord MXW нужны внешние боты-трекеры кошельков и алертов — задача открыта, конкретика от участников не поступила [[nft-c0444]].
- В боте MXWMainBot вести учёт приглашённых через личный счётчик (пример: 71 реферал) и запросить моноширинное отображение ссылки для удобного копирования [[life-c0287]].
