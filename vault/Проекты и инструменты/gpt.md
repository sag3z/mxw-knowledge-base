# GPT

**Что это:** ИИ-модель/провайдер, доступная по подписке и API-ключу, которую в комьюнити используют как рабочую лошадку: для продолжения задач после других моделей, генерации визуала, автореплаев в X и как движок для агентов; из РФ требует VPN.

## Итог

GPT — дефолтный провайдер в чате: лимиты сбрасываются почти ежедневно, подписка подключается к агентам вроде Hermes, модель используют для ботов и визуала. Риски: доступ из РФ только через VPN со сменой страны, а с октября 2026 участники жалуются на выдачу сжатых квантов вместо полной модели; бесплатные промо-API — только старые версии.
