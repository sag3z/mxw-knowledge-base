## Chrome-расширение для трекинга минтов OpenSea

Пересланный пост (автор — M - Drops, 03.08.2026 00:44, запостил wdnad) описывает расширение под Google Chrome, которое фильтрует страницу активности OpenSea: штатный поток минтов прокручивается вручную и отследить, какие коллекции минтятся прямо сейчас, неудобно [[nft-c0227]].

- **Экономика примера:** минт стоил 0,0001 ETH ($0,19), «x62» — это 0,0062 ETH ($11,75); автор сам пишет, что заголовок про «изи x62» — пародия на каналы с кричащими заголовками [[nft-c0227]].
- **Лимит на кошелёк:** «вроде можно было максимум 10 штук на кошелёк взять, но это не точно» — автор взял одну [[nft-c0227]].
- **Установка:** на GitHub зелёная кнопка «Code» → «Download ZIP», распаковать; открыть `chrome://extensions/`, включить режим разработчика; «Загрузить распакованное расширение» → выбрать папку; расширение появится в списке [[nft-c0227]].
- **Настройка фильтров:** открыть `https://opensea.io/activity?activityTypes=mint&markets=opensea` и выставить «window 60 min», «min mints 1», галочку «has any offer» — по словам автора, так отсекается около 90% мусорных коллекций, остаются только те, где есть офферы [[nft-c0227]].
- **Проверка кода:** автор предлагает не верить на слово, а скопировать код, вставить «в любую ИИшку» и спросить, работает ли он и нет ли вредоносного кода, и только потом устанавливать [[nft-c0227]].

## Выводы и правила

1. Для трекинга минтов OpenSea ставить связку фильтров «window 60 min» + «min mints 1» + «has any offer» — это отсекает основную массу мусора [[nft-c0227]].
2. Любое скачанное расширение прогонять через ИИ-проверку кода перед установкой в Chrome [[nft-c0227]].
3. Ориентир по «x»-доходности: считать в ETH, а не в процентах — 0,0001 → 0,0062 ETH это $0,19 → $11,75 [[nft-c0227]].
4. Лимит минта на кошелёк проверять до минта: в примере автора он «вроде 10», фактически взята 1 штука [[nft-c0227]].
5. По контракту MonkeyHood: `upgradesPaused = False` — только первый сигнал; ждать подтверждения обновления контракта перед апгрейдами и слиянием [[nft-c0227]].
6. Галка на OpenSea привязана к объёму: порог — больше 25 ETH по словам FrostY [[nft-c0227]].
7. Парсер подборок писать не с нуля: wdnad советует брать готовую заготовку, FroZi при этом уже спарсил Twitter и искал API [[nft-c0227]].
