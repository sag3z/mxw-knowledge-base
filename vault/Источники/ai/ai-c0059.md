OAuth для входа в сервис Например "Sign in with OpenAI/ChatGPT". Это просто авторизация аккаунта, но не даёт Hermes право бесплатно использовать твои ChatGPT-лимиты. 2. OAuth для ChatGPT Apps / Connectors Это когда ChatGPT подключается к внешнему сервису. Это обратная сторона: не Hermes подключается к ChatGPT, а ChatGPT подключает сторонний сервис. Для Hermes обычно варианты такие: • OpenAI API key Работает, но оплачивается отдельно. • Ollama / локальная модель Бесплатно, но слабее по качеству. • Другой провайдер с OAuth, если Hermes его поддерживает Но это уже не твоя подписка ChatGPT. То есть если в Hermes есть кнопка OAuth/OpenAI login, можешь попробовать, но почти наверняка она не даст использовать подписку как API. Для полноценного подключения нужен API key. СУТЬ: Скриншот развёрнутого ответа из чата, где автор объясняет техническую разницу между двумя типами OAuth и почему подписка ChatGPT не даёт права бесплатно гонять модели через сторонний клиент Hermes.
