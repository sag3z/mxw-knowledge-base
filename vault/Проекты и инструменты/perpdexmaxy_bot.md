# perpdexmaxy_bot

**Что это:** Телеграм-бот (@PerpDexMaxy_bot) для трекинга фандинга на перпах: шлёт алерты по ликвидным парам, уведомляет, когда фандинг по открытой позиции становится отрицательным, позволяет контролировать свои позиции в личке. Разработчик — Макс из чата.

## Что говорили в чате

- 2026-06-24 — Бот обновлён: по словам Макса, алертов станет примерно вдвое меньше и только по самым ликвидным парам; добавлена сводка по фандингу раз в сутки; контроль собственных позиций доступен в личке с ботом. [[perps-c0004]]
- 2026-06-26 — Контекст использования: фарм фандинга на стабильных парах даёт 30–60% APR, с плечом x3–x5 капает доход; на волатильных монетах нужны большой банк и минимальное плечо. Спреды отслеживаются через uainvest, а @PerpDexMaxy_bot шлёт алерты, когда фандинг по открытой позиции становится отрицательным (для участников чата). [[perps-c0006]]
- 2026-06-28 — Проблема: бот перестаёт трекать позицию при 0% фандинга, из-за чего её приходится добавлять заново. Макс обещал в течение дня режим трекинга, работающий и при нулевом/отрицательном фандинге; функционал ещё не доделан, база данных уже работает. [[perps-c0008]]
- 2026-07-13 — Пользователи запросили кнопку, меняющую местами биржи для лонга и шорта; Макс ответил «добавлю». [[perps-c0012]]

## Итог

Полезный инструмент для фарма фандинга: алерты по отрицательному фандингу на открытых позициях и сводки по ликвидным парам. Статус — в активной разработке (по словам Макса, дорабатываются трекинг при нулевом/отрицательном фандинге и кнопка смены бирж), так что возможны сбои вроде отвала трекинга при 0% фандинга.
