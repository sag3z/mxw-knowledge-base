# Задача: доработка смысловой карты (после задачи 003)

Смысловой режим в `app/index.html` работает, но на скриншоте две проблемы. Меняй только `layout.py` и `app/index.html`. Не читай `.llm_env`/`.openrouter_key`. НЕ открывай PNG-файлы инструментом Read — модель не принимает картинки, это роняет сессию. Скриншот проверит ревьюер.

1. **Карта — узкая вертикальная полоса.** UMAP дал вытянутое облако, и при общей нормировке оно занимает ~1/4 ширины экрана. Сделай так, чтобы облако заполняло экран 16:10: в `layout.py` перед нормировкой поверни облако по главной оси (PCA через numpy: собственные векторы ковариации 2×2), чтобы длинная ось была горизонтальной; затем нормируй x в [-1600, 1600], y в [-1000, 1000] (независимо по осям). Пересчитай `clusters.x/y`. Названия кластеров берутся из кэша `data/cluster_names.json` — LLM при повторном запуске звать не должно (проверь, что кэш-ключ не зависит от координат; если зависит — сделай, чтобы не зависел, и не допускай повторных LLM-вызовов: если кэш не совпадает, напечатай предупреждение и спроси через флаг `--rename` разрешение, по умолчанию переиспользуй старые названия по номеру кластера k).

2. **Подписи кластеров налезают друг на друга.** В отрисовке подписей (onRenderFramePost / аналог) сделай жадное размещение без перекрытий: сортируй кластеры по размеру n (больше — приоритетнее), для каждой подписи считай прямоугольник в экранных координатах (`ctx.measureText`, высота шрифта), если пересекается с уже нарисованной — сдвинь вниз/вверх на высоту строки (до 2 попыток), иначе не рисуй. При приближении (zoom) места становится больше — скрытые подписи появляются сами, так как расчёт каждый кадр. Шрифт подписи: размер на экране ~12–13px независимо от зума (то есть `fontSize = 13 / globalScale`), жирный, тёмная полупрозрачная подложка.

3. Проверь, что в режиме «смысл» подсветка поиска и tooltip с названием кластера работают (прочитай код, исправь, если что-то не так), а режим «ветки» не сломан.
