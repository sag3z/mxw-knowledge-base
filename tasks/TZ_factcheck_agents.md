# ТЗ: доделать проверку фактов статей через параллельных агентов

Рабочая папка: `C:\Users\fl3xx\Desktop\mics\mxw-kb` (Windows, есть Git Bash и PowerShell, Python 3; запускай python с `PYTHONUTF8=1`).

## Контекст
База знаний MXW (Telegram-комьюнити: крипта, NFT, AI) → статьи Obsidian в `vault/`. Скрипт `factcheck.py` проверял статьи
через LLM, часть разделов упала с ошибкой. Эти разделы уже нарезаны на **пакеты** `data/fc_agents/in/NNNN.md`
(всего 1893, номера 0001–1893). Каждый пакет = кусок статьи + материал исходных разговоров.
Субагент читает пакет, выносит вердикты по утверждениям и пишет `data/fc_agents/out/NNNN.json`.
Сейчас готово 577, осталось **1316** пакетов (точные цифры — у factcheck_agents_status.py).

Инструкция для субагентов (формат ответа, вердикты, правила) — `data/fc_agents/AGENT_GUIDE.md`. Сам её прочитай, но НЕ меняй.

## Задача
1. Узнать, что осталось:
   `PYTHONUTF8=1 python factcheck_agents_status.py 15`
   Скрипт печатает задания: по строке на агента, ~15 пакетов в каждом, всего ~88 заданий.
   Битые out-файлы он покажет отдельно: удали их, они попадут в задания.
2. Раздать задания субагентам. **Держи одновременно 20 параллельных агентов (это максимум)**.
   Как только агент завершился, сразу запускай следующее задание, чтобы в работе всегда было 20. Запуск в фоне.
   Модель субагентов — самая дешёвая (Haiku или аналог): задача механическая.
3. Промпт каждому субагенту (подставь список номеров из строки задания):
   ```
   Рабочая папка: C:\Users\fl3xx\Desktop\mics\mxw-kb. Прочитай data/fc_agents/AGENT_GUIDE.md и выполни ровно по ней,
   сам, без других агентов. Твои пакеты: 0299,0319,0320,... (файлы data/fc_agents/in/NNNN.md).
   Результаты — data/fc_agents/out/NNNN.json. Ответ — одна строка «готово N из M».
   ```
   Давай список номерами через запятую, а не диапазоном: в диапазонах есть уже готовые пакеты.
4. Время от времени (например, после каждых 20 завершённых агентов) запускай
   `PYTHONUTF8=1 python factcheck_haiku_merge.py`.
   Он вливает готовые разделы в `data/factcheck/*.json` и пересобирает `data/factcheck/report.md`.
   Скрипт идемпотентный, частичные разделы не трогает.
5. Когда все задания отработали, снова запусти `factcheck_agents_status.py`. Недоделанное раздай повторно, до 2 кругов.
   Потом сделай финальный `factcheck_haiku_merge.py`.
6. Выборочный контроль качества: открой 5 случайных `out/*.json` и сверь с их `in/*.md`.
   - Цитаты (`quote`) должны реально быть в материале.
   - Вердикты должны быть разумными.
   - Если какой-то агент писал мусор (пустые claims, всё supported без цитат), удали его файлы и переделай.

## Если API падает
- **Ошибки rate limit / overloaded:** не перезапускай сразу все 20. Подожди, потом поднимай параллельность постепенно.
- **Ошибка аккаунта (verification_required, 403):** остановись и скажи пользователю. Это не лечится ретраями.
- Агент, который упал на середине, мог записать часть файлов. Это нормально: при повторе он пропустит готовые.

## Запрещено
- Читать, выводить или передавать агентам `.llm_env`, `.openrouter_key`, любые ключи и credentials.
- Менять `vault/`, `data/kb.sqlite`, `data/fc_agents/in/`, `AGENT_GUIDE.md`, `index.json`, код проекта.
  Писать можно только в `data/fc_agents/out/`; скрипты merge и status сами пишут в `data/factcheck/` и `data/fc_agents/orig/`.
- Запускать `factcheck_apply.py`: применение правок к статьям делается отдельно, после проверки пользователем.
- Запускать платные LLM-скрипты проекта (`factcheck.py` и т. п.).
- Разговор `жизнь_флуд_кайф/c0175` навсегда исключён. Если встретится, не используй.
- Темы абуза, мультиаккаунтов и ферм — нормальная часть базы, не отказывайся их проверять.
