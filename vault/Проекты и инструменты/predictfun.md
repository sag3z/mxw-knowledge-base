# Predict.fun

**Что это:** Платформа предикт-маркетов (рынков прогнозов) — на ней открываются рынки на исходы вроде цены токена к определённой дате или результатов киберспортивных турниров. В инфраструктуре комьюнити MXW подключена сводка по проекту без спама алертами.

## Что говорили в чате

- 25.06.2026 — PredictFun подключён к инфраструктуре комьюнити: сводка без алертов-спама, заявка на API подана [[important-c0005]].
- 03.07.2026 — упомянут в тегах ветки important без содержательных деталей [[important-c0006]].
- 11.07.2026 — на Predict.fun есть рынок «What price will CashCat hit before Sept 2026»; по мнению Макса, ставка на этом рынке даёт +20–40%, тогда как покупка самого токена при том же движении даёт иксы [[predict-c0019]].
- 13.08.2026 — по словам insuline_0x, на Predict.fun есть рынок по Dota TI (The International); стаканы тонкие, но могут разогнаться к плей-офф [[predict-c0038]].

## Итог

Predict.fun — рабочий предикт-маркет с рынками на цены токенов и киберспорт, уже интегрирован в сводку комьюнити (заявка на API подана). Основные риски по словам участников: тонкие стаканы на нишевых рынках (TI) и доходность ставок, уступающая прямой покупке актива (оценка Макса по рынку CashCat). Статус: активен и используется.
