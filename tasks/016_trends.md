# Задача: «Темы во времени» — график активности тем по неделям

Меняй только `app/server.py` и `app/index.html`. Не читай `.llm_env`/`.openrouter_key`, не читай `tasks/*.log`, НЕ открывай PNG. LLM не вызывать.

## Данные
`data/kb.sqlite`: `layout(topic, conv, x, y, k)`, `clusters(k, name, descr, n)` — 30 смысловых кластеров полезных разговоров; `convs(topic, conv, msg_ids JSON, category, verdict)`; `messages(topic, id, ts, is_bot)`.

## 1. Сервер: `GET /api/trends?by=cluster|category`
Недели (понедельник, ISO) от первой до последней даты сообщений. Значение = число не-бот сообщений в полезных разговорах темы за неделю (сообщение относится к разговору через msg_ids). Ответ: `{"weeks":["2026-06-15",…], "series":[{"key":…, "name":…, "values":[…], "total":…}]}`, серии отсортированы по total убыв. Кэшируй результат в памяти (данные статичны).

## 2. Фронт: кнопка «📈 Темы» в `#top` (иконка + `.lbl`, как остальные)
Открывает НЕ узкую боковую панель, а широкий оверлей (≈85% ширины, ≈70% высоты, поверх карты, тёмный фон панели, закрытие ✕/Esc/клик по затемнению).

Форма: **stacked area** (накопленные площади, baseline = 0, НЕ wiggle/streamgraph) по неделям, d3 v7 (уже подключён), SVG.
- Переключатель «кластеры / категории» над графиком; там же — период: «всё / последние 3 мес / последний месяц».
- **Цвета — строго этот проверенный порядок для тёмного фона (не менять, не генерировать новые)**: `#3987e5, #d95926, #199e70, #c98500, #d55181, #008300, #9085e9, #e66767`. Цвет назначается теме по её месту в топе по total за ВЕСЬ период (не по видимому периоду) — при смене периода цвета тем не перекрашиваются. Топ-8 тем — свои цвета, остальные сложить в одну серию «Прочее» цвета `#5a5c66`, она лежит самой нижней.
- Разметка: между слоями 1px зазор цветом фона (stroke цвета поверхности), кривая `d3.curveMonotoneX`; сетка по Y тонкая и приглушённая (`#2a2c35`), подписи осей — вторичным цветом текста (не цветом серий); ось X — месяцы по-русски.
- Легенда всегда (над графиком, в ряд): цветной квадратик + название + total; клик по пункту легенды — скрыть/показать серию (стек пересчитывается). Плюс прямые подписи названий на 3–4 самых толстых слоях в точке их максимальной толщины (если подпись влезает по высоте; текст основным цветом текста с тёмной обводкой-подложкой, не цветом серии).
- Hover: вертикальная линия-курсор по неделе + тултип: «неделя с <дата>», список серий этой недели по убыванию с цветными маркерами и числами, сумма. Цель наведения — вся ширина колонки недели.
- Клик по слою (или по строке тултипа) → закрыть оверлей, на карте подсветить узлы этой темы (для кластеров — по `k`, для категорий — по `c`) тем же механизмом, что подсветка результатов поиска (задача 003), и выставить слайдер таймлайна на конец выбранной недели — чтобы были видны разговоры до этой даты; плюс в боковой панели открыть список топ-15 разговоров этой темы за эту неделю (по числу сообщений; клик → `openConv`). Кнопка «сбросить» убирает подсветку и возвращает слайдер.
- Доступность: под графиком ссылка «таблица» — показать те же данные таблицей (недели × серии).
