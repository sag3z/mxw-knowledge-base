# Soft Hub и хаб софтов sprintray: модули, патчи и реферальные цепи (август 2026)

Кратко

sprintray (@OxSprintray) выложил Soft Hub — локальное приложение, которое собирает его софты в один UI: заполненная один раз база аккаунтов шифруется на ПК, софты подтягиваются как `.patch`-пакеты из GitHub, а реферальные цепочки между аккаунтами настраиваются в самом хабе [[crypto-c0201]]. К 11 августа хаб держал уже 50 аккаунтов и версию v0.9.11, а в нём появился радар GitHub для поиска `.patch`-репозиториев по нику автора [[crypto-c0207]]. Отдельно выложен Abstract-хаб, завязанный на профили AdsPower: поинты, авто-голосование со стриком, Gigaverse и Tollan [[crypto-c0214]]. В ветке soft Макс (Max Wayld 福) закрепил правило «только софты» и включил хаб sprintray в список главных инструментов, переслав посты автора от 09 и 17 августа [[soft-c0001]]. У части участников радар не подключается к GitHub — sprintray советует VPN [[crypto-c0207]].

## Механика Soft Hub: что делает приложение

По словам sprintray, проблема была в том, что софтов стало слишком много и держать их открытыми и контролировать неудобно; хаб — «приложение, которое собирает все софты в одну кучу» и даёт запускать их централизованно из одного места, с выводом результатов во вкладке «Результаты» [[crypto-c0201]] [[soft-c0001]].

Сценарий пользования по описанию автора [[crypto-c0201]]:

1. Заполнить (или импортировать) БД аккаунтов и сохранить — она шифруется в хабе локально на ПК.
2. Настроить реферальную цепочку аккаунтов — зависимость «какой аккаунт чей реферал», чтобы софты при первой регистрации строили цепочку (если софт поддерживает реферальную систему).
3. Скачать патч — софт поставляется как патч в гите; в радаре патчей достаточно указать ник `spr1ntray`, и хаб подтянет все доступные патчи автора.
4. Настроить и запустить — софты сами тянут данные из БД.

Репозиторий хаба: https://github.com/spr1ntray/soft-hub — «если не доверяете, проверьте» [[crypto-c0201]].

## Интерфейс и разделы

По скриншотам, скинутым в чат 09.08, интерфейс Soft Hub («локальный центр») состоит из блоков [[crypto-c0201]]:

- Центр управления: 01 Обзор, 02 Софты, 03 Аккаунты, 04 Результаты.
- Система: 05 Патчи, 06 Настроек.
- Статус: «Vault открыт», «N аккаунтов готовы к запуску», версия и подпись «by sprintray with love».
- «Мои софты»: библиотека установленных софтов, «Установить пакет», пакетный запуск — «отметьте софты галочками, чтобы запустить их одной пачкой».
- Карточки софтов с версией и типом: Checkpoint / v1.5.3 / Checkpoint Testnet — «Работа и парсинг Checkpoint XP», TESTNET · 2 действия · готов; Incognitive / v1.1.2 / Incognitive Waitlist — «Email → waitlist Incognitive через proxy», «без риска для средств» · 1 действие · готов.

Версии в разных сообщениях расходятся: на скрине в посте от 09.08 22:34 указано v0.5.12 и 19 аккаунтов [[crypto-c0201]], а в том же посте, пересланном 25.08, — v0.6.13 и те же 19 аккаунтов [[soft-c0001]]. К 11.08 в чате фигурирует уже v0.9.11 и «50 аккаунтов готовы к запуску» [[crypto-c0207]].

## Патчи и радар GitHub

Раздел «Патчи» по скрину [[crypto-c0207]]: «Патчи и перенос софтов — добавьте пакет с компьютера или GitHub. Перед установкой Hub проверит структуру и контрольные суммы». Радар GitHub описан как «лента ваших *.patch репозиториев: Hub найдёт ваши открытые репозитории с окончанием .patch и покажет свежие пакеты»; в поле подставляется ник (в примере — sprintray) и кнопка «Сканировать».

Проверка пакета, по тому же скрину, локальная, четыре пункта:

- безопасный архив — внутри нет опасных ссылок, выходов из папки и конфликтующих путей;
- описание пакета — версия Hub подходит, действия и доступы описаны;
- SHA-256 каждого файла — все файлы перечислены и совпадают с контрольными суммами;
- надёжная установка — новая версия включится только после полной проверки пакета.

Пакет с компьютера — перетащить `.softhub.zip` или выбрать файл, лимит до 256 МБ; есть установка релиза GitHub по ссылке и очередь запуска [[crypto-c0207]].

- Manta Network / Incognitive Waitlist. Патч для хаба: https://github.com/spr1ntray/incognitive-waitlist.patch — «софт делает базовый рег в ВЛ» [[crypto-c0201]] [[soft-c0001]]. Контекст от автора: Manta собирает вейтлист на свою нейронку — модель крутится на железе телефона (Gemma 4 по умолчанию, переключается на Llama 3.2, Qwen 2.5 и др.), работает в airplane mode и без интернета, без аккаунта, подписки, рекламы и трекинга, данные (переписки, документы, «память») хранятся только на устройстве, умеет vision, summarization, drafting, memories. Вывод автора: «интересная фича + могут насыпать» [[crypto-c0201]].
- Skew (вейтлист). sprintray делал софт под WL Skew; 11.08 сообщил, что Skew выслал на почты коды со ссылками для подвязки кошельков (скрин письма с invite code) [[crypto-c0205]].
- Abstract. Готовился хаб под фарм XP в Abstract; на вопрос, какую активность накинуть на мульты, hh ответил: дейли-клейм в Tollan и стрик апвоутов [[crypto-c0201]].
- NFT. 17.08 в Soft Hub «улучшен UI, добавлена вкладка с НФТ и возможность с ними работать» [[crypto-c0214]] [[soft-c0001]]. Минтилки по slug OpenSea, по словам автора, ещё не обкатаны [[crypto-c0214]].

## Abstract-хаб на AdsPower

Репозиторий: https://github.com/spr1ntray/Abstract_hub. «В хабе всё завязано на Ads профилях»; для работы обязательно держать AdsPower открытым на фоне, сами профиля запускать не надо — «софт сам всё сделает» [[crypto-c0214]] [[soft-c0001]].

Реализовано, по словам sprintray [[crypto-c0214]]:

1. сбор информации по количеству поинтов на аккаунтах;
2. автоматическое голосование и поддержка стрика в фоне;
3. Gigaverse — зачистки подземелий, крафт перчаток, разбитие ваз, открытие сундуков; софт умеет продавать предметы и показывать, что в инвентаре каждого отдельного аккаунта;
4. Tollan Practice — клейм миссий в Tollan и забеги по данжам.

Отдельно в пересланном посте из ветки soft упоминается жалоба hh: сессии в Abstract-хабе приходится обновлять каждую неделю [[soft-c0001]].

## Выводы и правила

- Один раз заполнить БД и включить шифрование Vault — это база для всех патчей; софты сами тянут данные из неё [[crypto-c0201]].
- Реферальную цепочку настраивать до первой регистрации аккаунтов: софт строит цепочку только на этапе регистрации и только если поддерживает реф-систему [[crypto-c0201]].
- Патчи ставить только через радар GitHub по нику `spr1ntray` или из его репозиториев; хаб сверяет SHA-256 каждого файла и структуру архива перед активацией версии [[crypto-c0207]].
- Если радар выдаёт «Не удалось подключиться к GitHub» — проверять VPN и IP, а не ник [[crypto-c0207]].
- Не запускать Abstract-хаб без открытого AdsPower на фоне; профиля вручную запускать не нужно [[crypto-c0214]].
- Минтилки по slug OpenSea в хабе на 17.08 не обкатаны — на них не рассчитывать [[crypto-c0214]].
- В ветке soft разрешены только собственные или проверенные софты, остальное удаляется; обсуждение — в других ветках [[soft-c0001]].
- Проверка версий обязательна: номера на скринах в разных постах расходятся (v0.5.12 / v0.6.13 / v0.9.11), ориентироваться на последнее обновление в хабе [[crypto-c0201]] [[soft-c0001]] [[crypto-c0207]].
