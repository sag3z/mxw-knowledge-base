# Cashmere (cashmere.exchange)

**Что это:** NFT-проект (Cashmere Labs) с бесплатной регистрацией ника с любого кошелька и фриминтом через форму; NFT продвигался как «торговый агент, работающий 24/7» с демо-счётом.

## Что говорили в чате

- 2026-08-17: Ник на платформе регистрируется бесплатно с любого кошелька (Max); WL, по словам S.Rollins (инфа из дискорда), получат участники тестнета/майнета, стейкавшие NFT [[nft-c0287-04]]
- 2026-08-17: Фриминт шёл через форму длиной в два дня; по словам Max, после фриминта и двух суток на форму «всё равно надо абузить», для чего нужны gmail-почты («заёба» по его словам) [[nft-c0287-04]]
- 2026-08-17: Cashmere 🤙 описывал NFT как торгового агента, работающего 24/7, и ставил «высокий риск»; есть демо-счёт. FroZi считал проект скамом: по его словам, команда должна была отправить 2500 NFT на коллабы и не отправила (не проверено) [[nft-c0287-05]]
- 2026-08-17: Снапшот WL был накануне (16.08) в 13:00; по мнению S.Rollins, список могли урезать, у FrostY остался только паблик. По словам sag3z и Bnd, при готовом балансе на аккаунтах минт занимал ~3 минуты; glimjke минтил руками с нескольких аккаунтов (+3 NFT) [[nft-c0287-05]]
- 2026-08-28: По расписанию Max, GTD-минт Cashmere должен был начаться через ~30 минут; GTD, по его словам, выдавали по форме и регистрации пустого аккаунта с ником на платформе проекта [[nft-c0360-02]]
- 2026-08-28: Cashmere вышел с флором $50+; GTD выдали не всем, софт под проект не делали [[important-c0015]]

## Итог

Проект дошёл до листинга с флором $50+, но риски высокие: в чате его называли скамом (невыдача 2500 NFT на коллабы — не проверено), WL урезали по снапшоту, GTD получили не все. Софт под минт сообщество не делало — минтили вручную с нескольких аккаунтов.
