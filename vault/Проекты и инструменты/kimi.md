# Kimi (Moonshot AI)

**Что это:** ИИ-сервис/модель от Moonshot AI (Kimi K3, по утверждению пересланного поста — аналог Fable 5 и GPT-5.6) с платной подпиской, CLI и расширением Kimi Code для VS Code; в комьюнити используется как бюджетная альтернатива Claude/Codex для написания софта, фронтендов и геймдева, плюс фармится через реферальную программу.

## Итог

Kimi — рабочая бюджетная альтернатива Claude/Codex (~$40/мес, по словам участников — выше лимиты, меньше отказов, лучше дружит с софтами), но с рисками: перегрузки и приостановка продаж подписок (июль 2026), ограничения по сессиям и мультам без самописных скиллов. Реферальный фарм подписки работает, но это мультиаккаунт-схема. На ноябрь 2026 сервис активно используется, включая бесплатную версию.
