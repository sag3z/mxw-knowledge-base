# Инструкция: переразметка разговоров с расшифрованным медиа

Первый проход размечал переписку вслепую: вместо голосовых, видео и скринов модель видела только пометки `[голосовое]`, `[фото]`. Теперь медиа распознано и вставлено прямо в строки сообщений:

```
#3602 06-26 20:33 Max Wayld 福: [голосовое] ⟪голосовое: дословная расшифровка …⟫
#3610 06-26 20:35 Bnd: [фото] ⟪фото: ТИП: скрин сайта / ТЕКСТ: … / СУТЬ: …⟫
```

Разговоры отобраны двух видов: (1) с речью (голосовые, кружки, видео, аудиофайлы) и (2) раньше помеченные мусором, но со скринами, где есть информация. Часть из них после медиа станет полезной, часть так и останется мусором — решай заново, с нуля.

## Что делать

Прочитай `SORTING_GUIDE.md` (критерии полезного, категории, формат) и `SCHEMES_GUIDE.md` (схемы: мультиаккаунты, антисибил, фермы, аккаунты, софт, KYC, прокси, баны — **это тоже полезное**, фиксируй как архивист). Размечай по обоим сразу, учитывая расшифровки медиа как полноценный текст сообщения. Скрин твита/сайта с конкретикой (условия минта, цены, анонс, инструкция) — это полезное сообщение. Мемы, селфи, случайные фото — нет.

## Выход

Для каждого `data/batches_media/<ветка>/bNNN.txt` — файл `data/labels_media/<ветка>/bNNN.jsonl`, ровно одна JSON-строка на каждый блок `=== РАЗГОВОР`, в том же порядке:

```json
{"conv": "c0064", "verdict": "partial", "category": "tools", "tags": ["tiktok", "phonegrid"], "key_msgs": [3602, 3610], "summary": "…факты из текста и медиа…", "has_scheme": true, "scheme_types": ["farms", "accounts"], "scheme_summary": "…конкретика по схеме…"}
```

- `verdict`, `category`, `tags`, `key_msgs`, `summary` — как в SORTING_GUIDE (при `drop`: category null, остальное пустое).
- `has_scheme`, `scheme_types`, `scheme_summary` — как `has_scheme`, `scheme_types`, `summary` в SCHEMES_GUIDE; если схем нет — `false`, `[]`, `""`.
- Если суть взята из медиа, так и пиши: «в голосовом Max объясняет…», «на скрине условия минта: …».
- `key_msgs` — только номера, которые реально есть в блоке.
- Строго валидный JSON; рефералки, адреса кошельков, личные данные не переписывай; не выдумывай.
