# TickerYard

**Что это:** Проект в сети Robinhood Chain, запущенный через Stonk Launcher как один из четырёх «спецпроектов» (вместе с Oakmont Vault, Sleuth Intel и засекреченным); токен $YARD и NFT-коллекция Yardkeeper, по словам Andrey, официальный токен будет у pools.fun.

## Что говорили в чате

- 11.08.2026: TickerYard назван одним из четырёх спецпроектов, запускаемых в течение 96 часов на Stonk Launcher (Robinhood Chain) в ночь запусков 11.08; в той же ветке обсуждали снайп-ботов в TG (based_eth_bot) и предупреждения о высокой комиссии [[nft-c0263-10]]
- 12.08.2026: по пересланному разбору бота — NFT-коллекция Yardkeeper (3 333 NFT), supply токена 999 999 990, по 300 030 YARD на NFT, рынок создан через Anvil; токен без owner, без дополнительного минта и без transfer tax [[nft-c0263-14]]
- 12.08.2026: во время старта в basedbot было ~385 просмотров (sag3z); TheRikka писал «х50 за 1.5ч» (на одном из проектов) [[nft-c0263-14]]
- 12.08.2026: Al спрашивал, как покупать YARD, и предлагал ставить уведомления через GMGN на 4 проекта; слил часть покупки по 0,007 и, по его словам, почти отбил стоимость приватки ($10) [[nft-c0263-14]]
- 13.08.2026: по словам Andrey, официальный токен будет у pools.fun; токен по ссылке из #25529 создал не проект, а случайный участник через бота, который по сообщениям в X делает ончейн-действия [[nft-c0265-14]]
- 13.08.2026: по словам TheRikka, на прошлом буке NFT флипали по 0,5–2 ETH волнами [[nft-c0265-14]]
- 13.08.2026: TickerYard live — 3 спешла в течение 72 часов (C.Rollins); в той же ветке отмечен антиснайп у клоков [[nft-c0269-03]]

## Итог

Активный запуск 11–13.08.2026 на Robinhood Chain: по словам участников, один из проектов дал х50 за 1,5 ч при ~385 зрителях в basedbot, NFT прошлого бука флипали по 0,5–2 ETH. Риски: фейковые токены от случайных участников (официальный — по словам Andrey, у pools.fun), снайп-боты с высокими комиссиями и антиснайп-механики. Статус на 13.08.2026: live, анонсированы 3 спешла в течение 72 часов.
