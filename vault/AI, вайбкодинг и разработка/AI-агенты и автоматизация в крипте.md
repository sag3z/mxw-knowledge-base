# AI-агенты и автоматизация в крипте

Кратко: за два месяца чат прошёл путь от «Claude пишет посты в X через AdsPower на burner-аккаунте» до полностью автоматизированных NFT-газет за $1.5 в день и MCP-сервера Arkham, через который ончейн-активность ищется обычным языком. Параллельно копились рецепты агентных минтов: Inference Angels на 20 сессиях Claude (выход в ноль и 0.25 ETH случайного газа), Ink-пунки с самописным софтом, минт NFT на арендованных GPU через API RunPod. Отдельно — Bankr, который сам задеплоил BNKR на Robinhood Chain через LayerZero и оформил это как переиспользуемый «скилл» для любого токена Base, и калькулятор Dota Fantasy, собранный Claude Code через computer use. Всё это упирается в лимиты подписок ($20 / $200 / $500 планы) и в умение дробить задачу для модели.

## Автоматизация X: AdsPower, Playwright, API

Схема FroZi (видео от 30.06.2026): нужен ADS Browser (AdsPower), левый burner-аккаунт X, который не жалко сжечь, и прокси. В AdsPower есть раздел автоматизации с API MCP — его конфиг скармливается Claude/Codex с запросом «работай с моим твиттером через ADS Browser». Прокси обязателен: если аккаунт забанят, в бане будет фигурировать прокси, не привязанный к основному аккаунту [[ai-c0055]]. По словам FroZi, бан не прилетел, burner живёт 2–3 месяца; для стабильности нужны stealth-скиллы [[ai-c0055]].

Альтернативы из того же обсуждения:
- Playwright вместо AdsPower: по словам FroZi, его знакомый подключил основной аккаунт через Playwright и его не банит 2 месяца [[ai-c0055]].
- Timur держит агента на VPS в headless Playwright; рассматривал twitterapi, но эмуляция ему нравится больше [[ai-c0055]].
- Дешёвое API для X — twitterapi.io, «кто дрочиться не хочет» [[ai-c0055]].
- По словам nrcair, покупка галочки X даёт Grok 4.3 и доступ к API X [[ai-c0055]]. Официальный API при этом ограничен: по словам FroZi, квотить через него нельзя [[ai-c0055]].

Причина, по которой Max вообще слез с части инструментов: не хватает лимитов подписки — перестал использовать ultracode и ревью Claude, думает переходить на Codex [[ai-c0055]].

## Промпт для поиска статей в Grok

Max переслал (из «AI берлога пингвина», оригинал — t.me/batcherx) промпт для поиска англоязычных статей об AI на X с быстрым набором охватов: минимум 200k импрессий за 24 часа или 50k за 8 часов, минимум 5 статей от AI-лабораторий/компаний и 5 от креаторов X, без YouTube-ссылок, только статьи, опубликованные внутри X [[crypto-c0155]]. Промпт целиком:

> Find English Articles about AI topics on X that are rapidly gaining impressions over the last 24 hours, exclude not related to AI. Only Articles published on X — no articles from outside X. Make sure to include links and impressions amount. At least 5 articles from AI labs/companies and 5 from X creators. Don't include YouTube links. Minimum 200k imressions over last 24hrs or min 50k impressions over last 8 hrs.
> Skip:
> - articles that aren’t related to AI and gained less than 50k impressions/views
> - Not written in English.
> - posts, QT, comments, threads

По словам Max, подписка Grok не обязательна — достаточно зайти с аккаунта X, «нормально и с галочкой работает» [[crypto-c0155]]. Промпт предлагается переделывать под свои задачи (тренды, идеи под баннера) [[crypto-c0155]]. Пример выдачи на скрине: статьи @harleyfoote_ (~335k просмотров за ~20 часов) и @firesidealpaha (~102k за 12–13 часов) [[crypto-c0155]].

## Агентные минты NFT

**Inference Angels** (github.com/jacklarmer/inference-angels) — серия ИИ-загадок с минтом. Max запускал около 20 сессий Claude параллельно и начал абузить примерно на 4K саплая; на сложных загадках взял «пару штук», потому что криво настроил и из-за нехватки мощностей ПК сессии ломались [[nft-c0271]]. Итог: вышел в ноль — случайно потратил 0.25 ETH на газ, на Клода ушло около $100 [[nft-c0271]]. Андрей успел только лёгкие квесты и «выжрал лимиты» [[nft-c0271]]. TheRikka взял 10 штук через сайт по $0.22 [[nft-c0271]]. ArteMm сообщил, что минт вышел без доработки софта, которую «не успели подправить» [[nft-c0271]]. Прогноз Max: если проект жёстко иксанёт, пойдут копирки с ежедневными загадками «до 5 утра» [[nft-c0271]].

**Ink / inkpunk** — по sag3z, claim-форма коллекции inkpunk остановилась на 144/1000 [[nft-c0342-01]]. По словам Max: коллекций на Ink всего 9, «более менее адекватных» две, обе с более высоким сапплаем и ценой, зато с менее активными твиттерами; на момент разговора на Ink 101 панк [[nft-c0342-01]]. По словам Rollins, минт Onchain InkPunks стоил $3.6 при сапплае 2K [[nft-c0342-01]].

Вайбкод минт-софта — практика:

- Max советует давать ИИ по одному действию аккуратно, а не сразу «фулл абуз», и объединять параллельные сессии задач [[nft-c0342-01]].
- wdnad собрал «скил» и пишет всё одной командой [[nft-c0342-01]].

- FroZi держит одну долгую сессию, которая сама помнит контекст; новую Kimi открывать отказывается, для ввода данных использует папку с софтами [[nft-c0342-01]].

**Минт на арендованных GPU.** Антон палыч минтил на RunPod: арендовал видеокарты, во втором заходе автоматизировал минт через API — «очень удобно у них»; на vast.ai зарегистрироваться не дала ошибка капчи [[nft-c0449]]. Итог: 6 NFT — 4 по 0.02, 1 по 0.04, 1 по 0.08 ETH, работал примерно до 5 утра, вернулся из больницы и взял в 3 раза больше видеокарт, «дожег деньги на сервере и вышел» [[nft-c0449]]. Bnd регистрировался через рабочую почту и прокси, оплата через Crypto.com / BitPay / Stripe; после 1к минтов посчитал, что минтить смысла нет, и просто купил токен [[nft-c0449]].

## Bankr, Virtuals, Vibestarter

**Bankr** (агент @bankrbot) по пересланному посту сам задеплоил BNKR на Robinhood Chain: LayerZero OFT-мост Base → Robinhood Chain и пул $50K BNKR/WETH на другой стороне, всё исполнено агентом [[crypto-c0110]]. Ключевое — это оформлено как переиспользуемый скилл: любой токен Base расширяется в Robinhood Chain с бутстрапом ликвидности одним промптом (bankr.bot/skills) [[crypto-c0110]]. В посте рекомендуется выбирать более мощные модели в консоли Bankr — claude fable, opus 4.8, gpt-5.5 [[crypto-c0110]]. По скрину DEX: цена ~$0.00036, ликвидность $51K, FDV $39K; на вопрос «там не рагпул?» ответ в чате — «хз» [[crypto-c0110]].

**Virtuals** — на скрин профилей в X от Kodak: @IntoPurpleMoon «building @Virtuals_io / @virtuals_vc» и @DonJohnsonSays — chef @virtuals_io, соавтор стандарта ERC-8126 [[crypto-c0066]]. Скинуто как список людей экосистемы, за которыми стоит следить [[crypto-c0066]].

**Vibestarter** (vibestarterxyz) — токен-лаунчпад для AI-проектов: холдеры могут открыть спор, и если его массово поддержат и спор подтвердится, дев перестаёт получать разлоки, деньги возвращаются, токен закрывают [[life-c0156]]. По словам Сёмы, Серпин «шишка Ethos» заносил 5 ETH в их токен; пад сейчас в тишине, на хакатон по набору проектов подалось ~50 человек, 20 получили от команды подписки Claude [[life-c0156]]. Kodak возразил, что на Base уже есть готовое решение для рефандов в лаунчах, и дал ссылку на whitepaper Virtuals (capital formation layer, 60 days) [[life-c0156]]. Тезис Сёмы: главная проблема крипты — девы не отвечают за продукт, а тут «тебя хотя бы год поебут заставят билдить и выполнять план» [[life-c0156]].

## Ончейн-данные: Arkham MCP и софт для Solana

Arkham выпустил MCP-сервер: подключение к Claude, Claude Code, Codex и любому MCP-совместимому инструменту, запросы об ончейн-активности обычным английским языком; настройка за минуту по API-ключу Arkham [[crypto-c0310]].

spacetime написал с ИИ софтину для Solana — кастомные транзакции для переводов; на скрине обозревателя четыре трансфера за ~45 минут, в одной из подписей транзакции заданная нецензурная строка [[ai-c0390]]. По словам Сёмы, Opus 5.5 у него работает по 30 минут с редкими остановками, а ресет лимитов надо потратить до 22 числа [[ai-c0390]].

## Computer use вне крипты: Dota Fantasy

Автор (переслано от dev.insuline.eth) скормил Claude Code три гайда — dotabuff, battlepass.ru и тред с реддита — и попросил сгруппировать в методичку: как работает система ролей, какие статы сколько дают очков, как тратить рероллы [[life-c0357]]. Затем дал через computer use доступ к клиенту Dota 2 и сказал собирать состав, считая EV каждого ролла (рероллы необратимые) [[life-c0357]]. Модель разложила ценность статов по историческим данным (Teamfight силён на любой роли, руны для мида безальтернативны), отроллила эмблемы по одной, прогнала всё через калькулятор и выбрала оптимальный состав с титулами [[life-c0357]]. Результат по калькулятору: ~32 500 очков за карту, суммарные множители баннеров 700–770% при бенчмарке топ-5% игроков в 500% [[life-c0357]]. В ник команды в клиенте вклинился текст «claude code» — агент оставил след в ростере [[life-c0357]].

Инструменты и награды: калькулятор battlepass.ru/ti2026/fantasy-calc бесплатный [[life-c0357]]; за фэнтези дают эксклюзивные имморталки, ландшафт Dota Plus и Aegis со скидкой или бесплатно [[life-c0357]]. Попутно: автор ждёт, что апдейт HIP-4 (тестируется в testnet) заведёт киберспорт в Outcome на Prediction Markets [[life-c0357]].

## Выводы и правила

- Для автоматизации X: AdsPower + отдельный burner-аккаунт + отдельный прокси; конфиг API MCP из AdsPower скармливается Claude/Codex [[ai-c0055]]. Playwright на основном аккаунте — рабочий, но рискованный вариант (2 месяца без бана — это не гарантия) [[ai-c0055]].
- Не тянуть официальный API X, если нужны квоты: дешёвая альтернатива — twitterapi.io; галочка X даёт Grok и API [[ai-c0055]].
- Давать модели по одному действию и объединять параллельные сессии — вместо одного «фулл абуза»; готовый скил позволяет писать софт одной командой [[nft-c0342-01]].
- Держать одну долгую сессию с накопленным контекстом (подход FroZi) либо папку с софтами как источник данных [[nft-c0342-01]].
- Мощности ПК — узкое место: при 20 параллельных сессиях Claude сессии ломались [[nft-c0271]]; GPU-минт выносится на аренду (RunPod) с автоматизацией через API, но регистрация упирается в капчу и требует рабочей почты и прокси, а оплата — Crypto.com/BitPay/Stripe [[nft-c0449]].
- Считать экономику минта: после ~1к минтов смысл пропадает, выгоднее купить токен [[nft-c0449]]; на аренде «дожигать деньги на сервере» нужно сразу, как только стало невыгодно [[nft-c0449]].
- Агентные деплои смотрят на скиллы: Bankr расширяет любой токен Base в Robinhood Chain одним промптом, и в консоли стоит выбирать более мощные модели [[crypto-c0110]]. Ликвидность $51K при FDV $39K — повод проверять пул на раг, ответа по нему в чате не было [[crypto-c0110]].
- Ончейн-разбор делегируется Arkham MCP: ключ API + минута на настройку, запросы на обычном языке [[crypto-c0310]].
- Контент-автоматизация окупается: газета + сводка NFT-проектов на API твиттера и Opus — $1.5 в день [[life-c0677]].
- Подписки: $20 Codex хватает для ImageGen, но для тяжёлых задач выгоднее два плана по $200 из-за двух ресетов, чем один дорогой [[ai-c0314]].
