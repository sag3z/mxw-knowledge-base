# Другие сети и механики: BNB, BTC, NEAR, Solana, тестнеты (октябрь–ноябрь 2026)

**Кратко.** В подборке — не-Ethereum минты и механики конца сентября — начала ноября 2026: первая NFT на CRC-20 (seals.garden) и раздача Silent Payment, боксы Chrodinals на Bitcoin L1, агентский минт чёрных дыр на BNB Chain только для держателей SPACE ID .ai Agent ID, ретро-картриджи Nulls на NEAR и тестнет-бейджи с фильтром по возрасту твиттер-аккаунтов. Отдельный блок — Identity Units с отбором ИИ-агентами IMD и добором по хешу будущего блока. Плюс два сюжета про «новые стандарты»: пиксельные боты с майнинг-бустами и TAP-721 (netlist-bound NFT) с обзором майнинг-проектов от Max Wayld 福. По Solana-specific механикам в этом материале конкретики нет — только упомянутые сети TapeOut (X Layer, BNB Chain, Base).

## Identity Units: ИИ-отбор + хеш будущего блока (06.10)

Механика по посту glimjke: коллекция одна — **787 NFT**. **Genesis (первые 87)** уже закрыт и роздан держателям **IMD**. На остальные — **14 дропов по 50** заявок [[nft-c0595]].

Как податься:
1. Открыть **identityunits.fun/claim**.
2. Вставить адрес кошелька — **ничего подключать и подписывать не нужно**.
3. Зарегистрироваться и **запостить об этом в X** — без поста в розыгрыш не попасть [[nft-c0595]].

Дальше распределение: когда вайтлист закрывается, победителей выбирают **по хешу будущего блока** (результат нельзя подкрутить) и назначают каждому один из дропов; NFT присылают сразу на кошелёк — **claim, газ и подпись не нужны**. На момент поста (06.10, 06:49) дедлайн — **16 часов**. Торговли нет, контракт ещё не выложен. Отдельно места есть у держателей **IMD-seats** и их токена — это не тот же raffle [[nft-c0595]].

Итог отбора (пост проекта, переслан в чат 06.10, 22:12): вайтлист закрыт, **11 282 заявки**. Отбор делают **ИИ-агенты IMD** — читают ончейн-активность каждого кошелька, **один агент выбирает, другой проверяет**; остаток разыгрывается по хешу будущего блока; держатели IMD-seats получают свои места, причём **seats с большим числом выполненных работ — в приоритете**. Результаты через ~2 часа на identityunits.fun: кнопка **CHECK WINNERS**, вставляешь кошелёк и видишь, что решил «swarm» и почему [[nft-c0597]].

У glimjke иная картина: **PHASE 1: GTD — 1 бот** (`gL1Mjke`), в **PHASE 2+3 — «No bots allocated»**, т.е. во второй/третьей фазе ему ничего не досталось [[nft-c0676]].

## TAP-721 и майнинг-проекты: разбор Max Wayld 福 (23.10)

**TAP-721 (TapeOut / X Layer)** — новый стандарт NFT в экосистеме TapeOut, работает на **X Layer, BNB Chain, Base**. Суть (Netlist-Bound NFT): обычный ERC-721 получает не только картинку, но и **привязанную схему (netlist) в формате tapnet/1** — только **NAND + LATCH**, без внешних ссылок. Любой может скачать файл, проверить **SHA-256**, симулировать схему, в перспективе — запускать её прямо в смарт-контрактах (Eval-расширение). Связано с **Proof-of-Design (PoD)** TapeOut: люди дизайнят логические схемы, «tape out» — запекают их в NFT-майнеры и получают **BEM**. Первый adopter — коллекция **TapeCode-Test1** на X Layer, появляются «circuit-native» NFT вроде **Circuit Punk**. Статус — **Draft, подан 18 октября 2026**, не финальный стандарт; оценка Max — «классический degen-плей на новую механику NFT + on-chain compute» [[nft-c0676]].

Второй скрин — таблица майнинг-проектов (по пересланному разбору) [[nft-c0676]]:

| Название | Что это | Тип | Комментарий |
|---|---|---|---|
| Blocknet (BNT) | CPU-майнинг, Argon2id | CPU | Ранний, рынка почти нет; майнят на spare CPU/VPS «на удачу» |
| Trac / RESET | AI-агенты «майнят» RESET | Agent | Привязано к Bitcoin-блокам, game theory (fair share vs greed); запускаешь агента (Claude/Codex и т.п.) |
| TSC (TensorCash) | Proof-of-Inference | GPU/CPU | Майнеры запускают LLM (Qwen3 и др.), proof = фрагмент инференса; есть цена и рынок (~$7, MC ~$30M+) |
| Vearl (VRL) | Proof of Useful Work (verified compute) | GPU | int8 matrix multiplication / AI; публичный тестнет стартовал **23 октября 2026**, нужна NVIDIA Ampere+ |
| Ptah | NFT + mining (ptah.trade) | NFT + Agent | Mint Relics только через **Binance Agent ID**, 10 Relics → Loom (майнинг-машина); sold out, сильный объём |
| PRL (Pearl) | GPU PoUW (matrix mult) | GPU | «Самый нормальный» revival GPU-майнинга 2026, много софта и пулов |
| QTC (Quantus) | Post-quantum PoW | GPU | Poseidon2, обычный GPU-майнинг |
| BEM | Токен TapeOut | PoD | Майнинг через дизайн схем (NAND/LATCH → tape out в NFT), связан с TAP-721 |

Резюме Max на всё это: «Понапридумывают говна суки» [[nft-c0676]].

## Выводы и правила

- **Проверяй eligibility до минта, а не после.** Chrodinals и минт чёрных дыр дают публичный чекер по адресу (taproot / Agent ID) — фаза и число бесплатных минтов видны заранее [[nft-c0608]] [[nft-c0691]].
- **Считай цену минта против фриминта.** На BNB-минте бесплатная и дешёвая фазы закрылись на 7 000 из 10 000, остаток по $0,60 при 1–2 на кошелёк — экономика «копейки сверху фриминта» (замечание Max) [[nft-c0691]].
- **BTC-минт дешёвый только при низком газе:** ориентир sag3z — $1,5–2 [[nft-c0608]].
- **В Identity Units нет подписи и газа:** только адрес + регистрация + пост в X; всё остальное решают ИИ-агенты IMD и хеш будущего блока, дроп приходит на кошелёк сам [[nft-c0595]] [[nft-c0597]].
- **Вайтлист-коды ловят в постах проекта** (кейс Nulls, код WL 162-234) — мониторь X до объявления формы [[nft-c0703]].
- **Мультиаккаунты в тестнетах упираются в возраст аккаунтов:** X/Discord старше 365 дней, иначе задания не засчитываются (опыт Kapitoshich: «старые поотлетали») [[nft-c0734]].
- **Новые стандарты — это черновики:** TAP-721 в статусе Draft от 18.10.2026, оценивай как degen-плей на механику, а не как готовую инфраструктуру [[nft-c0676]].
- **Накрутка просмотров в мини-аппах работает точечно:** по словам Kapitoshich, от 15K просмотров дали 2 бота фазы 2+3 (+50%), но распределение по фазам неравномерное — у glimjke в 2+3 ноль [[nft-c0676]].
