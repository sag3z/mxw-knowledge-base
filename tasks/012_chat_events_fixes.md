# Задача: три правки после задач 010 (события) и 011 (чат)

Меняй только `llm.py`, `app/server.py`, `app/index.html`. Не читай `.llm_env`/`.openrouter_key`, не читай `tasks/*.log`, НЕ открывай PNG. Не запускай `extract_events.py` без флагов (события уже извлечены, повторный прогон не нужен).

1. **Чат падает на 429.** `llm.chat_stream` при HTTP 429/5xx/обрыве соединения ДО первого куска текста сразу отдаёт ошибку (`ошибка: HTTP Error 429: Too Many Requests`). Добавь повторы: до 5 попыток с паузой 2, 4, 8, 15, 20 с, только пока не отдан ни один кусок; после первого куска — не повторять (иначе текст задвоится). Если все попытки исчерпаны и в `chat_stream` передан `fallback` — один раз попробовать fallback-модель. В `/api/chat` вызывай с `fallback=llm.ENTITY`. Пока идут повторы, отправляй клиенту событие `status` с текстом «провайдер занят, повторяю (n/5)…» — фронт показывает его серым под вопросом.

2. **Стример-мод в чате связывает ник с псевдонимом.** При `anon:true` модель написала «Max (Участник 293)»: имя пришло из выжимки (тексты выжимок и сообщений мы не меняем — это решение пользователя), а псевдоним — из поля автора, и модель их сопоставила. Добавь в системный промпт при anon: «Авторов называй только псевдонимами вида "Участник XXX". Никогда не пиши рядом имя/ник и псевдоним, не раскрывай, кто скрывается за псевдонимом; если в тексте материала встречается имя — пересказывай без указания, какой это участник». Плюс пост-проверка на фронте не нужна.

3. **События только со сроком «до …».** В `/api/events` статус сейчас считается по `date`; у событий с `date = null` и заполненным `end_date` статус `undated`. Правило: если `date` нет, но есть `end_date` — `active`, если `end_date >= сегодня` (в UI показывать «до <end_date>»), иначе `past` (сортировать по end_date). В группе «Идёт сейчас» показывай «до <end_date>» и для событий с обеими датами. События с `date` в прошлом и `end_date` дальше чем через 120 дней от `date` — это почти наверняка ошибка извлечения: статус по `date` как без end_date (то есть `past`), end_date в UI не показывать.
