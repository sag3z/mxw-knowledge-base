# Rabby Wallet

**Что это:** Браузерный крипто-кошелёк (расширение Chrome), который комьюнити регулярно использует для подключения к EVM-сетям и минтов NFT — упоминается наравне с MetaMask и Phantom.

## Что говорили в чате

- Для подключения кошелька к Robinhood chain упоминались Rabby Wallet (расширение Chrome) и мост relay.link/bridge/robinhood [[life-c0160]]
- Для минта Proof of Fun нужно минтить с того кошелька, который подключён в браузере (Rabby/MetaMask/Phantom) [[nft-c0077]]
- Сеть Robinhood в Rabby добавляется вручную [[nft-c0276]]
- По словам ArteMm, в Rabby видно, если отдаёшь NFT и получаешь WETH без msg.value — риск по офферам низкий, слить через approve от EOA по его словам нельзя; с токенами сложнее, нужна симуляция из-за блеклиста и налога на перевод. Совет: офферы рассматривать через Rabby, токены — через симуляцию [[nft-c0342-04]]
- Robinhood Chain — EVM: минт через Rabby или MetaMask; в Rabby есть сеть Robinhood, комиссии в ETH; бридж relay.link [[nft-c0415-02]]
- В Rabby при линке нужно выбирать нужный адрес; импорт кошелька — по сид-фразе или приватнику [[nft-c0415-03]]
- Для Rabby RPC Arc нужно прописывать вручную (docs.arc.io, rpc.blockdaemon.mainnet.arc.io); при этом Relay и Rabby баланс на Arc не показывали, бриджи Jumper и Zerion работали [[nft-c0471]]
- По словам glimjke, транзакция висела 3 минуты из-за кастомного газа, выставленного в Rabby, — перед минтом стоит проверять настройки газа [[nft-c0499]]

## Итог

Rabby — один из основных кошельков чата для минтов на EVM-сетях (Robinhood Chain, Arc), наравне с MetaMask. Нюансы: сети Robinhood и RPC Arc добавляются вручную, а Rabby не показывал баланс на Arc; кастомный газ может подвесить транзакцию. Плюс по словам участников — наглядная видимость деталей транзакции (msg.value), что помогает оценивать риски офферов, но для скам-токенов всё равно нужна симуляция.
