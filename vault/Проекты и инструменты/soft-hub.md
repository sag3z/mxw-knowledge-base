# Soft Hub

**Что это:** Хаб-приложение автора sprintray для централизованного запуска его софтов/патчей: шифрованная локальная БД аккаунтов, подтягивание патчей из GitHub по нику, настройка реферальной цепочки аккаунтов. Репозиторий: spr1ntray/soft-hub.

## Что говорили в чате

- 2026-08-09 — sprintray выложил Soft Hub: приложение запускает его софты из одной базы, шифрует БД аккаунтов локально, тянет патчи из GitHub и строит реф-цепь при первой регистрации. Есть патч на Checkpoint и на вейтлист Manta Network (локальная модель на телефоне, без подписки — по его словам); готовится хаб под фарм XP в Abstract. Для фарма XP hh советовал дейли-клейм в Tollan и стрик апвоутов. [[crypto-c0201]]
- 2026-08-11 — скрины v0.9.11: раздел «Аккаунты (50)» с пометкой «Vault открыт», модуль патчей, радар GitHub для .patch-репозиториев; софт заявляет проверку безопасности пакетов. Участник Александр не смог подключиться к GitHub с украинского IP — sprintray посоветовал VPN. [[crypto-c0207]]
- 2026-08-12 — патч на тестнет ValueQube: регистрирует аккаунты, строит реф-цепь, делает ончейн-действия, достаточно запускать раз в день. БД шифруется AES-256; в чате советовали держать крипто-софт на отдельной машине. [[crypto-c0210]]
- 2026-08-17 — обновление: добавлена вкладка NFT и выложен Abstract-хаб на AdsPower-профилях — учёт поинтов по аккаунтам, автоголосование и поддержка стрика в фоне, Gigaverse (зачистки, крафт перчаток, продажа предметов), Tollan practice. Минтилки по slug OpenSea, по словам автора, ещё не обкатаны. [[crypto-c0214]]
- 2026-08-25 — хаб sprintray включён в закреп ветки soft (правило Max Wayld: только проверенные или самостоятельно написанные софты, остальное удаляется) в числе главных инструментов. hh жаловался, что сессии (AdsPower) приходится обновлять каждую неделю. [[soft-c0001]]

## Итог

Активно развиваемый инструмент с растущим набором патчей (Checkpoint, Manta WL, ValueQube, Abstract) и централизованным управлением аккаунтами; прошёл отбор модерации ветки soft. Риски: софт для мультиаккаунтинга — рекомендована отдельная машина, для GitHub из Украины нужен VPN, сессии требуют еженедельного обновления, а часть функций (минт по slug OpenSea) ещё не обкатана.
