# Задача: раздел «Люди» (кто в чём силён) — удобно и наглядно

Сначала прочитай `tasks/DESIGN.md`. Работай в `app/web/` (каркас из 019, чат из 020): `js/people.js` + правки `api.js`, `ui.js`, `style.css`, при необходимости `app/server.py`. Не читай `.llm_env`/`.openrouter_key`, не читай `tasks/*.log`, НЕ открывай PNG.

Данные: `GET /api/experts` (таблицы `experts(author, n_msgs, n_key, n_convs, first_ts, last_ts, profile, skills)` и `expert_topics(kind cluster|category|scheme, topic, author, score, n_key, n_convs, examples)`). Пользователю старый вид не понравился: неудобно и непонятно. Темы-кластеры здесь НЕ использовать — только категории (человеческие названия) и типы схем (по-русски).

## Экран `#/people`
- Заголовок «Кто в чём разбирается» + пояснение серым: «По содержательным сообщениям в чате: чем больше полезных сообщений человек написал по теме, тем выше он в списке».
- Сверху — большое поле поиска «Кто разбирается в… (например: минт-боты, антидетект, перпы)»: фильтрует людей по навыкам, профилю и названиям тем (без учёта регистра, по частям слов; подсветка совпадений). Под полем — чипы тем (категории + типы схем) для быстрого фильтра; выбранный чип сортирует людей по силе в этой теме и показывает рядом с каждым «N полезных сообщений по теме».
- **Сетка карточек людей** (3–4 в ряд, адаптивно): круглый аватар 44px с инициалами (цвет фона — из хеша имени, приглушённый), имя (или псевдоним в стример-моде), под ним одна строка «⭐ 1 152 полезных сообщения · с июня по ноябрь»; профиль — 2 строки с обрезкой; 3 чипа навыков; внизу — 3 полоски «сильнее всего в»: название темы + тонкая горизонтальная полоска (ширина ∝ score относительно лидера этой темы, цвет категории) + число. Сортировка по умолчанию: по числу полезных сообщений. Показывать людей с профилем (топ-50); остальных — кнопкой «Показать всех (N)» компактным списком.
- **Карточка человека (drawer)** по клику: аватар, имя, «активен: <первая> — <последняя дата>», полный профиль, все навыки чипами; блок «Темы» — горизонтальные полоски по всем его темам (категории и схемы), отсортированы; блок «Где он писал по делу» — 5–8 разговоров заголовками (как в ui.js: заголовок + дата + ветка), клик → разговор; кнопка «💬 Спросить ИИ про его опыт» → `#/chat` с готовым вопросом «Что <имя/псевдоним> советовал и рассказывал про <его топ-тема>?».
- Из панели разговора: клик по имени автора → его карточка (как раньше).
- Стример-мод: везде псевдонимы и инициалы от псевдонима.
