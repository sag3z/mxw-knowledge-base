# Боты (сводка упоминаний в чате MXW)

**Что это:** Не один проект, а разные боты, упоминавшиеся в чате: минт-боты для NFT, бот для создания токенов на pools.fun, opensearobinhood_bot со списком смарт-кошельков, внутренний бот MXW для наград и рейтинга активности, а также общий КУС-бот инфлюенсеров.

## Что говорили в чате

- 2026-07-11: Минт Robinhood Apes (OpenSea) за 5.47 с 13 смартами вышел в плюс после флипа (по скрину Макса); Макс считает, что бот для минта «легко сделать» после пары тестов, и говорит, что открытый на GitHub бот Асати вайбкодится и дефолтный. [[nft-c0069]]
- 2026-08-13: Andrey: токен по ссылке из #25529 создал не проект, а случайный участник через бота, который, по сообщениям в X, делает ончейн-действия (#25532); официальный токен будет у pools.fun. [[nft-c0265-14]]
- 2026-09-03: Сёма поделился ботом opensearobinhood_bot — там собирают народный список смарт-кошельков по Robinhood chain: можно предлагать адреса и батчем отправлять кошельки; Макс перенёс ссылку из чата в ветку NFT. [[life-c0480]]
- 2026-10-01: Награды участникам MXW выдаются командой /gift N в боте (например, /gift 60, /gift 30), обычно в конце месяца; если функция ломается, Макс выдаёт вручную. [[life-c0602]]
- 2026-11-01: Награды за активность считает бот; в следующем месяце Макс хочет сделать выдачу полностью автоматической, /gift N остаётся ручной выдачей через бота. [[life-c0782]]
- 2026-11-02: Асати: КУС-бот у всех инфлюенсеров один и тот же, хостится на одном сервере (у Xnota такой же); Макс пожаловался, что КУС-боты разных продавцов не отвечают, а отвечает только бот Вишни, и попросил добавить КУС Claude в поиск, чтобы не отправлять всех к Вишне. [[life-c0788]]
- 2026-11-10: Рейтинг активности в приватке считает бот, в том числе флуд из отдельных сообщений; предложено не учитывать короткие флуд-сообщения при подсчёте — Макс обсуждение не подтвердил. [[life-c0830]]

## Итог

Упоминания касаются разных ботов, а не одного инструмента. Внутренний бот MXW — рабочая инфраструктура (награды через /gift N, подсчёт рейтинга), выдача пока ручная, полная автоматизация обещана Максом. Внешние боты несут риски: через бота на pools.fun посторонние создают неофициальные токены, а общий КУС-бот инфлюенсеров на одном сервере периодически не отвечает; минт-боты, по словам Макса, «легко сделать», а бот Асати на GitHub — вайбкоденный и дефолтный.
