# relay.link

**Что это:** Кроссчейн-мост (бридж) для перевода средств между сетями; в чате MXW — основной инструмент для пополнения Robinhood chain и Ink перед минтами NFT.

## Что говорили в чате

- 2026-07-10: Для минта NFT на Robinhood chain ETH нужно бриджить через relay.link; OpenSea эту сеть поддерживает [[nft-c0062]]
- 2026-07-11: Для подключения кошелька к Robinhood chain упоминались Rabby Wallet (расширение Chrome) и мост relay.link/bridge/robinhood [[life-c0160]]
- 2026-08-11: Max советовал при долгом переводе из Ink использовать Relay, а не Jumper — на Jumper, по его словам, иногда медленные роутеры [[life-c0334]]
- 2026-08-24: Для бриджа на Ink — jumper.xyz или relay.link (на выбор) [[nft-c0342-02]]
- 2026-08-24: По совету Асати, для бриджа с биржи нужно вывести средства в любую сеть и бриджить через relay.link [[life-c0417]]

## Итог

Relay.link — дефолтный мост комьюнити для пополнения Robinhood chain и Ink перед минтами, упоминается стабильно с июля по август 2026. По словам Max, при долгих переводах из Ink он предпочтительнее Jumper из-за медленных роутеров последнего; нареканий на сам Relay в чате не зафиксировано.
