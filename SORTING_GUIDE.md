# Инструкция по сортировке переписки MXW

Ты размечаешь выгрузку приватного крипто-комьюнити MXW (Telegram, ветки-топики). Цель — потом собрать из полезного базу знаний. Твоя задача на этом шаге — **только сортировка**, не пересказ всего подряд.

## Вход

Файлы `data/batches/<ветка>/bNNN.txt`. Каждый файл — набор разговоров:

```
=== РАЗГОВОР c0012 (2026-06-18 20:51 — 21:40, 14 сообщ.) ===
#1158 06-18 20:51 Kapitoshich: [фото]
#1160 06-18 20:54 glimjke: чето дропнут мб сегодня
#1175 06-18 21:12 Max Wayld 福 (переслано от ...) (ответ на #1160): ...
```

`[фото]`, `[видео 0:42]`, `[голосовое ...]`, `[кружок]` — медиа, содержимое которого ты не видишь. Max Wayld 福 — основатель/админ комьюнити, его посты обычно весомее.

## Что считать полезным (keep)

То, что пригодится участнику через месяц:
- конкретные проекты, дропы, тестнеты, вайтлисты, минты — с условиями, датами, ссылками;
- стратегии и связки (NFT-флипы, арбитраж, фандинг, предикшены), разборы что сработало / не сработало и почему;
- инструменты, софты, боты, сервисы, ссылки с объяснением, зачем они;
- инструкции, гайды, «как сделать X»;
- предупреждения о скамах, взломах, рисках;
- решения и итоги (сколько заработали/потеряли, выводы);
- анонсы и правила самого комьюнити, его инфраструктура;
- AI/вайбкодинг: рабочие приёмы, промпты, инструменты, хакатоны.

## Что выкидывать (drop)

Приветствия, «ахах», мемы без контекста, реакции, личный трёп, споры без вывода, вопросы без ответа, голые [фото]/[видео] без пояснения, дубли того же самого, повторяющиеся «кто в деле?», шиллинг без сути.

Если в шумном разговоре есть 1–2 ценных сообщения — это `partial`: перечисли только их id.

## Категории (выбери одну главную)

- `drops_testnets` — дропы, тестнеты, ретро, поинты, фарм активностей
- `nft` — коллекции, минты, вайтлисты, флипы, NFT-рынок
- `trading` — трейдинг, перпы, фандинг, арбитраж, DEX/CEX, мемкоины
- `predictions` — Polymarket и предикшены, ставки
- `ai_dev` — AI, вайбкодинг, разработка, хакатоны, гранты
- `tools` — софты, боты, сервисы, кошельки, расширения
- `jobs_income` — работа, вакансии, заработок, амбассадорки
- `security` — скамы, дрейнеры, взломы, opsec
- `community` — правила, анонсы, инфраструктура MXW, коллы
- `market_news` — новости рынка, макро, листинги
- `other` — полезное, но не подходит выше

## Выход

Для каждого входного файла `data/batches/<ветка>/bNNN.txt` создай `data/labels/<ветка>/bNNN.jsonl` — **по одной JSON-строке на каждый разговор, без пропусков**, в том же порядке:

```json
{"conv": "c0012", "verdict": "partial", "category": "drops_testnets", "tags": ["hyperliquid", "airdrop"], "key_msgs": [1160, 1175], "summary": "Ожидали дроп X 18.06; Max переслал пост о том, что скамеры проекта Jailed арестованы."}
{"conv": "c0013", "verdict": "drop", "category": null, "tags": [], "key_msgs": [], "summary": ""}
```

Поля:
- `verdict`: `keep` (разговор в целом полезный) | `partial` (полезны отдельные сообщения) | `drop`
- `category`: одна из списка выше; `null` при `drop`
- `tags`: 1–5 коротких тегов в нижнем регистре: названия проектов, монет, инструментов (`"blur"`, `"polymarket"`, `"cursor"`)
- `key_msgs`: id (числа без `#`) сообщений с самой сутью; для `keep` — 1–10 главных, для `partial` — все ценные
- `summary`: 1–3 предложения по-русски — **конкретные факты**: что, где, условия, цифры, вывод. Не «обсуждали дроп», а «дроп Monad: снапшот 20.06, нужен 1 тх в неделю». Пусто при `drop`.

Правила:
- Строго валидный JSON в каждой строке, двойные кавычки, без комментариев и без обёрток markdown.
- Не выдумывай того, чего нет в тексте. Не понял медиа — не додумывай.
- Сомневаешься между keep и drop — ставь `partial` с конкретными id.
