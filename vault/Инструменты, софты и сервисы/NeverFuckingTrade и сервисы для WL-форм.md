# NeverFuckingTrade и сервисы для WL-форм

Кратко: FroZi собрал линейку сервисов вокруг вайтлистов — сначала агрегатор Stonkhuman с проверкой WL по подключённому кошельку, затем neverfuckingtrade.com с каталогом WL-форм, мини-игрой за GTD и PnL-трекером через OpenSea OAuth [[nft-c0253]] [[nft-c0263-06]] [[nft-c0297]] [[nft-c0556]]. Каталог WL-форм (/whitelists) бесплатно принимает только 3 проекта, где форма уже заполнена и WL получен, список ведётся полуавтоматически через Claude [[nft-c0498]]. Параллельно участники тестируют платный автозаполнитель Zyper (~$50/мес, промокод на $10, лимит 500 заполнений на запуск) [[nft-c0348-03]], чекеры Wallchain/Moni и фильтр Real Builders на самом сайте [[nft-c0348-03]] [[nft-c0541]]. По вайтлисту основного сайта за 29.10–02.11 подано 1635 заявок, из них 9 групп (47 ников) с одного IP помечены как фермы [[nft-c0713]].

## Stonkhuman: первый агрегатор WL (09.08)

FroZi показал сайт-агрегатор Stonkhuman: подключаешь кошелёк — видно все коллекции, где у тебя есть WL («кош конекетишь, тебе показывает везде где у тебя вл есть») [[nft-c0253]].

- Скриншот локального интерфейса (localhost:8791) с полями «ПРОВЕРИТЬ» и «ПОДКЛЮЧИТЬ КОШЕЛЁК», фильтром «ТОЛЬКО RH», строкой «ТЫ В СПИСКЕ У 4 КОЛЛЕКЦИЙ · ВПЕРЕДИ 4 ЗАКРЫТЫХ СТАДИЙ, ПРОВЕРИМ НА СТАРТЕ», блоком «HOT ТРЕНЧЕР МИНТЫ НА 7 ДНЕЙ ВПЕРЕД · ИДУЩИЕ НЕ СТАРШЕ 10 МИН» и переключателем сетей ETH / RH (Robinhood Chain) [[nft-c0253]].
- В выдаче скрина — карточки StonkHuman (97/4444, публичный через 4 ч 36 м, WL COMMUNITY / PUBLIC FREE ×3, 3 B PYHI), 9toDino (0/5555, WL открывается 10.08 15:00 UTC, WL FREE ×1, HOLDER FREE ×1, PUBLIC FREE ×2), Ronks (0/4444, GTD 0.000349 ×2, публичный 0.000349, WL открывается 10.08 16:00 UTC), Robinhood Rejects (0/1000, WL 0.0027 ×5, публичный 0.004 ×5, WL открывается 15.08 20:00 UTC) [[nft-c0253]].
- Ссылка на коллекцию: https://opensea.io/collection/stonkhuman/overview [[nft-c0253]].
- По словам FroZi, API-ключ OpenSea он получил, запросив его как разработчик; кредиты ограничены [[nft-c0253]].

## neverfuckingtrade.com: каталог и статусы WL

Основной сайт запущен 11.08: https://neverfuckingtrade.com/ — «вам покажет где у вас есть вл», проверка через кнопку Main only [[nft-c0263-06]].

Предложения тестеров (wdnad): локальное кеширование, вместо автоматических чеков — одна проверка за заход на сайт плюс кнопка «речек», и подключение нескольких кошельков в один из последних пунктов роадмапа [[nft-c0263-06]].

Раздел /whitelists (20.09) — каталог WL-форм, виден всем пользователям, без «кассеты» [[nft-c0498]]:

- бесплатно можно добавить только 3 проекта, и только те, где форму уже заполнил и получил WL [[nft-c0498]];
- список ведётся полуавтоматически через Claude (по подписке) [[nft-c0498]];
- после отметки «applied» запись уезжает в другую вкладку [[nft-c0498]].

Удаление карточек (26.09): Bnd попросил перманентное удаление коллекций для пользователя/кошелька, чтобы состояние WL-стадий не сбрасывалось после рефреша — «какой-то пидарас наклепал хуйни и после каждого захода на сайт эти коллекции вновь и вновь появляются»; предложил две функции — убрать временно и убрать перманентно [[nft-c0537]]. FroZi сделал модалку с двумя вариантами: HIDE («gone until you reload the page») и REMOVE FOREVER («this browser never shows it again, not even after a hard refresh») [[nft-c0537]].

Фильтр Real Builders (27.09): на скринкасте — тёмная тема, вкладки MINTS / WHITELISTS / RAFFLES, строка «CONNECT A WALLET, THEN SIGN IN WITH OPENSEA», фильтры по газу и редкости (IMMORTAL, LEGENDARY, EPIC, RARE, UNCOMMON, COMMON), секция «ROBINHOOD CHAIN · 41 PROJECTS» с карточками DuckHood, Pixel Chimps, Bell Street, Folks, Poodle In The Hood, Fluffberg и таймерами WL/PUBLIC OPENS IN [[nft-c0541]]. Механика проверки, по словам FroZi: «мы пишем что пообщались с челом и посмотрели что у него продукт есть который работает» — риск это не отменяет [[nft-c0541]].

Ограничение по X (07.10): сайт не показывает WL в коллекции, если не привязан Twitter — «отображает она в лоу сигнал… потому-что они не законектили твитак» [[nft-c0599]].

Статистика заявок (02.11): на вайтлист основного сайта 1635 заявок с 29.10 по 02.11; выявлено 9 групп, где несколько ников подавали с одного IP (всего 47 ников), самых подозрительных FroZi банит [[nft-c0713]]. Max Wayld: «Щас загрузим 160 тысяч» и просьба отключить проверку по X на пару часов; hh: 15к ждут апрува; FroZi будет выбирать квоты с нормальными просмотрами и кошельками [[nft-c0713]]. Max также заметил, что на Neverfuckingtrade Асати сливал WL сразу, а холдеры остались [[nft-c0713]].

## PnL-трекер на OpenSea OAuth

neverfuckingtrade.com/pnl показывает нереализованный PnL; подключение идёт через OAuth OpenSea, а не через коннект кошелька [[nft-c0556]].

- На вопрос Max, можно ли посмотреть без таких подключений: «да анариал. потому-что оно квоту тогда мою хавать будет» [[nft-c0556]].
- По словам FroZi: «по факту ты просто аутх опенсийное даешь. Это безопасно. К нам крипто царь конектил свой кош с лямом баксов» [[nft-c0556]].
- Обсуждение масштабирования: Nikita Asati иронично предложил «нафармить 100000000 апи ключей», FroZi спросил, можно ли делать это автоматически через Claude, Антон палыч ответил, что Claude может написать код; FroZi — каждый API-ключ надо ставить под прокси [[nft-c0556]].
- К ссылке на /pnl приложен скрин окна подписи с красным алертом «Please process the alert before signing» и кнопкой «Ignore all» — типовой фишинг-паттерн, подписывать такое не надо [[nft-c0556]].

## Подписка и инфраструктура

- Подписка на сайте считается в процентах от стоимости «кассеты»: «25 % например. И чем дороже касеета тем дорож пас на месяц» [[nft-c0593]].
- Серверы: Max Wayld — «Только Netcup брат» (без раскрытия контекста) [[nft-c0541]].
- Claude используется и для полуавтоматического ведения каталога WL [[nft-c0498]], и обсуждается как средство генерации кода для автоматизации API-ключей [[nft-c0556]].

## Выводы и правила

- Проверять свои WL проще всего подключением кошелька к neverfuckingtrade.com и Stonkhuman; статус по коллекции не отобразится, если не привязан X — это «лоу сигнал», а не отсутствие WL [[nft-c0263-06]] [[nft-c0599]].
- В /whitelists бесплатно вносится максимум 3 проекта, и только те, где форма заполнена, а WL уже получен; после «applied» запись уходит в отдельную вкладку [[nft-c0498]].
- Мусорные коллекции в каталоге убираются через REMOVE FOREVER — скрытие переживает хард-рефреш, HIDE работает только до перезагрузки [[nft-c0537]].
- Для чекера WL списки тянуть через OpenSea API по коллекциям, а не через контракт; каждый API-ключ ставить под прокси, иначе квота выжигается [[nft-c0348-03]] [[nft-c0556]].
- PnL смотреть через /pnl по OAuth OpenSea: кошелёк не коннектится, квота сайта не тратится [[nft-c0556]]. Любую подпись с красным алертом и кнопкой «Ignore all» не подтверждать [[nft-c0556]].
- Zyper: ~$50/мес с промокодом на $10, лимит 500 кошельков на запуск заполнения, дальше — повторный запуск; для капчи использовать API [[nft-c0348-03]].
- Фильтр Real Builders — это разговор с авторами плюс проверка работающего продукта, а не гарантия; риск остаётся [[nft-c0541]].
- При массовых заявках на WL (1635 за 29.10–02.11) отслеживать мультиаккаунты по IP: 9 групп / 47 ников ушли в бан; квоты выдаются по просмотрам и кошелькам [[nft-c0713]].
- Wallchain как чекер использовать осторожно: цена застревает, конфиг менялся с $2.47 на $0.74, публичный доступ; оценка FroZi — «помойка» [[nft-c0348-03]].
- Проверять контрагента по профилю Telegram (дата регистрации, страна, App Store установки) — несоответствия вроде Thailand + Kyrgyzstan App Store сразу отсекают [[nft-c0321]]; approvals на дорогие NFT периодически отзывать через сервисы типа nftsaresafu.xyz [[nft-c0537]].
