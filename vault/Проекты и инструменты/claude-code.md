# Claude Code

**Что это:** Терминальный агент Anthropic для работы с кодом и автоматизации задач: запускается в tmux, поддерживает MCP, hooks, computer use и флаг `--dangerously-skip-permissions`; в чате используют для билда проектов, написания крипто-инструментов, анализа данных и конспектов.

## Итог

Claude Code — активно используемый в чате инструмент для кодинга, автоматизации и анализа (от билда проектов до аудио-конспектов), но часть участников предпочитает альтернативы: Max — Cursor, ProstoXleb для крипты — DeepSeek. Основные риски: официальная недоступность в РФ и, по непроверенным данным, баны за настройку VPN через ИИ, а также попадание приватных ключей в контекст при `--dangerously-skip-permissions` — в чате это закрывают хуками и шифрованием. Статус: рабочий и развивается — по слухам, Anthropic добавляет co-op-режим.
