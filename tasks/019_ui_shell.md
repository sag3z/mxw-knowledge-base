# Задача: новый каркас сайта, панель разговора, карта по веткам

Сначала прочитай `tasks/DESIGN.md` — это обязательные правила. Не читай `.llm_env`/`.openrouter_key`, не читай `tasks/*.log`, НЕ открывай PNG.

Текущий фронт — `app/index.html` (~1300 строк, всё в одном файле): карта force-graph с двумя видами (ветки/смысл), панели поиска, чата, статей, активностей, «кто в чём», тем, панель разговора с режимами «Главное/Без флуда/Всё», медиа, стример-мод. Сервер — `app/server.py` (эндпоинты `/api/graph`, `/api/conv`, `/api/search`, `/api/chat`, `/api/articles`, `/api/article`, `/api/find_article`, `/api/events`, `/api/experts`, `/api/trends`, `/api/media`). Логику бери из старого файла, но перекладывай в новую структуру и новый вид.

## Сделать в этой задаче
1. Каркас `app/web/` по DESIGN.md: левая боковая панель в стиле claude.ai (разделы + место под «Недавние» чаты — список наполнит задача 020, сейчас пусто), роутинг по hash, drawer, `api.js` (пока только серверный режим, но с точкой расширения для автономного), `ui.js`, `style.css`. Библиотеки локально в `app/web/lib/`. Сервер: `/` → `app/web/index.html`, статика `/web/...` (только внутри `app/web`, защита от `..`), старый фронт на `/old`.
2. **Панель разговора (drawer)** по DESIGN.md: заголовок разговора (первое предложение выжимки), строка мета (дата и время начала–конца, ветка, категория, «N сообщений», «⭐ ценное» если keep); выжимка; блок схемы (если есть) с русскими названиями типов; переключатель «Главное · Без флуда · Всё» (логика как в старом, поле `show/noise/hit` с сервера) с подсказкой при наведении, что значит каждый режим; сообщения: автор (или псевдоним), время, цитата-ответ «↩ …», текст с переносами и кликабельными ссылками (открывать в новой вкладке), медиа (как в старом: сетка фото с просмотром, аудио, кружки, видео, файлы с предупреждением), расшифровки свёрнуты «показать расшифровку». Свёрнутые группы «… ещё N сообщений» — заметная, но тихая кнопка. Внизу панели кнопка «💬 Спросить ИИ про этот разговор» → `#/chat` с контекстом (pin), сам чат делается в задаче 020 — пока просто переход с параметром. Также `?article=` — ридер статьи (markdown, ссылки `[[разговор]]` открывают разговор в этом же drawer с кнопкой «назад», `[[Статья]]` — статью), заголовок статьи + мета (категория, период, сколько источников).
3. **Карта** (`#/map`): два вида, переключатель-сегмент вверху «По темам · По веткам» (по умолчанию «По темам»), с подсказкой: «По темам — похожие по смыслу разговоры рядом, независимо от ветки чата».
   - **По веткам** — как в старом режиме «ветки» (предрасчёт d3, зафиксированные позиции, круги веток кольцом, подписи веток над кругами).
   - **По темам (смысловой вид) — переделать, чтобы был компактным и аккуратным**, сейчас он рыхлый и с наползающими подписями. Новый вид — «острова тем»: каждый кластер (`clusters`/`layout.k`, 30 штук) — плотный круг из своих точек (упаковка внутри кластера: синхронная d3-симуляция `forceX/forceY` к центру кластера + `forceCollide`, без пустот), круги кластеров расставлены вплотную друг к другу без перекрытий (центры — от UMAP-медиан `clusters.x/y`, потом `forceCollide` по радиусу кластера, чтобы похожие темы остались соседями, но без пустого пространства). Под каждым кластером — мягкая подложка-круг (поверхность `#171a21`, граница `#272b35`), название кластера — внутри круга сверху или по центру, крупно и читаемо (13–15px на экране независимо от зума, с подложкой; у мелких кластеров — показывать при приближении), под названием мелко «N разговоров». Точки цветом категории. Наведение на кластер — подсветка его подложки и tooltip с `descr`. Клик по названию кластера — список его разговоров (заголовки, дата) в drawer; клик по точке — разговор.
   - **Названия кластеров понятнее**: сейчас многие — перечисления проектов («Cassette, Never Fucking Trade, Wobz»). Добавь в `layout.py` флаг `--rename` с новым промптом для DeepSeek: «понятное название темы для обычного участника чата, 2–4 слова, по сути (механика/тип активности), не перечисляй больше одного проекта; descr — одно предложение, о чём разговоры» — и перезапусти `python layout.py --rename` (координаты и состав кластеров не пересчитывать — только имена; если layout.py пересчитывает всё — сделай, чтобы `--rename` трогал только названия). LLM-вызовы разрешены (30 штук).
   Мусор не показывать (и кнопку «мусор» убрать). Над картой — строка пояснения «Каждая точка — разговор. Цвет — тема, размер — сколько сообщений. Нажми на точку, чтобы прочитать». Легенда категорий справа сверху (клик — скрыть/показать, с подсказкой). Tooltip при наведении: заголовок разговора, дата, «N сообщений». Клик — drawer. Таймлайн внизу (гистограмма + слайдер + ▶) с подписью «Перетащи, чтобы увидеть, как росла база» и датой.
4. Разделы `#/events`, `#/people`, `#/topics`, `#/articles`, `#/chat` — пока заглушки по DESIGN.md (заголовок + пояснение + «скоро»), КРОМЕ `#/events`: перенеси доску активностей в новый вид — карточки событий по группам «Идёт сейчас / Скоро / Позже / Прошло (свёрнуто) / Без даты (свёрнуто)», фильтры в одну строку над списком (тип, сеть, поиск по проекту), карточка: дата крупно слева, бейдж типа по-русски, **проект**, описание, «источник: <заголовок разговора>» (клик → drawer).
5. Стример-мод в шапке, применяется ко всему, запоминается.
