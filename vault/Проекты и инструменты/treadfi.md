# TreadFi

**Что это:** Агрегатор для торговли перпами с собственным терминалом и оптимизацией торговли — по словам Макса, остальные агрегаторы «просто агрегируют». У проекта была программа поинтов за торговлю перпами; токен после TGE 16.09.2026 торгуется на Hyperliquid.

## Что говорили в чате

- 2026-07-03: TGE TreadFi анонсировался на 21 июля вместе с GRVT (фактически прошёл позже — 16 сентября) [[important-c0006]]
- 2026-09-15: TGE назначен на 16.09 в 16:00 МСК — клейма не нужно, токены придут на кошелёк сразу, продать можно на Hyperliquid [[perps-c0017]]
- 2026-09-15: По пересланному мнению El Muar, перпы под TreadFi фармились ботами, а поинт за $1–2 даст кешбек за сожжённый газ [[perps-c0017]]
- 2026-09-16: По пересланному сообщению El Muar, после TGE токен открылся на ~70 млн$ (метрика не уточнена), продать было легко по 30–40 млн$ [[perps-c0019]]
- 2026-09-16: glimjke сделал вывод из TGE: на дропах в первую свечу надо продавать через стакан [[perps-c0019]]
- 2026-10-26: По мнению Макса (в контексте анонса агрегатора Jumper), из агрегаторов выделяется TreadFi — у него свой терминал и оптимизация торговли, остальные просто агрегируют [[perps-c0043]]

## Итог

TGE состоялся 16.09.2026 без клейма, с возможностью сразу продать токен на Hyperliquid — по словам участников, на старте легко выходило по оценке $30–40 млн. Проект после TGE активен и выделяется среди агрегаторов собственным терминалом; нюансы — ботовый фарм перпов (по словам El Muar) и непроверенные метрики оценки.
