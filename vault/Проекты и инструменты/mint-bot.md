# mint-bot

**Что это:** Боты и скрипты для автоматического минта NFT и проверки вайтлистов, обсуждавшиеся в чате MXW: бот MXW для ленты минтов, самописный Python-бот wdnad, сервис FroZi для проверки элигибельности кошельков и ИИ-подход к написанию минт-софта.

## Что говорили в чате

- Бот MXW несколько дней не показывал минты: X-аккаунты, с которых он парсил данные, не работали; Max обещал обновить. FroZi выиграл FCFS у just_t00ns (минт 20-го числа). [[nft-c0107]] (2026-07-18)
- wdnad собрал Python-скрипт минт-бота: прокси и приватники, при старте спрашивает реф-код и число кошельков, задержки меняются в конфиге; по его словам, FCFS выпадает много и для этого нужен минт ботами — руками почти никто не купит. [[nft-c0263-09]] (2026-08-11)
- Для проверки WL FroZi сделал сервис neverfuckingtrade: кошелёк подключается к OpenSea и показывает, где есть WL; по его словам, коннект безопасный. Бот Asati — для уведомлений о постах, не для снайпа, задержка около 3 с. [[nft-c0263-09]] (2026-08-11)
- По словам sprintray, вслепую минтить нельзя: у каждой коллекции свои slug и названия фаз, поэтому в софт задают триггер-фразу (например «WL») и slug коллекции. FroZi предлагает сайт, куда подключают до 10 кошельков и видят, где есть элиг. [[nft-c0287-01]] (2026-08-17)
- Александр разобрался с ботом, закинув архив в Claude и попросив помочь с установкой; glimjke спрашивал про минтер Grass, где написано использовать только бернеры. [[nft-c0287-01]] (2026-08-17)
- FroZi пробовал минтить ботом с домашнего ПК (не с сервера): задержка ~200 мс, но не успел запустить. По словам ArteMm, газ не определяет FCFS, но нужен, чтобы попасть в блок секвенсера; один участник ошибся с газом на 0.6% (забыл base fee), 300 NFT не заминтили из-за ошибки. [[nft-c0287-07]] (2026-08-17)
- По словам Max, готового минт-софта нет — wdnad написал свой; Max советует давать ИИ по одному действию и объединять параллельные сессии. wdnad собрал скил, и софт теперь пишется одной командой; Max не успел доделать свой софт для клейма на Ink (на Ink на тот момент 101 панк). [[nft-c0342-01]] (2026-08-24)
- Кейс ошибки бота: при проверке eligibility для GAME WL на OpenSea бот принял временный ответ «not eligible» на границе стадий за окончательный и остановился; по признанию на скрине, кошелёк был eligible, а коллекция потом полностью заминтилась. [[ai-c0226]] (2026-08-31)

## Итог

Готового минт-софта в комьюнити нет — боты самописные (wdnad, Max, FroZi), и на FCFS они считаются необходимыми. Риски: ошибки логики (кейс GAME WL — упущенный минт при eligible-кошельке), задержки при запуске с домашнего ПК (~200 мс), работа с приватниками и ограничения вроде «только бернеры» у некоторых минтеров; бот MXW для ленты минтов периодически ломается из-за источников парсинга.
