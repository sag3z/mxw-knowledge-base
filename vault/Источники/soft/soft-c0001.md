# Софты · c0001 · 2026-08-25 11:16

**Выжимка:** Ветка только для софтов: главные сейчас — сборщик токен-аккаунтов и бабок с Solana-кошельков, NFT-минтер, чекер OpenSea-вайтлистов, ИИ-скилл с примерами абузов, хаб OxSprintray и реген ZCash-кошельков. Хаб sprintray (soft-hub на GitHub) собирает софты в одном UI с локальной зашифрованной БД, реферальной цепочкой и патчами; есть патчи под Manta waitlist и Abstract-хаб (Ads-профили, поинты, Gigaverse, Tollan). Макс выложил свой минт-софт под Robinhood, Ink и ETH mainnet с большими задержками; его нужно настроить под себя, добавив кошельки и прокси.

**Схема** (bots_soft, multiaccount): Max Wayld закрепил правило ветки: только софты, которые проверены или написаны самостоятельно, остальное удаляется. В закреплении перечислены сборщик токен-аккаунтов и SOL-средств, NFT-минтер, чекер вайтлистов OpenSea на любое число аккаунтов, ИИ-скилл для написания абузов, хаб sprintray (тестнеты, Abstract), регистрация кошельков ZCash и джейлбрейк-скилл для форм. Затем он переслал пост sprintray о soft-hub (шифрование БД, рефцепочки, патчи из GitHub), патч для WL Manta Network и Abstract-хаб на AdsPower, где hh жалуется, что сессии приходится обновлять каждую неделю. Свой минт-софт с большими задержками, по его словам, загружает 1000 аккаунтов около 13 часов; на вход нужны адреса кошельков (не приватники) и список прокси.
