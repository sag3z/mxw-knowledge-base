# Инструменты вайбкодера: CLI, IDE, MCP, скиллы и окружение

**Кратко**

Ветка про рабочий сетап вайбкодера: Макс (Max Wayld 福) свёл всё в видеогайд на 1:13:40 — Claude и Codex через CLI и IDE, скиллы, MCP, память, домены, хостинг, ключи и fail2ban, а вторую часть обещал «через пару неделек» [[life-c0168]]. Позже он же заявил, что старые гайды неактуальны и он работает только через CLI в Windows Terminal [[life-c0536]], а ещё позже — что идеал не CLI, а среда с сохранением контекста вроде Orca [[soft-c0033]]. Параллельно чат разбирал MCP-связки Claude + Codex по четырём схемам с прямым минусом: ответы второго агента жрут лимиты обеих подписок [[ai-c0229]]. Отдельный пласт — скиллы: архив MXW-FormLab на 625 файлов с инструкциями, примерами софтов и практиками мультиаккаунтинга [[soft-c0033]]. Плюс мелочи окружения: UI-библиотеки, голосовой ввод по хоткею мыши, прошивка колонки Яндекса за ~$0.6 и кросс-компиляция с macOS под Windows [[ai-c0041]] [[crypto-c0083]] [[life-c0743]] [[ai-c0135]].

## CLI, IDE и терминал

Базовый сетап по гайду Макса: установка CLI Claude и CLI Codex в консоли, Windows Terminal и OpenCode; отдельный блок — «Как работать с ИИ: CLI и IDE. Их полная настройка + скиллы и MCP + память» (таймкод 07:33) [[life-c0168]]. Он же подчёркивал, что кроме Claude и Codex сейчас «ничего не существует» (05:07) [[life-c0168]].

16 сентября Макс заявил, что старый гайд неактуален: «я всё через консоль через CLI только», Windows Terminal и никаких костылей; актуальный видеогайд — https://t.me/maxycrypto/522 [[life-c0536]]. На скрине к сообщению — многооконный интерфейс агента с панелями Claude Code / Opus 5 и gpt-6-astra и отчётами по нескольким проектам [[life-c0536]].

По развитию Qwen 3.8 вышло много форков и версий, которые ускоряют модель или делают её легче, — ProstoXleb сам за этим не следит [[ai-c0229]].

## MCP-связки: Claude + Codex

Скрин от участника разбирает четыре варианта совместной работы двух агентов [[ai-c0229]]:

- **А. Две независимые консоли, обмен через файлы.** Вкладка с Codex рядом с вкладкой Claude: нулевая связность, полный контроль, у каждого свой промпт; минус — задания переносятся руками [[ai-c0229]].
- **Б. Codex как MCP-инструмент внутри сессии Claude:** `claude mcp add codex -- codex mcp`. «Красиво», но ответы Codex падают в контекст Claude, то есть одна задача жрёт лимиты обеих подписок сразу [[ai-c0229]].
- **В. Claude как MCP-сервер внутри Codex:** `claude mcp serve` (команда проверена в версии 2.1.252). Зеркальная картина с теми же минусами [[ai-c0229]].
- **Г. А + тонкий протокол обмена** — за этот вариант автор скрина и голосует [[ai-c0229]].

Тот же минус MCP озвучил ImmuneFOMO: «через MCP тебе Клод написал, что ты получаешь весь контекст в чат», а в случае detached-сессии в терминале можно сказать агенту доставать только нужное [[ai-c0230]]. По его словам, агент может запускать сессию фоном, а потом из файла истории фонового диалога доставать всё необходимое — «по сути не сильно отличается от общения через файл» [[ai-c0230]].

## Скиллы и память

16 октября Макс выложил улучшенный скилл для ИИ, который «закрывает» написание софтов под абузы: в папке — примеры софтов, инструкции, практики мультиаккаунтинга и сам скилл; запускать сессию нужно сразу из этой папки, чтобы дать больше контекста [[soft-c0033]]. Состав архива MXW-FormLab-new.zip — 625 файлов, среди них `.agents/skills/form-farm/` с `SKILL.md` и `references/01-recon.md` … `09-gotchas.md`, кейсы (`apps-script-404.md`, `closed-whitelist-410.md`, `decorative-vs-real-field.md`, `free-captcha-fallback.md`, `two-opposite-409s.md`), а также `AGENTS.md`, `CLAUDE.md` и `.gitignore` [[soft-c0033]].

По его словам: Opus 5 и Opus 5.5 такие задачи закрывают без проблем, на GPT 5.6 «тоже должно работать»; китайские модели, Gemini и Grok он не тестировал; на Fable такие запросы могут легко флагаться, на Astra — вероятно тоже, поэтому «модельки попроще юзайте, там всё равно задачи лёгкие» [[soft-c0033]]. Файл `agents.md` универсален, но для Claude, Gemini и Qwen есть отдельные версии из-за их специфики [[soft-c0033]].

Ключевой совет по окружению: работать не в CLI и не в консоли, а там, где сохраняется контекст и диалог — «лучший вариант это Orca сейчас»; в приложениях Claude/GPT есть системные промпты, которые могут мешать [[soft-c0033]].

## Периферия и мелкие хаки

**Голосовой ввод.** FroZi показал на видео: ввод привязан к хоткею на мыши, речь сразу уходит в Claude и может сразу переводиться на английский; минус — хоткей иногда нажимается случайно и отправляет «рандомную хуятину» [[crypto-c0083]].

**Прошивка колонки Яндекса.** Макс (пересланное от densharik) прошивал колонку по сборкам из чата через откат версии; тема развивается на https://hackalice.me/, там же сообщество в ТГ [[life-c0743]]. Во всём процессе безотказно помогала deepseek v4.1 Flash от 17 октября, подключённая в OpenCode через fal.ai (у fal.ai есть прокси на OpenRouter и все модели); на всё ушло $0.6 [[life-c0743]]. На колонке теперь Android TV 9 — можно ставить лёгкий лаунчер, VPN, YouTube и кинопросмотрщики [[life-c0743]]. Видео — «просто забавы ради», на нём светодиодная матрица колонки мигает под трек [[life-c0743]].

**Кросс-компиляция.** Разработчик в тех-чате описывает боль: настроить среду на macOS для кросс-компиляции под Windows, не выдёргивая вручную глубоко вложенные хедеры и не правя каждый раз CMake/стек-файлы под свой мак [[ai-c0135]]. Max похвалил присланный роадмап: «Ебать ты роадмап расписал хороший», и добавил, что «это можно как-то сильно лучше реализовать», сославшись на https://t.me/codeonvibes/104 [[ai-c0135]].

**Сбои ChatGPT.** У Timur сообщения зависали в «В процессе» на 10 минут и исчезали после обновления страницы — 5 раз подряд; чат не ожил, помогло создание нового чата с перенесённым туда контекстом [[ai-c0363]].

**Новости без подтверждения.** По пересланному посту «Доктор GPT», Anthropic работает над кооперативной работой в Claude Code, на странице Projects появился блок «Недавняя активность»; официального подтверждения в ветке нет [[ai-c0499]].

## Противоречия и эволюция взглядов

- **CLI против IDE/среды с контекстом.** 16 сентября Макс: работает только через CLI в Windows Terminal, гайды со «костылями» устарели [[life-c0536]]. 16 октября: «в идеале работать не в CLI не в консоли, а где-то где контекст и диалог сохраняется… Лучший вариант это Orca сейчас» [[soft-c0033]].
- **Cursor против Claude Code.** 2 августа Макс: Claude Code «залупа», Cursor «пизже в миллиард раз» [[ai-c0157]]. При этом в апрельском гайде и в сентябрьском описании сетапа база — CLI Claude и Codex [[life-c0168]] [[life-c0536]].
- **MCP: удобство против контекста.** MCP даёт агенту «весь контекст в чат» [[ai-c0230]], и в схеме с Codex-как-MCP это прямо названо вредом при ограниченных лимитах подписок [[ai-c0229]]. Альтернатива — detached-сессия + выборочное чтение файла истории [[ai-c0230]].

## Выводы и правила

1. **Стартовая точка — гайд Макса** (https://t.me/maxycrypto/522): установка CLI Claude/Codex, Windows Terminal, OpenCode, скиллы, MCP, память, домены, хостинг, ключи и fail2ban в одном видео [[life-c0168]] [[life-c0536]]. Учитывать, что сам автор называет прошлые версии наполовину неактуальными [[life-c0168]].
2. **Не смешивать агентов через MCP без нужды.** Схема «Codex как MCP в Claude» и обратная тратят лимиты обеих подписок; предпочтительный вариант — две консоли + тонкий протокол обмена [[ai-c0229]].
3. **Контекст беречь:** либо MCP с полным сливом контекста, либо detached-сессия и выборочное чтение истории [[ai-c0230]].
4. **Скиллы держать папкой проекта** с примерами и `agents.md`; запускать сессию из этой папки, а не тащить инструкции в чат [[soft-c0033]]. Под флаги лучше брать модели попроще (Fable/Astra — риск), рабочие лошадки по опыту Макса — Opus 5/5.5 и GPT 5.6 [[soft-c0033]].
5. **Домены:** NameCheap (крипта + карта) или SpaceShip (только карта); хостинг — GitHub Pages или Vercel [[life-c0168]].
6. **Оплата ИИ:** web3-карта либо сторонние продавцы (GGSel, Plati, Funpay) — по гайду Макса [[life-c0168]]; в его же кейсе с колонкой хватило $0.6 через OpenCode + fal.ai [[life-c0743]].
7. **Голосовой ввод по хоткею мыши** ускоряет работу с Claude и сразу переводит на английский, но легко отправить случайный текст — держать хоткей подальше от частых нажатий [[crypto-c0083]].
8. **Мелкий софт под себя проще сгенерить**, чем адаптировать чужой: нативная macOS-аппка на Swift через Astra быстрее, чем поиск тудушника с MCP и виджетами [[ai-c0261]].
