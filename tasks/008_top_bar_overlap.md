# Задача: панель разговора перекрывает кнопки верхней панели

Меняй только `app/index.html`. Не читай `.llm_env`/`.openrouter_key`, не читай `tasks/*.log`, НЕ открывай PNG.

Когда открыта правая панель `#panel` (разговор/поиск/статья), она перекрывает правую часть `#top`: не видно и нельзя нажать кнопки «Поиск», «Дайджест», «База знаний», «мусор», «вид», «ники». Сделай так, чтобы при открытой панели `#top` сжимался до левой границы панели (например, класс на body `panel-open` и `#top { right: <ширина панели> }`, с учётом того, как задана ширина панели в CSS — посмотри), а кнопки при нехватке места переносились на вторую строку или уменьшались (компактные отступы, без текста — только иконки при ширине < N). Легенда/таймлайн не должны съезжать под панель тоже — проверь `#timeline` (right) аналогично.

Проверка: `node --check` на инлайн-скрипте; скриншот headless Edge с открытой панелью через deep-link `http://127.0.0.1:8765/#conv=nft-c0083-01&anon=1` в `data/map_topbar.png` (не открывать). Сервер перезапускать не нужно (статический файл).
