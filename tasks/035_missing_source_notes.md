# Задача: заметки-источники для разговоров, на которые теперь ведут исправленные ссылки

Меняй `factcheck_apply.py` и при необходимости `build_vault.py` (только вынести/переиспользовать функцию записи заметки-источника — поведение `sources` не менять). Не читай `.llm_env`/`.openrouter_key`, не читай `tasks/*.log`, НЕ открывай PNG. LLM не нужен. Не трогай `factcheck.py` и идущий прогон `factcheck.py --all`.

## Проблема
`factcheck_apply.py` применён к 10 статьям пилота. В статье `vault/Безопасность и скамы/Telegram-подарки и маркетплейсы баг MRKT, украденные гифты и гаранты.md` неверные ссылки `[[life-c0254]]` заменены на `[[life-c0255]]` — это правильный разговор (там getgifts и заморозка лотов), но `check_vault.py` показывает 7 битых ссылок: заметки `vault/Источники/life/life-c0255.md` нет. Причина: заметки-источники `build_vault.py sources` пишет только для полезных разговоров, а `life-c0255` при разметке получил verdict `drop`.

## Сделать
1. Функцию записи одной заметки-источника из `build_vault.py` (`cmd_sources` — там формируется markdown разговора: заголовок, мета, выжимка, схема, сообщения с выделением ключевых) вынеси в отдельную функцию `write_source_note(topic, conv)` и используй её в `cmd_sources` (вывод `sources` не должен измениться — проверь на 3 файлах побайтно до/после). Для drop-разговора без выжимки — в заметке вместо выжимки строка «Разговор не прошёл первичную сортировку, но на него ссылается проверенная статья».
2. В `factcheck_apply.py`: перед заменой/добавлением ссылки на `correct_source`, если заметки нет — создать её через `write_source_note` (и записать в лог «создана заметка-источник …»). Это же в `--dry` — только сообщение.
3. Исправь текущее состояние: создай заметку для `life-c0255` (и для любых других целей битых ссылок, если `check_vault.py` их покажет и они являются разговорами `<short>-<conv>` из базы). Затем `python build_vault.py index` и `python check_vault.py vault` — битых ссылок 0.
4. Сайт: `app/server.py` `/api/conv` для drop-разговора уже отдаёт его (проверь `curl /api/conv?id=life-c0255` → 200) — ничего не менять, только проверить.
