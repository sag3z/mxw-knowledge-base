# ABS-FARM-TOOL (safe): хаб для многоаккаунтного фарма в экосистеме Abstract

- Источник: ветка крипта_работа_проекты, сообщение #30160, files
- Категория: tools
- Теги: abstract, фарм, мультиаккаунт, adspower, webshare, gigaverse, tollan, dyli

## Кратко
Архив ABS-FARM-TOOL-safe.zip (190 файлов). Список файлов полностью совпадает с архивом #35332 из ветки «софты», поэтому это тот же инструмент. Главный вывод: фермерский хаб для аккаунтов в проектах Abstract (Gigaverse, Tollan, Dyli, abstract-upvote).

## Главное
Структура и назначение те же, что в конспекте #35332: модули hub_* для аккаунтов, прокси, профилей подписи, учётных данных, расписания, Telegram-уведомлений и балансов; папка projects с модулями abstract-upvote (сессии AGW, голосования, ежедневные чек-ины и задания Dyli, AdsPower и webshare-прокси), giga (gigaverse_bot, автопилот, веб-интерфейс инвентаря) и tollan (массовые действия по аккаунтам с прокси). В архиве есть тесты, wiki и аудит бота Gigaverse от 2026-07-24 (docs/SPR1NTRAY_GIGAVERSE_BOT_AUDIT_2026-07-24.md). По именам файлов — один аккаунт на один прокси и один браузерный профиль.
