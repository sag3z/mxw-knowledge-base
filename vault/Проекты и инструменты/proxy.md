# Прокси (proxy)

**Что это:** Инструмент смены IP/региона, в чате применяется для обхода гео-ограничений, регистрации и прогрева аккаунтов, ферм и массовых заявок. Упомянутые сервисы: Webshare (дешёвые датацентр-прокси), Proxyshard (резидентские и мобильные), CLIProxyAPI.

## Итог

Прокси — стандартный рабочий инструмент чата: дешёвые датацентр (Webshare) для софтов и абузов, резидентские/мобильные (Proxyshard) для регистрации и «тёплых» аккаунтов. Риски: платформы отслеживают регистрацию через прокси (капчи, приостановки X, анти-сибил), а Webshare, по словам Max, банит аккаунты после непродлённых прокси. Для массовых заявок обязательно включать прокси в конфиге — иначе лимит ~6 заявок на IP режет всё ошибкой 429.
