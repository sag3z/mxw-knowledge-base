# ТЗ: пересобрать архив MXW и заменить zip в GitHub Releases

Рабочая папка: `C:\Users\fl3xx\Desktop\mics\mxw-kb` (Windows; есть Git Bash, PowerShell, Python 3, `gh` уже авторизован).
Python запускай с `PYTHONUTF8=1`.

## Зачем
Код сайта обновлён и уже лежит на GitHub (ветка `main`). Изменились настройки ИИ: свой выпадающий список моделей, загрузка всех моделей провайдера. Zip в Releases собран до этих правок. Его нужно пересобрать из текущего кода и заменить.

## Шаги
1. Убедись, что рабочая копия чистая по коду: `git status --short`. Должен быть изменён максимум `tasks/TZ_factcheck_agents.md`. Если в коде есть незакоммиченные изменения — остановись и спроси пользователя.
2. Собери архив:
   `PYTHONUTF8=1 python export_static.py`
   Это занимает около 5 минут, получится примерно 1,1 ГБ.
   Результат: папка `dist/MXW-база-2026-11-16/` и `dist/MXW-база-2026-11-16.zip`.
   В конце вывода обязательно должны быть строки:
   - `скан на секреты: чисто` — если там что-то найдено, НЕ заливай, а покажи находки пользователю (сами ключи не выводи);
   - `life-c0175 отсутствует`.
3. Быстрая проверка архива: в zip есть `MXW-база-2026-11-16/Открыть карту.html`, а `zipfile.testzip()` возвращает None.
4. Замени файл в релизе. GitHub выкидывает кириллицу из имён, поэтому залей копию с латинским именем:
   ```bash
   cp "dist/MXW-база-2026-11-16.zip" "$TEMP/MXW-baza-2026-11-16.zip"
   gh release upload v2026-11-16 "$TEMP/MXW-baza-2026-11-16.zip" --clobber --repo sag3z/mxw-knowledge-base
   rm "$TEMP/MXW-baza-2026-11-16.zip"
   ```
5. Проверь:
   `gh api repos/sag3z/mxw-knowledge-base/releases/tags/v2026-11-16 --jq '.assets[] | "\(.name) \(.size) \(.updated_at)"'`
   Должен быть ровно один файл `MXW-baza-2026-11-16.zip`: размер около 1,09 ГБ, дата сегодняшняя.

## Запрещено
- Работать с любыми репозиториями, кроме `sag3z/mxw-knowledge-base`. Не создавать новые репозитории, релизы и теги — только заменить файл в существующем релизе `v2026-11-16`.
- Читать, выводить или куда-либо передавать `.llm_env`, `.openrouter_key` и любые ключи.
- Менять код, `vault/`, `data/`. Коммитить и пушить — только если пользователь отдельно попросит.
- Запускать `factcheck_apply.py` и другие скрипты, которые зовут платные LLM.
