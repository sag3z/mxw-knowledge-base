# Крипта, Работа, Проекты · c0201 · 2026-08-09 22:34

**Выжимка:** sprintray выложил Soft Hub: приложение запускает его софты из одной базы (патчи из GitHub, шифрованная локальная БД, реферальная цепь). Патчи уже есть на checkpoint и на вейтлист Manta Network (локальная модель на телефоне, без подписки по его словам).

**Схема** (bots_soft, multiaccount): sprintray сделал хаб для своих софтов: приложение, которое запускает их централизованно, шифрует БД аккаунтов локально, подтягивает патчи из GitHub по нику и позволяет настроить реферальную цепочку аккаунтов, чтобы софты при первой регистрации строили цепочку рефералов. Есть патч на Checkpoint и патч для WL Manta Network (базовая регистрация), а также готовящийся хаб под фарм XP в Abstract. На вопрос, какую активность накинуть на мульты для фарма XP в Abstract, hh ответил: дейли-клейм в Tollan и стрик апвоутов.
