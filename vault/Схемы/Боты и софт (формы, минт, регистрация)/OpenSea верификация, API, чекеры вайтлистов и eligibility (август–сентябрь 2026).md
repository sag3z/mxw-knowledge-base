Отдельная боль — подпись кошелька на OpenSea сбрасывается примерно раз в 12 часов, из-за чего вайтлисты просто не отображаются, и «починить это никак» (FroZi) [[nft-c0368-07]]. Галочка (верификация) коллекции — не автомат: нужна заявка и объём порядка $50k [[nft-c0372]]. Для проверки eligibility есть чекер из ветки софтов, Max прогонял его через Claude и обещал собрать автономный билд [[life-c0475]]. Параллельно обсуждали ботов на изменение цены до фришки, карточки коллекций от OSnoty и доступы в розыгрыши через NFT [[nft-c0387]], [[nft-c0315]], [[nft-c0368-07]].

## API OpenSea: коллекция, fees, реальный расход

Max Wayld (28.08, 15:21) дал шаблон: `https://api.opensea.io/api/v2/collections/<ID коллекции>`, где ID — слаг или адрес контракта; пример для коллекции `0xc21159f412c294ca2c38f2a9ecaaccf9d93ec929`, у которой слаг совпадает с адресом контракта, у большинства же это слово (`argonauts`, `skyink`) [[nft-c0360-03]].

- Открывается в браузере без ключа и регистрации, подставляется нужный ID [[nft-c0360-03]].
- В ответе ищется блок `fees`: `"fee": 1.0, "recipient": "0x0000a26b...", "required": true` и `"fee": 10.0, "recipient": "0x2bf95e5f...", "required": true` [[nft-c0360-03]].
- Читается так: `required: true` — удержат всегда, деться некуда; `required: false` — по желанию покупателя, на практике примерно половина не платит [[nft-c0360-03]].
- `0x0000a26b...` (мейннет) и `0x07d3a100...` (Ink) — это сама OpenSea, её 1%; всё остальное — автор [[nft-c0360-03]].
- Итог: складываешь все `required: true` — получаешь свой реальный расход при продаже [[nft-c0360-03]].

Два альтернативных способа проверки от того же Max: открыть выставленный токен, нажать Buy Now и не подтверждать — в окне будет разбивка по получателям, ровно то, что уйдёт по факту из самого ордера; либо в обозревателе коллекции зайти во вкладку Contract → Read → функция `royaltyInfo` [[nft-c0360-03]].

- В том же сообщении по софту ZecBit: в него закидывают только свои прокси и адреса кошельков, без приватников; на вопрос wdnad, как без приватников что-то дрейнить, Max ответил обещанием выложить софт, который сгенерирует к кошелькам хендлеры и подставит их в файл, используемый затем во всех остальных софтах; в новых софтах хендлеры будут проставляться автоматически, «можно будет также без ИИ вручную крутить всё» [[life-c0475]].

## Выводы и правила

1. Данные по коллекции — `https://api.opensea.io/api/v2/collections/<slug-или-контракт>`, без ключа; реальный расход при продаже = сумма всех `required: true` в блоке `fees`, 1% из них уходит OpenSea (`0x0000a26b...` в мейннете, `0x07d3a100...` в Ink) [[nft-c0360-03]].
2. Проверять фи, если API неудобен: Buy Now без подтверждения на самой OpenSea либо `royaltyInfo` во вкладке Contract обозревателя [[nft-c0360-03]].
3. Перед проверкой WL — переподписать кошелёк: подпись OpenSea сбрасывается ~раз в 12 часов, иначе WL не отображается, фикса нет [[nft-c0368-07]].
4. WL-чекер по OpenSea брать из ветки софтов, но помнить: Max гонял его через Claude вручную, автоматический билд только обещан [[life-c0475]].
5. Галочка на OpenSea — заявка + объём около $50k; без этого верификации не будет [[nft-c0372]].
6. Перед покупкой WL на стороне (пример: Tatakaefyt, «+2–3 бакса за секунду») проверять наличие WL в своём кошельке после переподписи [[nft-c0372]], [[nft-c0368-07]].
7. Гугл-формы без gmail-авторизации софтом проходятся; формы с обязательным gmail — не брать, экономика не сходится [[nft-c0360-03]].
8. Твит-чеки на дефолтных формах обычно не проверяют, но это абуз с риском: подставляется несуществующая ссылка под рандомный хендл [[nft-c0387]].
9. Проверка коллекций — `neverfuckingtrade.com`; OriginalBrokers считать подделкой Blokyz до доказательств обратного [[nft-c0368-07]], [[nft-c0372]].
10. Доступ в рафлы через NFT-верификацию в Discord (пример: Blupets, Stage с синим фоном) [[nft-c0368-07]].
11. Опускание флора офферами на свои NFT (~20 шт.) — манипуляция, а не торговая тактика [[nft-c0368-07]].
