# Тестнеты и privacy-проекты: Sekai, Fairground, Umia, Orbinum, RiseX (июль–август 2026)

Кратко: с 23 июля по 11 августа 2026 участник sprintray выложил в чат четыре собственных софта под тестнеты — Sekai (Python + Playwright), закрытый тестнет Forte/Fairground, Orbinum (privacy L1) и дельта-нейтральный трейдер для RiseX — и параллельно рассылал софты других авторов (@wthll, @wdnad) через Max Wayld. Механики простые: объёмы → XP (Fairground), активность в Shielded Pool → ORB Credits (Orbinum), прокликивание WL-форм без реальной проверки заданий (Arc, Wreckers, Virion и др.). По Sekai заявлено отсутствие банов «с первого дня тестнета», по Fairground — бесплатный вход при собранных ~1B у проекта. Часть кейсов разобрана скептически: Arc (мост без резервов, рагнувшие щитки), GRVT/EdgeX («краймят»), Hood AI (абуз не сработал).

## Sekai: софт на Python + Playwright

23 июля 2026 sprintray спросил, кто крутит тестнеты Sekai или Fairground, и сразу выложил свой софт под Sekai (проект — https://x.com/sekai_fi) [[crypto-c0146]].

- Репозиторий: https://github.com/spr1ntray/sekai_testnet [[crypto-c0146]]
- Установка и запуск: `python -m venv .venv` → `source .venv/bin/activate` → `pip install -r requirements.txt` → `playwright install chromium` → `python main.py` [[crypto-c0146]]
- По словам sprintray, софт крутится «почти с самого первого дня тестнета» и «ни один акк не отлетел» [[crypto-c0146]]
- Количество аккаунтов под софтом не указано; ссылки на репозиторий в исходной записи не переписаны [[crypto-c0146]]

## Fairground (закрытый тестнет Forte): XP за объёмы

26 июля 2026 sprintray анонсировал закрытый тестнет от Forte (https://x.com/ForteProtocol) — Fairground (https://fairground.fi/), вход по WL-заявке [[crypto-c0153]].

- Механика по его словам: «всё по базе — набиваете объёмы, получаете XP» [[crypto-c0153]]
- Для тех, у кого есть доступ, выложен софт автоматизации активности: https://github.com/spr1ntray/fairground-testnet-bot; перед этим — «продолжаем отрабатывать прокси» [[crypto-c0153]]

Спор о проекте:

- FroZi скептичен: проект, по его словам, трижды переобувался (игровая платформа → ИИ → перпы), при этом собрано около 1B [[crypto-c0153]]
- sprintray не защищает проект («был один пивот из GameFi, собрали почти 1B и нихуя толком не сделали»), но указывает на большую команду — по его пониманию, от 100 до 300 человек, с опытом билдинга; вывод: «заходишь бесплатно и крутишь поинты абсолютно бесплатно» [[crypto-c0153]]
- FroZi: тестнет можно пофармить бесплатно, но ему нужно во что-то верить, чтобы крутить поинты [[crypto-c0153]]

## Umia и остальные: WL-формы, которые прокликиваются

Из того же сообщения #17396 — формы и условия [[important-c0011]]:

- BR0KE B◉_◉KIES на Arc — «интересное», задания не проверяются; кликать по одному, чтобы не ловить ошибку рейтлимита; в конце нужно указать любой твит — он тоже не проверяется [[important-c0011]]
- Hood Pengies — «хуйня», но форма рабочая и прокликивается без проверок [[important-c0011]]
- LuckyCall — 555 штук на эфире, форма доступна, минт через 3 дня на OpenSea [[important-c0011]]
- Wreckers — 10К на эфире с TBA-прайсом, «оч плохо», но форма прокликивается за 3 секунды [[important-c0011]]
- Virion — 1000 на эфире, форму только открыли [[important-c0011]]
- Mibbles, 10kWaysToDie, Folks — перечислены без деталей [[important-c0011]]
- Deadchains — на днях добавят первые ивенты для влов; в Guild of Grime ждать добавления ещё одной игры и спотов [[important-c0011]]
- Arcion — лаунчпад на Arc, форма на ёрли-доступ «просто прокликивается» [[important-c0011]]
- Robinhood Punks — дешёвые (~4$), но за них часто дают вайтлисты в другие коллекции [[important-c0011]]
- The Lost Pixel Gem — фриминт на 10К супплая, влы легко выбиваются через коллабы, но прошлая коллекция зашла плохо, объёмы «буквально нулевые» — не покупать её ради WL [[important-c0011]]
- Hood AI — попытка абуза всей NFT-веткой не сработала («в этот раз … ничего не вышло») [[important-c0011]]

## Выводы и правила

- Sekai: софт ставится через venv + Playwright Chromium, запуск `python main.py`; заявленного отсутствия банов достаточно, чтобы тестировать, но число аккаунтов автор не раскрыл — масштаб фермы неизвестен [[crypto-c0146]]
- Fairground/Forte: участие только при наличии доступа в закрытый тестнет + WL; смысл — объёмы и XP; риски проекта (три пивота, ~1B собранных) признаёт сам автор софта [[crypto-c0153]]
- Orbinum: ориентир на активность в Shielded Pool ради ORB Credits; софт в активной разработке, ждать доп. функции [[crypto-c0163]]
- RiseX: инструмент для тех, кто уже в позиции (дельта-нейтраль), а не рекомендация входить [[crypto-c0163]] [[important-c0011]]
- WL-формы без проверки заданий (BR0KE B◉_◉KIES, Hood Pengies, Wreckers, Virion, Arcion) прокликивать по одному клику — иначе рейтлимит [[important-c0011]]
- Не покупать NFT «под WL», если у прошлой коллекции автора нулевые объёмы (кейс The Lost Pixel Gem) [[important-c0011]]
- По Skew: следить за письмами с инвайт-кодами на подвязку кошелька; актуальная версия софта — 1.5.5 с усиленным антисибил-бэкендом [[crypto-c0205]]
- По Arc: новый мост без резервов и высокие комиссии + рагнувшие щитки — не заводить ликвидность без возможности вывода [[crypto-c0163]]
