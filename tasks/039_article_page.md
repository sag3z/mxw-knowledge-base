# Задача: статья — отдельная страница для чтения + новый список статей

Работай в `app/web/` (`js/articles.js`, `js/conv.js` — сейчас там `renderArticle`/`openArticle`, `js/ui.js` — `linkify`, `js/main.js` — роутер, `style.css`, `js/icons.js` из задачи 038). Сначала прочитай `tasks/DESIGN.md`. Не читай `.llm_env`/`.openrouter_key`, не читай `tasks/*.log`, НЕ открывай PNG. LLM не нужен. Бэкенд не трогай (если без него никак — минимально и опиши в отчёте).

Пользователь: «статьи и разговоры бесят больше всего». Выбрал: статья открывается **отдельной страницей на всю ширину**, как пост в блоге, а не в узкой правой панели (520px).

## 1. Страница статьи
- Маршрут `#/articles?article=<путь>` показывает в основной области раздела «Статьи» страницу чтения вместо списка (drawer для статей больше не используется; для разговоров drawer остаётся). Все места, которые открывали статью в drawer (`openArticle`, `data-act="article"`, `data-act="article-name"` в чате/карте/разговоре/людях), теперь делают `location.hash = "#/articles?article=…"`. Кнопка «назад» браузера возвращает туда, откуда пришёл (в т.ч. в чат). Без `article` — список.
- Раскладка (≥ 1200px): колонка текста max-width 720px по центру свободной области; справа sticky-оглавление 220px («На этой странице», пункты из h2/h3, активный пункт подсвечивается при прокрутке — IntersectionObserver; клик — плавная прокрутка). На 900–1200px оглавление скрыто за кнопкой иконкой `list` в шапке. На < 900px — без оглавления справа, кнопка в шапке.
- Шапка: ссылка «← Все статьи» (иконка arrow-left), хлебные крошки «Раздел» (папка статьи по-человечески), заголовок h1 28px/650 (первый `# ` из markdown или имя файла), мета-строка: категория-чип с точкой цвета, период, «N источников», плашка проверки (`fcPlateHtml` — уже есть) и кнопка «Спросить ИИ про статью» (вторичная, иконка chat; поведение как у текущей кнопки `ask-article`).
- Текст: 16px, line-height 1.7, абзацы с отступом 14px, h2 20px/600 с отступом сверху 32px, h3 17px/600, списки с маркерами вторичного цвета, `blockquote` — полоска слева 3px `#272b35` и вторичный цвет, таблицы — тонкие границы, горизонтальный скролл в обёртке, код — моноширинный на `#1e222b`. Ссылки `#7cb4ff` без подчёркивания, подчёркивание при hover.
- Пометки ⚠ проверки фактов (`fcMarks`, класс `.fc-mark`) — сохранить как есть (с общей подсказкой).

## 2. Ссылки-источники → номера-сноски
Сейчас в тексте сырые `[life-c0417] [nft-c0083-01]` — их очень много, читать невозможно.
- Ссылки на разговоры (`[[life-c0417]]`, `CONV_RE` в ui.js) в статье рендерить как маленький надстрочный номер `<sup class="src">1</sup>` (13px, цвет ссылки, без скобок; несколько подряд — «1,2,3» через тонкую запятую). Нумерация — по порядку первого появления в статье; одинаковый разговор — тот же номер.
- Наведение — общий tooltip (как у сносок чата в `chat.js`/`ui.js`): заголовок разговора (`convTitle` из выжимки), ниже мелко «дата · ветка · N сообщений». Данные разговоров есть в графе (`ensureGraph()`/`getGraph()` из ui.js/api.js — посмотри структуру узлов); если разговора там нет (например drop-разговор) — лениво `api.getConv(id)` с кешем, пока грузится — «Загружаю…».
- Клик — открывает разговор в правой панели (drawer) поверх страницы статьи (как сейчас `data-act="conv"`), URL `#/articles?article=…&conv=…`; закрытие панели возвращает к статье на то же место прокрутки.
- В конце статьи — раздел «Источники»: нумерованный список «1. Заголовок разговора — 14 авг 2026 · ветка», каждый пункт кликабелен (открывает разговор). Свернуть по умолчанию, если пунктов > 12 («Показать все N»).
- Ссылки на другие статьи (`[[Название статьи]]`) — обычная текстовая ссылка с названием (без квадратных скобок), ведёт на страницу той статьи.
- `linkify` используется и в других местах (чат, разговоры) — там поведение не ломай: сделай отдельную функцию/опцию для статей.

## 3. Список статей (`#/articles` без параметра)
Сейчас — длинный список строк с символами «└», тяжело.
- Сверху: заголовок, пояснение, поле поиска `.field` (из 038), справа «472 статьи в 15 разделах».
- Разделы — сетка карточек-групп: заголовок раздела + количество, сворачиваемые (состояние в localStorage, по умолчанию развёрнуты первые 3 раздела). Внутри — строки статей: название (1 строка с обрезкой «…», полное — в title), справа мелко период и «✓ 93%» если проверена. Подстатьи серий (сейчас с «└») — группой под заголовком серии с отступом 16px и тонкой вертикальной линией слева вместо символа «└».
- Поиск фильтрует по названию мгновенно, подсвечивает совпадение (`<mark>`), раскрывает разделы с совпадениями, пустой результат — пустое состояние по DESIGN.md.

## 4. Автономный режим архива
Архив (`export_static.py`) собирается из этих же файлов, `api.js` в режиме `window.MXW_DATA`. Всё выше должно работать и там (данные графа и статей есть в `MXW_DATA`) — не используй ничего, что есть только на сервере.
