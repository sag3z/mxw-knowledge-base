# Задача: check_vault.py

Напиши скрипт `check_vault.py` в корне проекта (Python 3.13, только стандартная библиотека).
Запуск: `python check_vault.py vault` — проверяет Obsidian-хранилище в папке `vault/`.

Что проверить и вывести (по-русски, компактно):
1. Все wiki-ссылки `[[цель]]` и `[[цель|подпись]]` во всех .md (кроме папки `Источники/` как источника ссылок — её файлы только как цели). Цель резолвится, если существует файл `<цель>.md` где угодно в vault (сравнение по имени файла без .md). Вывести число ссылок, число битых, топ-20 битых целей с количеством и в каких файлах.
2. Статьи (все .md вне `Источники/`): пустые или короче 500 символов; без заголовка `# `; с frontmatter без поля `категория` (только для папок категорий, не для `Проекты и инструменты/`, `Медиа-конспекты/`, `Схемы/`, и не для `00 Главная.md`).
3. Сводка по папкам: число файлов, суммарный размер в КБ, среднее число ссылок на источники (`[[nft-c...]]` и т.п. — цели из папки `Источники/`) на статью.
4. Код выхода 0 всегда (это отчёт, а не тест).

Не трогай другие файлы проекта. Не читай `.llm_env`. Проверь скрипт запуском `python check_vault.py vault` (если папка vault ещё неполная — это нормально) и исправь ошибки.
