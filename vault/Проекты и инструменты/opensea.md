# OpenSea

**Что это:** NFT-маркетплейс, основной инструмент комьюнити для минта и торговли коллекциями (ETH mainnet, Robinhood Chain, Ink): фри-минты, флип вторички, фарм дропов, запуск своих коллекций через OS Studio, API для ботов и чекеров.

## Итог

OpenSea — основной маркетплейс комьюнити для минта, флипа и фарма дропов (ETH, Robinhood Chain, Ink) с API, на котором строятся боты и чекеры. Ключевые риски: honeypot-минты через подставные контракты, неожиданное исполнение висящих офферов, сбивание флора ботами и сносы коллекций при жалобах; условия верификации в чате расходятся (25К–50K объёма, всё «по словам»). Статус: активно используется весь период наблюдений (июнь–ноябрь 2026), платформа добавила сеть Ink и функцию «Add a Signal».
