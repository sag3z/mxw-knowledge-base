# allowlist-25000.csv: CSV-вайтлист адресов для минта

- Источник: ветка nft_движуха, сообщение #30475, files
- Категория: nft
- Теги: allowlist, вайтлист, минт, csv, evm

## Кратко
CSV-файл со списком адресов формата 0x (EVM) для вайтлиста минта. В строке — адрес и две пустые колонки. По имени файла список рассчитан на 25 000 адресов, но в файле около 449 строк — это либо фрагмент, либо обрезанная выгрузка. Главный вывод: сам файл — список адресов без пояснений; ценности для базы знаний в нём нет, кроме факта существования такого формата.

## Главное
- Формат: адрес, пустое поле, пустое поле (например, `0x…,,`). Колонок с количествами или статусами нет.
- Количество строк: 449 (по wc -l); в имени указано 25 000.
- Адреса не переписываются в конспект.
- Проверка перед использованием по таким спискам не сделана: не видно, для какого проекта и минта список.
