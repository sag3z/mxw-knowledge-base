# Kupo (kupo.world)

**Что это:** NFT-платформа/лаунчпад с вайтлист-формами и розыгрышами (пулами) мест, где задания проверяются через Twitter; по контексту чата используется для минта и флипа коллекций.

- 2026-08-15: По словам ArteMm, в Kupo лучше заходить с твиттерами, где 50+ подписчиков, WL выдавали не сразу. Max Wayld выпустил тестовую коллекцию без твиттера и аудитории дефолт-минтом, WL выдал 25К активным кошелькам. [[nft-c0279-04]]
- 2026-08-16: По словам FroZi, в пуле Kupo даётся одно место на кошелёк даже при выигрыше в двух пулах. ## Итог

Kupo — рабочая площадка с реальной проверкой Twitter-заданий: для WL нужен подключённый живой твиттер (желательно 50+ подписчиков), боты без подключения не проходят, WL выдаётся не сразу. Флип возможен: по словам участников, цена росла с $7 примерно вдвое, отдельные NFT продавались за $37–55; для фарма нужны прокачанные аккаунты (twiboost.com пока не проверен).
