# maxy.tools

**Что это:** Магазин аккаунтов и расходников для web3-активностей и мультиаккаунтинга: по описанию на скрине, продаёт аккаунты, почты и одноразовые материалы (раздел «Расходники и аккаунты»); на сайте также есть каталог с разделами «Web3 Проекты», «Инструменты», «Фарм Фандинга», «ИИ & Билдинг» и гайды для новичков (maxy.tools/ru/ai).

## Итог

maxy.tools — регулярно рекомендуемый в чате магазин аккаунтов и расходников (PornHub, TikTok, GitHub, почты) с гайдами по ИИ и каталогом web3-инструментов. Статус на 2026-09-13: каталог выглядит недоделанным — из карточек открылась только Qwen, остальные пустые. Заявления о качестве аккаунтов («не автореги») исходят только от участников чата и не проверялись.
