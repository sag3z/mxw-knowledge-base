# Base

**Что это:** Сеть (ончейн-экосистема), в которой комьюнити фармит аирдропы, минтит NFT-паки и торгует токенами; для расчётов в ней используются USDC и ETH. По словам автора пересланного твита Base Posting, Base — вторая по размеру ончейн-экосистема [[life-c0433]].

## Итог

Base — основная площадка фарма для комьюнити (аирдропы, паки, NFT, активность в Base App), которую Max называл «самой главной альфой», но результаты смешанные: раздача o1.exchange признана слабой, мелкие токены падали на 32–60%, а 26.06 сеть лежала. Выпуск токена сети и creator program обсуждались, но не подтверждены; по словам Bnd, доверие к команде Base-приложения упало после смены руководства и скандалов.
