# Anvil

**Что это:** AMM-протокол/маркет на Robinhood Chain (сайт anvil.clutch.market), через который токены свапаются в NFT и обратно; используется проектами экосистемы (ScriptKiddies, Ticket Yard/$YARD, Squiggle-wuiggle, HoodTangs, Robo Brokers) как механизм минта и казна.

## Что говорили в чате

- По словам С.Rollins, контракт Anvil — это место, откуда идёт минт и казна Anvil, через него токены свапаются в NFT; между ценой NFT на OpenSea и токеном всегда есть спред — можно купить NFT дёшево, сжечь и продать через токен. glimjke советовал на снайпе ставить защиту от price impact около 50 (2026-08-10) [[nft-c0259-09]]
- У ScriptKiddies из 10 000 NFT резерв 2500 был зарезервирован под Anvil AMM (2026-08-10) [[nft-c0259-07]]
- После запуска токена ScriptKiddies токен сильно вырос, NFT продавали за токен, но ликвидности не хватало; токен был на 1M cap, NFT можно было свапнуть в токен и продать (2026-08-11) [[nft-c0259-10]]
- У Robo Brokers стейкинг на Anvil был сломан (токен на Dexscreener помечен как скам и раг-пул), но почти всё исправили: стейкинг заработал, токен верифицировали (2026-08-11) [[nft-c0260]]
- По словам Mikhail, у Ticket Yard токен свапается на Anvil в одну из 3333 NFT (2026-08-11) [[nft-c0263-03]]
- $YARD (TickerYard): рынок создан через Anvil, supply токена 999 999 990, по 300 030 YARD на NFT, токен без owner, без дополнительного минта и без transfer tax (2026-08-12) [[nft-c0263-14]]
- По TheRikka, механика YARD: сначала покупают токен, потом свапают в NFT через Anvil (anvil.clutch.market); С.Rollins подтверждал — «свапаешь через Anvil» (2026-08-12) [[nft-c0263-15]]
- Squiggle-wuiggle: через Anvil можно менять NFT на токен; по словам Max Wayld, у нескольких человек было по 300+ сапплая на анвиле (2026-08-13) [[nft-c0269-07]]
- HoodTangs: минт через Anvil, сначала покупают токен (2026-08-14) [[nft-c0274-05]]

## Итог

Anvil — ключевой элемент меты Robinhood Chain: фактически стандартный механизм запуска NFT-коллекций через токен (минт = покупка токена + свап). Основные риски по опыту чата — нехватка ликвидности при свапе NFT→токен после лонча и спред между OS и токеном; для снайпа советовали защиту от price impact. Статус — активно используется множеством проектов, включая случаи с техническими сбоями (стейкинг Robo Brokers), которые позже чинились.
