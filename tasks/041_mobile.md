# Задача: полноценная мобильная версия

Работай в `app/web/` (`index.html`, `style.css`, `js/*.js`). Сначала прочитай `tasks/DESIGN.md`. Не читай `.llm_env`/`.openrouter_key`, не читай `tasks/*.log`, НЕ открывай PNG. LLM не нужен. Бэкенд не трогай.

Пользователь пользуется сайтом с телефона и хочет, чтобы это было нормально. Сейчас при ширине 390px **не видно кнопки меню** — между разделами не перейти.

## Сделать (ширина < 900px; проверять на 390×844 и 768×1024)
1. **Верхняя панель** 52px, sticky: слева кнопка меню (иконка `menu` из `js/icons.js`), по центру название текущего раздела, справа кнопка «Новый чат» (иконка pencil-square, только иконка). Боковая панель выезжает слева поверх (уже есть `side-over` + `#sideVeil` — довести: ширина 280px, анимация 200ms, закрывается по вуали, по Esc, при выборе пункта меню и свайпом влево).
2. **Drawer разговора** — на весь экран, шапка с кнопкой ← (закрыть) крупной зоной нажатия 44×44.
3. **Чат**: поле ввода прилипает к низу (`position: sticky; bottom: 0` + `env(safe-area-inset-bottom)`), не перекрывается клавиатурой (используй `100dvh`), подсказки-вопросы — горизонтальная лента с прокруткой вместо стены чипов; сноски `[n]` — по тапу показывают подсказку (tap = hover), второй тап — открывает разговор.
4. **Списки**: «Люди» — карточки в одну колонку, чипы категорий — горизонтальная прокручиваемая лента в одну строку (не 8 рядов, как сейчас); «Активности» — фильтры в одну строку с горизонтальной прокруткой, карточка события: дата сверху строкой, а не отдельной колонкой; «Темы» — карточки-итоги в столбик, график по ширине экрана, легенда — лента с прокруткой; «Статьи» — список и страница статьи в одну колонку (оглавление — кнопкой).
5. **Карта**: занимает всю высоту под верхней панелью, жесты pinch-zoom/pan работают (если используется d3-zoom — проверь `touch-action: none` на холсте), таймлайн снизу компактный; переключатель «По темам/По веткам» и «Категории» — в одну строку.
6. **Общее**: нигде нет горизонтального скролла страницы; зоны нажатия ≥ 40px; минимальный текст 13px; tooltips по тапу и закрываются тапом мимо; `<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">`.
