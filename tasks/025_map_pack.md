# Задача: карта «По темам» — упаковка кругов (zoomable circle packing) вместо рыхлых островов

Сначала прочитай `tasks/DESIGN.md`. Меняй только `app/web/js/map.js` и `app/web/style.css`. Не читай `.llm_env`/`.openrouter_key`, не читай `tasks/*.log`, НЕ открывай PNG.

Ревьюер посмотрел `#/map` («По темам»): после прошлой правки острова стали мелкими, а подписи островов наползают друг на друга и на соседние острова — нечитаемо. Нужен другой, заведомо аккуратный способ.

## Новый вид «По темам» — d3.pack (SVG, не canvas)
- Иерархия: корень → **группы** (категория, преобладающая в кластере: по `c` его разговоров; 11 категорий, названия и цвета из DESIGN.md) → **кластеры** (30, `clusters`/`layout.k`, имя `clusters.name`, описание `descr`) → **разговоры** (листья; значение = `sqrt(n сообщений)`, чтобы большие разговоры не забивали всё). Мусор (drop) не показывать.
- `d3.pack().size([w, h]).padding(d => depth-зависимый: группы 6, кластеры 3, листья 1)` — круги вплотную, без наложений, всё вписано в доступную область (между верхней строкой и нижним таймлайном, с учётом сайдбара и легенды).
- Оформление: группа — круг с очень лёгкой заливкой цвета категории (opacity ~0.06) и тонкой обводкой того же цвета (opacity ~0.35); кластер — заливка поверхности `#171a21`, обводка `#272b35`; лист — точка цветом категории разговора.
- **Подписи**: у каждого кластера — название внутри круга, по центру, текст `#e8e9ed`, 600, размер шрифта подбирается под радиус круга на экране (от 11 до 16px; перенос на 2 строки по словам; если даже 2 строки по 11px не влезают в ~1.6·r по ширине — подпись не рисуется, она будет в tooltip и появится при приближении), под названием мелко вторичным «N разговоров». Подписи групп (категорий) — по дуге не нужно: маленькая «таблетка» с названием категории у верхнего края круга группы. Пока кластер не приближен — листья приглушены (opacity 0.5), чтобы подписи кластеров читались поверх.
- **Zoom по клику** (классический zoomable circle packing): клик по кластеру — плавное приближение к нему (750 мс), подписи кластеров снаружи скрываются, листья становятся яркими и кликабельными (клик → разговор в drawer, наведение → tooltip: заголовок разговора, дата, N сообщений); клик по группе — приближение к группе; клик по фону или кнопка «← Все темы» (появляется вверху слева при приближении) — назад к общему виду. Колесо мыши/перетаскивание не нужны (не ломать прокрутку страницы).
- Наведение на кластер — подсветка обводки акцентом и tooltip с `descr`.
- Таймлайн внизу: при сдвиге слайдера листья позже выбранной даты скрываются (как сейчас), размеры кругов не пересчитываются.
- Вид «По веткам» — не трогать, переключатель «По темам · По веткам» оставить. Легенда категорий — та же сворачиваемая; клик по категории — скрыть/показать её листья.
