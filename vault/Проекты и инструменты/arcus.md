# Arcus

**Что это:** Торговая платформа (app.arcus.xyz) в экосистеме Robinhood Chain: спот-торговля, включая акции (TSLA), позже появились перпы и поинтовая система.

## Что говорили в чате

- 2026-07-02: По словам Max, экосистема чейна Robinhood пока пустая (офф-аппки других сетей), из интересного — только вейтлист Arcus. [[crypto-c0054]]
- 2026-07-13: Ignis зовёт фармить по рефке с вейтлиста; Max считает, что продукт уже работает, вейтлист не даёт преимуществ, а решать надо после проверки затрат и условий торговли. [[crypto-c0115]]
- 2026-10-01: Для реферальной ссылки на Arcus нужен открытый перп, а не старый вейтлист — ссылка из вейтлиста, которую дали в чате, другая. [[perps-c0025]]
- 2026-10-01: Arcus запустил поинты. [[important-c0016]]
- 2026-10-01: Открытый перп уже доступен (не только вейтлист), поинтовая система запущена; по словам участников, нулевой сезон уже закончился и был короткий. [[perps-c0026]]

## Итог

Продукт работает (спот, перпы) и поинтовая система запущена, но, по словам участников, нулевой сезон был коротким и уже завершился. Вейтлист преимуществ не даёт, для рефки нужен открытый перп; перед фармом стоит проверить затраты и условия торговли (совет Max).
