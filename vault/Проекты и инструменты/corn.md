# Corn (ивент Arcade на Abstract)

**Что это:** Ивент с кукурузой в игре Arcade (портал Abstract): игроки по ключам проходят раны из 10 этажей, собирают кукурузу для лидерборда и розыгрыша (raffle) с призовым пулом; ивент также даёт вл (WL).

## Что говорили в чате

- Ивент ради вл и лидерборда: один ключ на одну игру из 10 этажей; ходы рассчитываются так, чтобы забрать кукурузу для ЛБ и энергию, монетки тоже собираются [[life-c0544]] (2026-09-17).
- Пул розыгрыша кукурузы по лидерборду: 12к за 3 часа; на прошлой раздаче — 18к за неделю; до конца ивента около 10 дней [[life-c0545]] (2026-09-17).
- Идея софта: голосовать за ОЧХ, клеймить три бесплатных ключа, играть 3 игры и заносить кукурузу в рафл на бесконечном числе аккаунтов; по словам Сёмы, игру автоматизировать нельзя, поэтому рафл можно абузить только вручную [[life-c0546]] (2026-09-17).
- По словам Max Wayld, софт под Abstract уже был, но его больше нет [[life-c0546]] (2026-09-17).
- Ограничение рафла: без Expedition Pass принимается только золотая кукуруза из Arcade-ранов (в тесте Сёмы — 0 из 150); фри-аккаунты с ключами за апвоуты не проходят — по словам Сёмы, этот способ уже пофиксили [[life-c0552]] (2026-09-18).

## Итог

Ивент с заметным призовым пулом (12к за 3 часа по лидерборду) и дедлайном около 10 дней с 2026-09-17. Абуз рафла мультиаккаунтами возможен только вручную (игра не автоматизируется, по словам Сёмы), а основной фри-способ с ключами за апвоуты уже закрыт: без Expedition Pass в рафл принимается только кукуруза из Arcade-ранов.
