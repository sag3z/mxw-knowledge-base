# Virtuals

**Что это:** Экосистема/лаунчпад для запусков токенов AI-проектов: через Virtuals запускались AI-агенты (например, VEX в Robinhood Chain), в whitepaper описана «capital formation layer», есть механика запусков с рефандами и собственные токены «виртуалы».

## Что говорили в чате

- 2026-07-02 — Стратегия Kodak: покупать только в первые минуты после запуска (генезис-свеча), окно на реакцию ~60 секунд, иначе скип, без коррекций. Предупреждение: деплойер может выставить налог любого процента на любое время (вплоть до 100 → 0 за минуту), а копитрейдеров известных кошельков обычно «бреют». [[crypto-c0056]]
- 2026-07-03 — По словам Kodak, Eastworlds — лаборатория, владеющая роботами, с партнёрством с Virtuals с начала года. [[crypto-c0061]]
- 2026-07-04 — В чат скинули скрин двух профилей X из экосистемы Virtuals: @IntoPurpleMoon строит проект, DonJohnson — «chef» Virtuals и соавтор ERC-8126. [[crypto-c0066]]
- 2026-07-06 — Участники признали, что упустили раннюю покупку VEX (ProjectVEXai, AI-агент в Robinhood Chain через Virtuals); Kapitoshich, по его словам, не прошёл в заявку — вайтлист уже набрали и передали команде. Kodak подписался на CEO Robinhood и ProjectVEXai, Timur трактует это как сигнал. [[crypto-c0072]]
- 2026-07-10 — Эвристика wdnad для оценки проектов: пустой твиттер проекта и девов, три поста и мемы в ленте — признак мусора; Kodak отметил, что конкретный аккаунт он проверил и тот не пустой. [[life-c0155]]
- 2026-07-10 — Kodak дал ссылку на whitepaper Virtuals (capital formation layer) и отметил, что на Base уже есть решение для рефандов в лаунчах (в контексте обсуждения Vibestarter). [[life-c0156]]
- 2026-08-24 — По словам Kodak, раньше абузил рефанды Virtuals: на 60-дневных запусках рефанд возвращал больше виртуалов, чем стоила покупка; также входил в один из новых запусков примерно по 1.5 с ожиданием таргета 5. [[crypto-c0238]]

## Итог

Virtuals — активная экосистема запусков AI-проектов, упоминается в чате с июля по август 2026. Ключевые риски: налог деплойера может меняться вплоть до 100%, копитрейдеров бреют, много мусорных проектов — нужен DD (проверка твиттеров девов). Рефанд-механика ранее, по словам Kodak, позволяла абузить возвраты, но это опыт прошлого и не гарантия на будущее.
