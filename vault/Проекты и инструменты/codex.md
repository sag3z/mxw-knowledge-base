# Codex

**Что это:** агентный инструмент OpenAI для кодинга (CLI, приложение, расширение для VS Code) на моделях GPT (gpt-5-astra, gpt-5.6-sol/terra/luna, gpt-6-astra), доступный по подпискам ChatGPT (Plus $20, Pro $100, планы $200 и $500) с недельными лимитами и сбросами; в чате MXW — основная «рабочая лошадка» для тех-части в паре с Claude.

## Что говорили в чате

- Разделение ролей: Claude — обдумывание проекта и визуал, Codex — тех-часть, аудиты и проверки [[ai-c0042]] (2026-06-28); Damirka предлагал схему «Claude-архитектор ставит задачи, Codex исполняет» [[ai-c0061]] (2026-07-02); Max переходил на Codex из-за нехватки лимитов Claude и рассматривал вторую подписку Codex вместо второй Claude [[ai-c0054]], [[ai-c0055]] (2026-06-30).
- По словам Max, Codex в разы дешевле и выгоднее Claude при сопоставимом качестве в ряде задач [[ai-c0171]] (2026-08-10); по опыту его знакомых и видео, Claude в среднем делает задачи лучше, Codex выигрывает по цене и удобству, включая визуальную работу [[ai-c0172]] (2026-08-11).
- FroZi: Codex сильнее, когда понимаешь архитектуру и задаёшь рамки; Claude лучше для абстрактных задач и новичков [[ai-c0171]] (2026-08-10).
- Бенчмарк по пересказу видео: Claude за недельный лимит выполнил ~700 задач с GitHub, Codex ~300; по опыту sag3z, Codex сбрасывают так часто, что половину лимита не успеваешь выжечь; Max: Codex заметно слабее Claude в сложной логике [[ai-c0424]] (2026-10-26).
- Max: Codex доводит задачу до конца и спокойно работает 3+ часа (Claude так обычно не делает); новую модель приходится обновлять вручную через `codex update` [[ai-c0303]] (2026-09-24).
- Сбросы лимитов для Codex доступны только в приложении; сбросы выдаются случайно, неиспользованные сохраняются [[ai-c0017]], [[ai-c0018]] (2026-06-20). Пересланный пост: OpenAI каждый день выдаёт подписчикам бесплатный сброс, пока нет доступа к Astra, применять в течение месяца [[ai-c0243]] (2026-09-04); по Max, при ежедневных сбросах, чтобы выжечь лимиты полностью, нужно вести сразу 8 проектов [[ai-c0142]] (2026-07-28).
- По посту из r/codex, у Pro-пользователей недельные лимиты сгорают быстрее эквивалентного API-расхода (~$46 API-эквивалента съели 98% лимита $200), OpenAI разбирается [[ai-c0267]] (2026-09-10).
- По сводке с Reddit, при переходе с Plus ($20) на Pro ($100) лимиты сбрасываются до 100% сразу после оплаты [[ai-c0487]] (2026-11-05); по расчёту spacetime, при обычной оплате использование не сбрасывается — на 1–23% выгоднее завести второй аккаунт и чередовать [[ai-c0256]] (2026-09-06).
- Абуз сбросов (по словам участников, не проверено): по Max, если не оплатить сразу, побыть на фри-плане и вернуться — общие лимиты сбрасываются; ImmuneFOMO советует покупать фри-триал аккаунты за пару долларов и держать до апгрейда [[ai-c0469]] (2026-11-02).
- Перепродажа доступа: codex.sale — токены Codex дешевле и без недельных лимитов, сессию вводят в терминал (Сёма пользуется ~3 месяцев, советует осторожность с вставкой в консоль; в NFT-ветке назвали «пираткой» — сначала проверить безопасность) [[ai-c0097]] (2026-07-13), [[nft-c0363-05]] (2026-08-29); готовые аккаунты с рук: FroZi брал за $10 (месяц отработал), ChatGPT Plus на 30 дней продают за 290 ₽ без гарантий [[ai-c0091]] (2026-07-10).
- Баны: по новостям, OpenAI начала банить аккаунты (сначала китайские, теперь и не только); hh за время использования Codex сменил ~40 аккаунтов, после обновления с мультиаккаунтами пока не банят [[ai-c0502]] (2026-11-08).
- Приватность: в Codex app стоит проверить Settings > Data Controls > Location, иначе ChatGPT может получить точную геолокацию [[ai-c0509]] (2026-11-10).
- Модели: в CLI по умолчанию gpt-5-astra, далее gpt-5.6-sol (current), terra и luna [[ai-c0247]] (2026-09-04); пробинг API показал, что gpt-6-astra и gpt-5.6-cyber существуют, но закрыты (404 GATED-EXISTS) [[ai-c0240]] (2026-09-03).
- Жалобы на Astra: по словам spacetime, не выполняет задачи в codex cli/conductor/omp и требует инструкции втрое подробнее, чем GPT 5.6/5.1 [[ai-c0252]] (2026-09-06); Max и spacetime отмечали, что Astra 6 стала заметно глупее и качество скачет [[ai-c0330]] (2026-10-03); Astra жрёт лимиты сильнее Codex [[ai-c0294]] (2026-09-19).
- Геймдев/3D: по Max, Codex пишет сцены в движке (для 3D советует Unity, а не Godot), делает 3D-сцены лучше Claude, но пайплайн с Blender/Unity сложнее [[ai-c0212]] (2026-08-27), [[ai-c0239]] (2026-09-02); для инди-игры Max использовал Codex для 3D-моделей [[life-c0483]] (2026-09-03); в видео с Aseprite от Codex — плывущие текстуры, качественнее анимации получаются через pixellab [[ai-c0289]] (2026-09-18).
- В Codex встроен Images 2.5 — можно сначала сгенерировать визуал, потом поручить реализацию Sol или Astra [[ai-c0295]] (2026-09-20); подписки за $20 хватает для генерации картинок, план за $500 Max не понял, spacetime считал два плана по $200 выгоднее из-за двух ресетов [[ai-c0314]] (2026-09-29).
- Интеграции: Codex подключается к Hermes по OAuth (`hermes auth add codex-oauth`) [[ai-c0059]] (2026-07-01); схемы связки с Claude через MCP (codex как MCP внутри сессии Claude через `claude mcp add`, Claude как MCP-сервер в Codex) — минус: ответы второго агента падают в контекст и тратят лимиты обеих подписок [[ai-c0229]] (2026-09-01).
- Проблемы клиента: расширение Codex в VS Code после обновления не отправляет запросы — Max советует работать напрямую через CLI [[ai-c0324]] (2026-10-01); hh: после обновления приложения кредитный сброс стал менее удобным, советует пока не обновлять [[ai-c0526]] (2026-11-13).
- Тюнинг: если модель «лезет не туда» — проверить срабатывание скиллов (description в SKILL.md; после выхода Astra старые скиллы срабатывали слишком часто); окно контекста по умолчанию ~258–282K, поднимается до 500–900K через model_context_window, wavyluv использует 500K [[ai-c0467]] (2026-11-02).
- Практика: ProstoXleb за несколько часов и ~$6 написал в Codex набор крипто-инструментов (минтер NFT, трейт-хантер, токен-снайпер) — по его словам, всё работает, но медленно [[ai-c0387]] (2026-10-20); по словам huraveq, Codex отказывался работать с реальными ордерами Polymarket [[predict-c0018]] (2026-07-10).
- Сравнение с конкурентами: подписка Kimi (~$40, тариф Allegretto) даёт функционал как у Claude и Codex с лимитами примерно в 2 раза больше, чем Codex за $20 [[life-c0450]] (2026-08-29); Max и ProstoXleb готовили видео-сравнение Codex и Claude с одинаковыми скиллами и промптами (пост Max о том, что GPT сделал приложение, а Claude нет, он сам назвал рейджбайтом) [[ai-c0315]] (2026-09-29).
- Прочее: OpenAI выпускала новый релиз ограниченным превью для доверенных партнёров в Codex и API по просьбе правительства США [[ai-c0039]] (2026-06-26); Sponsorbar показывает рекламу в терминале Codex вместо слова «thinking» [[ai-c0264]] (2026-09-09).

## Итог

Codex — основной инструмент сообщества для кодинга и тех-части: дешевле Claude, доводит задачи до конца, лимиты часто сбрасываются, но в сложной логике, по отзывам, слабее Claude. Риски — баны мультиаккаунтов со стороны OpenAI, «пиратский» доступ (codex.sale, аккаунты с рук) без гарантий и с вопросами безопасности, а также нестабильные обновления клиента (VS Code-расширение, механика сбросов в приложении). Статус: активно используется, лимиты и механики сбросов постоянно меняются — детали стоит проверять на актуальную дату.
