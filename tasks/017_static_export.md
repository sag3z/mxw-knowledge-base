# Задача: автономный архив базы для создателя приватки

Нужен один zip, который получатель распаковывает и открывает `Открыть карту.html` двойным кликом — без Python, без сервера, без установки, работает и без интернета (кроме чата/смыслового поиска, которые включаются его собственным API-ключом). Плюс папка для Obsidian.

Создай `export_static.py` и шаблон `app/static_shell.html` (или генерируй страницу из `app/index.html` — на твой выбор, но `app/index.html` и `app/server.py` для локальной версии НЕ ломать). Не читай `.llm_env`/`.openrouter_key`, не читай `tasks/*.log`, НЕ открывай PNG/медиа.

## Состав (решение пользователя)
- **Только полезные разговоры** (`convs.verdict != 'drop'`): узлы карты, разговоры с сообщениями, поиск — без drop. Разговор `жизнь_флуд_кайф/c0175` исключён в любом случае (проверь, что его нет).
- Всё остальное включить: статьи `vault/` (с `Источники/`, `Схемы/`, «Календарь активностей», карточки проектов), события, «Кто в чём» (таблицы experts/expert_topics), темы во времени (те же данные, что `/api/trends`), кластеры и смысловая раскладка, медиа (см. ниже). Ники НЕ скрыты по умолчанию, но кнопка стример-мода работает.
- НИКОГДА не включать: `.llm_env`, `.openrouter_key`, `data/llm_calls.log`, исходники пайплайна, `backup/`, `tasks/`. В конце — проверка: просканируй весь dist на подстроки `sk-`, `Bearer `, `api_key`, `LLM_API_KEY`, `reformboss`, `127.0.0.1:43117`, `ocam-` и выведи найденное (ожидается пусто, кроме кода настроек, где ключ вводит пользователь — там не должно быть значений).

## Устройство `dist/MXW-база-<YYYY-MM-DD>/`
- `Открыть карту.html` + `app/` (js, css, библиотеки **локально**: force-graph, d3 v7, marked, плюс клиентский полнотекстовый поиск, например MiniSearch — скачай один раз с unpkg в `app/lib/`, без CDN в итоговой странице).
- Данные: из-за ограничений `file://` (fetch JSON запрещён) — данные как JS-файлы `window.MXW_DATA.<часть> = {...}`, подключаемые `<script>`. Крупное (сообщения разговоров) — шардировать по веткам (`app/data/conv_<short>.js`) и подгружать по требованию динамическим `<script>`.
- Всё, что сейчас делают эндпоинты сервера, перенести в клиент: граф, разговор (режимы Главное/Без флуда/Всё — поле noise/show посчитай при экспорте той же логикой, что `conv_detail` в server.py, переиспользуй функции импортом из app/server.py), поиск по словам (клиентский индекс по сообщениям+расшифровкам и по выжимкам с фильтрами ветка/категория/схемы; сниппеты с подсветкой), статьи (md внутри JS + ридер с linkify `[[…]]`), события, эксперты, тренды.
- **Смысловой поиск и чат — по ключу получателя**: окно «⚙ Настройки»: base URL OpenAI-совместимого API (по умолчанию `https://openrouter.ai/api/v1`), API-ключ, модель чата (по умолчанию `deepseek/deepseek-chat`), модель эмбеддингов (по умолчанию `qwen/qwen3-embedding-8b`) — хранится в `localStorage` этого браузера, никуда кроме указанного API не отправляется (так и написать в окне). Эмбеддинги разговоров (таблица `emb`, Qwen3-Embedding-8B, 2048-d) упакуй квантованными в int8 (масштаб на вектор) в base64 в `app/data/emb.js`; запрос эмбеддится через API получателя, косинус — в браузере. Если ключа нет или эмбеддинг не удался — только поиск по словам, с подсказкой «включить смысловой поиск — ⚙ Настройки». Чат: та же логика, что `/api/chat` (переформулировка → поиск → материал → потоковый ответ), но прямо из браузера к API получателя (`stream: true`, SSE). Без ключа кнопка чата показывает объяснение.
- **Медиа** `app/media/`: только для полезных разговоров, из `data/media_index.jsonl`. Фото — миниатюра `_thumb.jpg`, если есть, плюс оригинал; голосовые и кружки — включить; видео ≤ 25 МБ — включить, больше — вместо плеера строка «видео не включено в архив (N МБ)»; файлы (`files`) ≤ 10 МБ включить с предупреждением «⚠ не запускай без проверки», больше — не включать. Флаг `--media none|light|full` (light = без видео и файлов; по умолчанию full по правилам выше). Имена файлов — нейтральные (`<i>.<ext>`), пути экспорта не раскрывать.
- `Obsidian/` — копия `vault/` (открыть как хранилище).
- `ПРОЧТИ.txt` (по-русски, коротко): что это; как открыть карту (двойной клик; лучше Chrome/Edge); как открыть Obsidian-хранилище; как включить чат и смысловой поиск (ключ OpenRouter, где взять, что хранится локально); что внутри есть разделы со схемами абуза и ники участников — не пересылать дальше; дата среза данных.
- Итог: `dist/MXW-база-<дата>.zip`. Печать размеров по частям (данные, медиа, Obsidian) и итог.

## Проверка
- `python export_static.py --media light` (быстрый прогон), потом полный `python export_static.py`.
- Открой `Открыть карту.html` через headless Edge с `file:///…` (`--allow-file-access-from-files` НЕ использовать — должно работать без него) и сними скриншоты: карта (`data/export_map.png`), разговор с медиа через deep-link `#conv=…` (`data/export_conv.png`), поиск по слову, если сделаешь deep-link `#search=…` (`data/export_search.png`). Скриншоты НЕ открывать — проверь через `--dump-dom`, что узлы/сообщения отрисованы и в консоли нет ошибок (`--enable-logging=stderr --v=0`, ищи `Uncaught`).
- Размер zip; результат сканирования на ключи; количество разговоров в экспорте (= 1578) и что drop-разговоров нет.
