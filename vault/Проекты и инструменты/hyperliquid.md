# Hyperliquid

**Что это:** Площадка для торговли перпами и спотом с токеном $HYPE, публичным API (данные по спот-листингам), EVM-цепью HyperEVM с дешёвыми минтами и экосистемой сторонних проектов (skew.trade, Elysium, HyENA, TreadFi). Фронтенд не подключает адреса, помеченные сторонним скринером как high-risk.

## Итог

Рабочая площадка для перпов, спота и дешёвых минтов на HyperEVM с активной экосистемой, которой чат пользуется для LP, фарминга наград и продаж токенов. Риски: маркет-ордера по твиту Max заметно дороже, чем на Lighter (~$500 против ~$70 за ту же позицию), и блокировка фронтендом адресов с пометкой high-risk от стороннего скринера без объяснения причин. Статус: работает; по тексту пересланного видео CFTC занимается легальным запуском в США, что уже двигало цену $HYPE.
