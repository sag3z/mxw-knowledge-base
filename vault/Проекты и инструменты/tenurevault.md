# TenureVault

**Что это:** NFT-проект/аккаунт, лаунчащий NFT-коллекции; в чате обсуждались коллекция «банкноты» (минт по $1, редкость по трейту Face Value) и фигурирующий в тех же ветках Cache-flow (NFT с фиксированным пулом фисов); твиттер проекта влиял на цену.

## Что говорили в чате

- 2026-08-29: у проекта подписчики и «аудиты» на 5–10к; по словам Сёмы, если аудит реально куплен — это зелёный флаг; 1/73 откупали по $80–90. FroZi предлагал колаб-менеджерам текст и инфу для пуша проекта и создал Discord-группу, чтобы не спамили одними и теми же вайтлистами; Rollins — вайтлисты только для холдеров NFT. [[nft-c0363-02]]
- 2026-08-29: «банкноты»: минт по $1, редкость по трейту Face Value (Face Value 1000 — флор ~$200; Сёма выставил 1/78 за $200). Сёма тратит на такие коллекции не больше $50, чтобы не было жалко потерять; Bnd — при насмотренности риск ректа ниже. S.Rollins: коллекция в hidden pool, ожидается исправление. [[nft-c0363-03]]
- 2026-08-30: флор Cache-flow за ночь вырос с $95 до $230. По словам Сёмы, девелопер сам заминтил ~1000 NFT (потом добрали холдеры), тестовый деплой шёл с кошелька самого девелопера, поэтому контракты, вероятно, связаны с его кошельками. S.Rollins: сайта нет вообще, покупают холдеры других коллекций — красный флаг; по словам Сёмы, фиксированный пул фисов может поднять цену. [[nft-c0365]]
- 2026-08-30: твит TenureVault сначала повлиял на цену, потом снова тильт (Сёма). S.Rollins: аккаунт, который лаунчит коллекции, запустил уже 10-ю (с геометрическим дизайном, по его словам). [[nft-c0368-06]]

## Итог

К концу августа 2026 проект активен и разогнан (флоры «банкнот» и Cache-flow доходили до ~$200–230), но с серьёзными красными флагами: контракты, вероятно, привязаны к кошелькам девелопера, самозаминтившего ~1000 NFT, сайта нет. Участники советовали заходить только небольшим бюджетом (до $50 по Сёме), рассчитывая на фиксированный пул фисов и твиты проекта; статус — под вопросом из-за девелоперских кошельков.
