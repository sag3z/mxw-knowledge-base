# Задача: смысловая раскладка карты (как карта форума Polkadot)

Сейчас карта (`app/index.html` + `app/server.py`) группирует разговоры по веткам чата. Нужен второй режим — «по смыслу»: близкие по содержанию разговоры рядом, независимо от ветки, с подписанными тематическими кластерами.

Не читай `.llm_env` и `.openrouter_key`, не печатай ключи. Не трогай `build_vault.py` (его сейчас правит другая задача) и `vault/`.

## 1. `layout.py` (новый, в корне проекта)
Данные: `data/kb.sqlite`, таблица `emb(topic, conv, vec)` — vec это float32 bytes (Qwen3-Embedding, 2048-d), 1578 строк (только полезные разговоры, verdict != 'drop'). Таблица `convs(topic, conv, verdict, category, tags, summary, ...)`; `tags` — JSON-список.
Пакеты установлены: numpy, umap-learn, scikit-learn.

Шаги:
1. Загрузить векторы, L2-нормировать.
2. Кластеры: `sklearn.cluster.KMeans(n_clusters=K, n_init=10, random_state=42)` на нормированных векторах, K по умолчанию 30 (`--k`).
3. 2D-координаты: `umap.UMAP(n_neighbors=20, min_dist=0.15, metric="cosine", random_state=42)`. Нормируй координаты в диапазон примерно [-1000, 1000].
4. Названия кластеров через LLM: `import llm` (модуль проекта; ключ он читает сам). Для каждого кластера возьми до 30 выжимок (`summary[:200]`) ближайших к центроиду + топ-15 тегов по частоте и вызови
   `llm.chat_json(llm.WRITER, SYS, user, max_tokens=2000, temperature=0.2, fallback=llm.ENTITY)`.
   SYS: попросить вернуть JSON `{"name": "2–5 слов по-русски, конкретно (проекты/механики), без слова 'обсуждение'", "descr": "одно предложение"}`. Запросы делай параллельно, `ThreadPoolExecutor(3)` (у провайдера лимит параллельных запросов — не больше 3). Кэшируй ответы в `data/cluster_names.json` по ключу `"<K>:<sorted ids первых 30>"` хеш — повторный запуск без изменений не должен звать LLM.
5. Записать в БД (пересоздавая): `layout(topic TEXT, conv TEXT, x REAL, y REAL, k INT)` и `clusters(k INT PRIMARY KEY, name TEXT, descr TEXT, n INT, x REAL, y REAL)` — x,y кластера = медиана координат его точек.
6. Печать: список кластеров с размером и названием.
Запуск: `python layout.py [--k 30]`.

## 2. `app/server.py`
- В `graph()` для каждого узла добавь поля `ux`, `uy`, `k` из таблицы `layout` (если строки нет — null). ВАЖНО: не используй имена полей `x`, `y`, `vx`, `vy`, `fx`, `fy` — их занимает force-graph.
- В ответ `graph()` добавь `"clusters": [{k, name, descr, n, x, y}, ...]` (пусто, если таблицы нет — сервер не должен падать без таблицы layout).

## 3. `app/index.html`
Сейчас: узлы раскладываются синхронной d3-симуляцией по веткам (кольцо кругов), координаты фиксируются `fx/fy`, `cooldownTicks(0)`. Подписи веток рисуются в `onRenderFramePost` (посмотри код).
Добавь:
1. Кнопку в `#top`: «вид: ветки» / «вид: смысл» (переключатель). По умолчанию — «смысл», если в данных есть clusters.
2. Режим «смысл»: узлы с `ux/uy` ставятся в эти координаты; чтобы точки не перекрывались, прогони короткую синхронную симуляцию `forceX(ux).strength(0.3)`, `forceY(uy).strength(0.3)`, `forceCollide(rad+0.5)` ~150 тиков, затем зафиксируй fx/fy. Узлы без ux (мусор, drop) — в этом режиме скрыты (кнопка «мусор» в этом режиме неактивна/игнорируется). Подписи — названия кластеров в точке (x,y) кластера, шрифт заметный, полупрозрачная подложка; при большом зуме подписи мельче (масштабируй размер шрифта на 1/globalScale в разумных пределах). Цвет узлов — как сейчас (категория).
3. Переключение режимов — без перезагрузки страницы: пересчитать позиции, обновить fx/fy, `G.graphData(...)` или просто обновить координаты и `zoomToFit(600, 90)`. Позиции режима «ветки» вычисляй один раз и запоминай (`n.bx, n.by`), позиции смысла — `n.sx, n.sy`.
4. Подсветка поиска: в панели «Поиск по смыслу» после получения результатов подсвети найденные узлы на карте (остальные — тусклые, alpha ~0.15; найденные — с белой обводкой), и `zoomToFit` по найденным (`G.zoomToFit(600, 80, n => hitIds.has(n.id))`). Кнопка «сбросить подсветку» в панели поиска; закрытие панели тоже сбрасывает.
5. Клик по названию кластера (или пункт в легенде кластеров не нужен) — достаточно: при наведении на узел в tooltip показывай название кластера.
