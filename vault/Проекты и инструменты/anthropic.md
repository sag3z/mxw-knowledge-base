# Anthropic

**Что это:** Компания-разработчик ИИ-ассистента Claude; по пересланным в чате новостям — готовится к IPO и, по словам Max, к анонсу собственного токена в ноябре 2026.

## Итог

Anthropic — ведущий AI-вендор, по пересланным новостям готовящийся к IPO до 26 ноября 2026 (оценка, по WSJ, упала с $2 до $1 трлн) и, по словам Max, к анонсу токена. Главный практический риск для комьюнити — жёсткая бан-политика: 11,4 млн банов за полгода, успешных апелляций ~10,6%, с 12 ноября — баны целых цепочек перепродажи по связям карт; обходы через VPN, KYC-сервисы и «чистые» аккаунты по опыту участников ненадёжны.
