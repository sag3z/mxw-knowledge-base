# Задача: архив для создателя — собрать из нового фронта `app/web/`

Сначала прочитай `tasks/DESIGN.md` (раздел «Код»). Не читай `.llm_env`/`.openrouter_key`, не читай `tasks/*.log`, НЕ открывай PNG/медиа.

Сейчас `export_static.py` собирает архив из отдельной копии фронта `app/static_shell.html` — она устарела (старый дизайн). Нужно, чтобы архив собирался из **тех же файлов `app/web/`**, что и локальный сайт, — через автономный режим `api.js` (данные из `window.MXW_DATA`, чат и эмбеддинги — напрямую к API из «⚙ Настройки» получателя: base URL по умолчанию `https://openrouter.ai/api/v1`, модель чата `deepseek/deepseek-chat`, эмбеддинги `qwen/qwen3-embedding-8b`; ключ только в localStorage).

1. Реализуй автономный режим в `app/web/js/api.js` (и где нужно): все функции, которые в серверном режиме ходят на `/api/...`, в автономном считают то же из `window.MXW_DATA` (граф, кластеры, разговор с show/noise — посчитаны при экспорте, поиск по словам — клиентский индекс, статьи, события, эксперты, тренды с top_tags, медиа — относительные пути `app/media/<i>.<ext>`). Чат — та же логика, что серверный `/api/chat` (переформулировка → поиск → материал с `[n]` и экспертами → потоковый ответ с SSE от провайдера), источники и сноски так же. Без ключа: чат показывает источники и объяснение «чтобы ИИ отвечал — добавь ключ в ⚙ Настройки». Окно «⚙ Настройки» добавь в боковую панель только в автономном режиме.
2. Перепиши `export_static.py`: копирует `app/web/` в `dist/MXW-база-<дата>/app/`, страница входа `Открыть карту.html` (из `app/web/index.html` с относительными путями), данные `app/data/*.js` (шардирование разговоров по веткам, подгрузка по требованию — переиспользуй то, что уже есть в export_static.py), медиа по прежним правилам (`--media none|light|full`), `Obsidian/`, `ПРОЧТИ.txt` (обнови описание разделов: Чат, Карта, Активности, Люди, Темы, Статьи). Только полезные разговоры, без `жизнь_флуд_кайф/c0175`. `app/static_shell.html` после этого удалить.
3. Скан на секреты (как сейчас: `sk-`, `Bearer `, `api_key`, `LLM_API_KEY`, `reformboss`, `127.0.0.1:43117`, `ocam-`) — должно быть пусто.
