# MXW — база знаний чата

База знаний, собранная из экспорта Telegram-чата MXW (крипта, NFT, AI, абуз-схемы).
В неё входят карта разговоров, поиск по смыслу, чат с ИИ по базе, статьи, активности, эксперты и темы.

> ⚠️ Внутри есть переписка участников и их ники, а также разделы со схемами абуза.

## Самый простой способ: готовый архив

1. Открой вкладку **[Releases](../../releases)** и скачай `MXW-база-….zip`.
2. Распакуй архив и дважды кликни по **«Открыть карту.html»** (лучше в Chrome или Edge).

Ничего устанавливать не нужно, сервер не нужен, интернет тоже. Поиск по смыслу работает на модели прямо в браузере, без ключей.
Подробная инструкция лежит внутри архива, в файле `ПРОЧТИ.txt`.

Папку `Obsidian/` из архива можно открыть в [Obsidian](https://obsidian.md) как хранилище (Open folder as vault).

## ИИ в чате: любой провайдер

Внизу слева есть кнопка **«Настройки ИИ»**. В ней выбирается модель, которая будет «мозгом» чата:

| Поле | Что это |
|---|---|
| Провайдер | OpenRouter, OpenAI, DeepSeek, Google Gemini, Groq, Mistral, xAI, Together, Ollama, LM Studio или свой адрес. Подходит любой OpenAI-совместимый API |
| Адрес API | подставляется сам; у пункта «Свой адрес» вписывается вручную |
| API-ключ | рядом с полем есть ссылка «получить ключ» |
| Модель ответа | кнопка «Модели» загружает список моделей провайдера, начни вводить название |
| Модель для поиска | быстрая дешёвая модель, которая переформулирует вопрос перед поиском. Если оставить пустым, используется модель ответа |

Кнопка «Проверить» делает тестовый запрос, после него нажми «Сохранить».
Ключ хранится только в localStorage твоего браузера и уходит только в выбранный API.
Без ключа чат всё равно ищет по базе и показывает источники.

Проще всего начать с [OpenRouter](https://openrouter.ai/keys): один ключ даёт доступ к сотням моделей, и он принимает запросы прямо из браузера.

## Что в репозитории

| Путь | Что это |
|---|---|
| `vault/` | статьи и выжимки разговоров (markdown, Obsidian) |
| `app/server.py`, `app/web/` | веб-приложение: локальный сервер и фронтенд (ES-модули) |
| `export_static.py` | сборка автономного архива (тот же фронтенд, данные вшиты) |
| `parse_export.py` … `build_vault.py` | пайплайн: экспорт Telegram → разметка → `kb.sqlite` → vault |
| `factcheck*.py` | проверка статей на соответствие исходным разговорам |
| `llm.py` | клиент для OpenAI-совместимых API |
| `tasks/` | спецификации задач и дизайн-правила (`tasks/DESIGN.md`) |

Исходных данных (экспорт чата, `data/kb.sqlite`, медиа) и модели поиска (`models/`) в репозитории нет, они слишком большие.
Всё нужное для работы уже лежит в архиве из Releases.

### Запуск сайта из исходников

Для этого нужны `data/kb.sqlite`, `data/media_index.jsonl` и `models/e5-small` из исходного проекта.

```bash
pip install numpy onnxruntime tokenizers
python app/server.py          # → http://127.0.0.1:8765
```

Ключи сервера берутся из файла `.llm_env` (его нет в репозитории). Если файла нет, провайдер задаётся в «Настройках ИИ» на странице, и сервер просто пересылает запросы в выбранный API.
