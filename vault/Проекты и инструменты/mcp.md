# MCP

**Что это:** Протокол/механизм подключения внешних инструментов и сервисов к AI-клиентам (Claude, Claude Code, Codex и др.). Используется крипто-сервисами (MoonPay, Arkham) для интеграции, а также для связки нескольких AI-агентов между собой.

## Что говорили в чате

- 2026-07-29: пересланный твит MoonPay — подключить MCP, залогиниться и заклеймить «микро дроп»; на скрине попап «USDC DROP» на $7.42 с обещанием «we'll keep sending it». glimjke скептичен («бесплатные деньги чи шо»); по тексту попапа похоже на промо-приманка. [[ai-c0145]]
- 2026-09-01: участник показал четыре схемы связки Claude и Codex, две из которых на MCP: codex как MCP внутри сессии Claude через `claude mcp add`, и Claude как MCP-сервер в Codex (плюс комбинированный вариант). Минус MCP-варианта: ответы второго агента падают в контекст и тратят лимиты обеих подписок. [[ai-c0229]]
- 2026-09-01: по словам ImmuneFOMO, через MCP агент получает весь контекст в чат; альтернатива — запустить сессию агента в detached-режиме терминала и доставать из файла истории только нужные ответы, тогда контекст не засоряется. [[ai-c0230]]
- 2026-10-06: Arkham выпустил MCP-сервер — подключение к Claude, Claude Code, Codex и другим MCP-клиентам для запросов по ончейн-активности на обычном языке; настройка за минуту по API-ключу Arkham. [[crypto-c0310]]

## Итог

MCP — рабочий и активно внедряемый способ интеграции крипто-сервисов с AI-клиентами: сервер Arkham для ончейн-запросов выглядит полезным инструментом с настройкой за минуту, тогда как «дроп» от MoonPay участники сочли похожим на промо-приманку. Для связки нескольких агентов (Claude + Codex) MCP работает, но засоряет контекст и расходует лимиты обеих подписок — в чате предлагали обход через detached-режим терминала.
